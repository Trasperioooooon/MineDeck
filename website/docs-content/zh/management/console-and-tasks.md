打开任一台服务器进入详情页，默认就落在 **「控制台」** 标签页，集中承担启停控制、实时日志排查、输入服务器命令和报错诊断。

## 控制台核心能力 {#console}

- **实时日志与历史回放**：进入标签页时自动拉取历史日志并经 SSE（Server-Sent Events）持续推送最新行；警告（WARN）与错误（ERROR）会自动着色标注，支持按关键词过滤日志行（如排查某个玩家或报错关键字）与调整字号。
- **UTF-8 / GBK 编码切换**：默认使用 **UTF-8**；如果在运行特别老的 Windows 插件/脚本且控制台输出中文乱码，可以在日志栏切换到 **GBK**，该设置按服务器各自记忆。
- **底部指令输入框与 Tab 补全**：支持键盘上下方向键翻阅历史发过的指令，按 **`Tab`** 键可自动补全常见 Minecraft 原版指令以及**当前在线玩家名**（输入指令不需要手动加 `/` 斜杠）。
- **页头快捷入口与报错横幅**：
  - 页头直接展示这台服务器的局域网 **连接地址**（点击复制；通过 **「···」** 可在多网卡 IP 间切换）。
  - **「打开目录」** 下拉入口（仅本机可用）可以直接在 Windows 资源管理器打开实例根目录，或直达 `mods`、`plugins`、`world`、`logs` 与 `crash-reports`。
  - 如果服务器没能启动或崩溃退出，控制台顶部会出现中文 **报错横幅**，自动识别常见故障并可点击 **「让 AI 分析」**，详见 [控制台报错横幅索引](../troubleshooting/error-banner-index.md)。

## 安全停服、重启与端口提示 {#safe-stop}

- **有玩家在线时二次确认**：除群组代理端外，点击 **「停止」** 或 **「重启」** 且当时服里有玩家在线时，页面会弹窗提醒「目前有 N 位玩家在线」，确认后会先让服务端安全保存世界再停服，避免直接回档丢物品。
- **优雅退出机制**：点击停服会优先发送 `stop` 命令，最多等待约 `30 秒`；超过时间仍卡死才强制终止进程。退出 MineDeck 主程序时，所有运行中的服务器和跟随启动的穿透隧道也会统一先停下并清理（Java 与 `frpc` 进程已绑定 Windows Job 对象，防止主程序退出后留僵尸进程）。
- **启动前端口试绑提示**：每次开服前 MineDeck 会按 `server-ip` 与 `server-port` 先做一次端口检测；一旦发现冲突直接停住并提示 **「改端口」** 按钮（或推荐一个避让端口），避免白跑几十秒加载核心后再崩。

## 后台任务追踪 {#tasks}

建服、下载 Java、导入整合包、导出或导入 `.mdpack` 交接包这些耗时操作会在后台跑任务：

- **切页刷新不中断**：页面底部或右上角随时能进 **任务列表** 或点回单个任务查看详细步骤进度与日志，长安装器日志会保留开头前 40 行与最近日志。
- **30 秒慢下载提示与超时记录**：如果某个源 30 秒无进度变化，任务卡片会提醒可能下载较慢或正在自动重连，失败快照会记录最近访问的主机名。
- **取消机制**：新建服务器、导入整合包和导入交接包在允许阶段可点击取消，等待临时目录清理后结束（**注意**：重启动作不会丢失文件，但本次重启前的任务摘要历史会在重启 MineDeck 后清空）。

## 操作记录（`logs/ops/`） {#ops-logs}

为了方便多人协助管理电脑或 AI 助手回溯历史改动，你在界面做的修改操作、定时任务、崩溃重启、通过 **AI 助手** 确认执行的提案以及 **MCP 客户端** 触发的提案执行，都会记入程序目录的 `logs\ops\` 审计文件：

- 单纯查看界面、读日志这类只读操作不记录。
- 记录中出现 API Key、密码、访问令牌、Webhook 地址或 `server.properties` 的密码项（如 `rcon.password`）时，参数一律自动掩码为 `***`，不会把明文密钥写入操作日志。
