手里有下载来的空岛/冒险地图、玩了很久的单人存档（`.minecraft\saves\` 里具体某一个存档文件夹）或旧服世界时，可通过两条路径直接使用：

- **① 新建一台新服**：侧栏 **「新建服务器 → 用已有地图开服」**（先扫地图，再按地图原本的游戏版本与核心类型自动预选配置，不会贸然给你升到最新版）；
- **② 替换现有服务器地图**：打开服务器详情页 **「世界与备份 → 换地图」**，点击 **「导入并替换当前地图」**。

> [!NOTE]
> **上传与选盘规则**：在本机电脑直接操作时，既可以选择未打包的世界文件夹，也可以选 `.zip` 压缩包；而在局域网用手机或其他设备远程操作网页时，只能上传 `.zip`（上限 **8 GB**）。同时，换地图、恢复与删除恢复点全部属于**仅人工操作**，AI 助手和 MCP 接口只能查看状态，无法代点导入或修改本机路径。

## 能导入什么、会拦截什么 {#formats}

MineDeck 通过识别 `level.dat` 与世界目录结构来判断，不看文件名或外层多套了几层压缩文件夹（如果一个压缩包里有多个地图会列出来让你挑）：

| 类型 | 能否导入 | MineDeck 的处理或建议 |
| --- | --- | --- |
| Java 版完整世界文件夹或 `.zip`（含 `level.dat`，支持 26.1 前后原版及 Bukkit/Paper 三文件夹布局） | **支持** | 正常扫描预览后导入 |
| `.mcworld`、手机/主机/Win10-11 基岩版存档 | 不支持 | 格式不兼容，无法通过改后缀转成 Java 版 |
| `.schem` / `.schematic` / `.litematic` 建筑蓝图 | 不支持 | 应在游戏内通过 WorldEdit 或 Litematica 粘贴 |
| `.rar` / `.7z` / 加密或分卷压缩包 | 需先解压 | 请用解压软件先解开成常规文件夹或无加密 `.zip` |
| 资源包、数据包、整合包或 `.mdpack` 交接包 | 不支持在此导入 | 整合包/交接包走新建页对应入口；数据包手动放入世界的 `datapacks/` |
| 只有 `region` 没有 `level.dat`，或单张目录多于 256 个世界的总根目录（如整个 `saves`） | 不支持 | 请点进去只选择含单个 `level.dat` 的那一层文件夹 |

## 导入前预览与版本比对 {#preview}

选好地图后会先出一份详细预览，列出探测到的 **地图最后保存版本、维度、自带数据包与资源包线索、模组加载器痕迹、即将替换的文件夹与占用体积**，以及**建议采纳的服务器配置**（如难度、游戏模式等默认**不勾选**，按需勾选才应用）。

版本对比按以下原则处理：
- **地图比当前服务器还新**（如 26.3 地图导进 1.21.11 的服）：**红色拦下禁止导入**，请用「用已有地图开服」另建对应版本的服，切勿强改存档降级避免坏档。
- **地图比当前服务器旧 / 是快照版 / 核心与探测模组不匹配**：**黄色提醒需勾选「我已了解」** 才允许继续；开服后旧世界会被升级为新版本格式且无法再回旧版客户端读取，原本模组服没在目标服补齐相同模组也会丢失模组方块与维度。
- **磁盘剩余空间无法探测的网络盘或特殊磁盘**：预览区会加出一项需要你手动确认体积放得下的勾选框。

## 替换过程、单人存档与恢复点回退 {#replace-flow}

### 替换时不卡服、断电不坏档

- 点击 **「停服并导入」** 时：复制与校验在暂存区完成期间服务器照常在线（此时仍可随时点取消）；进入真正替换阶段后，MineDeck 会先温柔通知服务器自己存盘停下（2 分钟停不下则放弃并保持原地图，**绝不强杀进程破坏存档**）。
- 更换完成后服务器状态保持为**已停止**（并标注「地图文件已导入，尚未启动检查」），同时确认核心、Java、内存、端口、`uid.dat`、白名单、OP、模组/插件及多世界插件建出的**非默认世界均保持不动**。

### 单人存档转服务器（背包与资源包）

- 世界、建筑、箱子全部在；主人背包/经验取决于服务器配置：若开启了正版验证且用同一个正版账号进服，通常会直接接上；若关掉了正版验证（离线模式），则按名字生成新 UUID，想接上需先空进一次服再退出、停服后按预览页标明的文件名把旧玩家数据改名覆盖过去（注意先留备份）。
- 地图包内若自带 `resources.zip` 或要求命令方块，服务器不会主动下发资源包或自动开命令方块（新版本已变为游戏规则，老版本在 `server.properties`），需要自行按地图包里的 README 调好。

### 换回之前的地图（恢复点） {#restore-points}

- 每次成功替换地图后，原有世界连同下界、末地都会**整个移入「恢复点」**，不占常规备份的轮换名额，也不会被定时备份冲掉，直到你点 **「删除恢复点」** 才移除。
- **依次向前换回**：如果你前后换了三张图，界面只有**最近那一次**恢复点能点 **「恢复导入前的地图」**（同时撤回当次勾改的地图推荐配置），把它换回原位后前一次的按钮才会显现；刚才玩出的新图会留在旁边不删，确认不要再清理即可。
- 用 **「用已有地图开服」** 新建的服因为没有前一张旧图，只有一次删除恢复点动作，没有可换回对象。

### 如果换到一半关机断电怎么办？ {#crash-recovery}

替换每一步都会持久化写状态；万一在移动文件的瞬间断电或强制关程序，下次启动 MineDeck 时程序会自动发现未完成操作并**先行退回导入前的世界**；如果原目录被杀毒软件或文件管理器占住退回一半，服务器会处于暂停启动状态，提示你关闭占用程序后在「换地图」页面点击 **「重试恢复」**，确保世界不处于半残状态（在完成重试恢复前，其他恢复点暂锁定不可操作）。
