在开始开服或做长期配置前，了解 MineDeck 当前支持的运行环境与功能边界，能帮你避开不少折腾。

## 运行环境要求 {#requirements}

| 项目 | 要求与说明 |
| --- | --- |
| **操作系统** | **仅支持 Windows 64 位**（如 Windows 10 / Windows 11），不提供 macOS 或 Linux 构建。 |
| **界面语言** | 程序界面为**简体中文**。 |
| **窗口依赖** | 桌面窗口使用系统自带的 **WebView2** 渲染；若你的精简版系统未安装 WebView2，启动时会自动退回用默认浏览器打开本地管理页。 |
| **Java** | **无需手动预装**。启动时会自动扫描注册表、`JAVA_HOME`、`PATH` 与常见安装目录；缺少对应版本时会按需自动下载便携运行时到程序目录 `runtimes/` 下，不改写系统环境变量。 |
| **磁盘空间** | 本体为单文件绿色程序；建议放在专门的英文路径文件夹中，并为服务端核心、世界存档和自动备份预留充足空间。 |

> [!WARNING]
> **路径限制**：如果你要运行 **Mohist** 或 **Taiyitist**（原 Banner）混合核心，服务器所在目录绝对路径**不能包含中文或非 ASCII 字符**，MineDeck 在新建和接管阶段都会拦截此类路径。即便不跑混合端，也强烈建议避免把程序放进系统桌面或带空格/特殊字符的深层目录。

## 当前功能边界 {#limits}

以下行为属于程序目前的明确设计边界，使用前建议先心里有数：

- **下载源差异**：Mojang 官方服务端与 Fabric 支持通过国内镜像（BMCLAPI）加速下载；**Paper、Purpur、Leaves、Folia、Mohist、Taiyitist（原 Banner）、Velocity、Waterfall 没有国内镜像**，默认直连各自官方接口；安装 Forge 与 NeoForge 时即使走镜像，仍有部分前置步骤需要访问官方源，官方源连不上时可能会失败。
- **备份范围边界**：世界备份**只包含世界目录，不包含 `mods`、`plugins`、`server.properties` 等配置**。如需把整台服务器打包搬迁或交给朋友，请使用 [接管已有服务器与交接包](../server-setup/adopt-and-handover.md)。
- **更新前必须停服**：在 **「设置 → 更新与关于」** 执行程序自更新前，必须先停掉所有运行中的服务器。
- **端口自动避让限制**：新建服务器和改端口时会自动探测同机其他 MineDeck 服务器和正在监听的端口，但 **Windows Hyper-V、WSL 或 Docker 占用的系统保留端口段无法提前预查**（若撞上会在启动前试绑阶段报错提示）。
- **Win10 与 Win11 音乐共享区别**：Windows 11 支持按单个播放应用单独采集（会自动排除游戏本身以防回声）；Windows 10 上只能采集**整机混音**，会把游戏声音与其他人的语音一起录进去（首次启用会在界面提醒确认）。
- **手机远程管理安全边界**：使用手机或别的电脑登录局域网管理页可以启停服、发指令与传模组，但**修改存储路径、添加本机 Java 路径、接管本地目录、改动 AI 与 MCP 设置、操作工具箱本地保存等仅接受本机请求**，局域网设备只读或不可触发。
- **模组配置文件编辑**：插件/模组页可直接启用、停用和删除已装文件，但不提供图形化编辑具体模组 `.toml`/`.yml` 配置文件的表单（你可在资源管理器打开目录修改，或配合 AI 助手 / MCP 修改并确认）。
- **代理端不支持项目**：**Velocity** 与 **Waterfall** 代理端没有 EULA 与 `server.properties`，不显示 **「玩家」**、**「世界与备份」** 与 **「扩展」**（游戏内 AI / AI 伙伴 / 音乐共享），也不做启动前游戏端口试绑。

## 尚待进一步实机覆盖的场景 {#untested-notes}

以下功能已在开发环境、仿真接口或测试框架下验证通过，但在大规模复杂真机环境中仍待进一步实际检验，正式使用前建议先小范围试跑并做好世界备份：

- **OpenFrp / 樱花穿透平台账户真实线上联调**：账户登录、创建隧道、导入与 OpenFrp UDP 语音隧道的线上真实节点兼容性。
- **多玩家真实客户端长期联调**：**AI 伙伴** 与 **音乐共享** 在多位真实玩家同时联机进服场景下的表现；**游戏内 AI** 双账号 `/私` 与 MC 1.21.5+ 真服实测。
- **工具箱导出成品与换地图复验**：工具箱生成的离线皮肤包与 `.mrpack` 整合包在不同第三方启动器上的实测兼容性；换地图后进入真服游玩的完整流程；手机远程页面在 iPhone 真机浏览器下的细节表现。
- **外部 MCP 客户端逐一实机检验**：目前官方已实际联调验证 Codex，Claude Desktop、Cherry Studio、Cursor 与 VS Code 均按官方配置规格生成导出片段，暂未在真实桌面环境下逐一开机跑遍。

如在实际使用时遇到边界外的情况，欢迎带着报错详情或截图到 [反馈页](/feedback/) 反馈。
