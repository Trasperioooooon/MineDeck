这里汇总了初次使用 MineDeck、开服和日常维护时最常遇到的问题。

## 需要自己先安装 Java 吗？ {#java}

不需要。MineDeck 启动时会自动扫描本机已安装的 Java；如果电脑里已经有满足目标 Minecraft 版本要求的 Java，就会直接使用。如果没有找到合适的版本，MineDeck 会自动下载一份便携版存放在自己的 `runtimes` 文件夹里只给自己用，不会修改系统环境变量，也不会干扰你原本的 Java。

> [!CAUTION]
> 请不要手动删除程序目录下的 `runtimes` 文件夹。删掉之后，所有指着那份 Java 运行的服务器都会找不到 Java 而无法启动（如果误删或文件损坏，可到服务器详情 **「设置 → 启动与内存」** 重新选用或下载）。

## 朋友不在同一个网络，怎么连进来？ {#remote}

打开侧栏 **「内网穿透」**，你可以添加 OpenFrp、樱花穿透（SakuraFrp）或者自己搭建的 frps 隧道，绑定到你要开的服务器并勾选 **「跟随服务器启动」**。开服后把隧道卡片上显示的公网连接地址发给朋友即可。

如果朋友就在**同一个局域网**（如连着同一台路由器），不用开内网穿透，直接把服务器页头上显示的 `局域网IP:端口` 发给对方即可。详情见 [内网穿透与平台账户](../networking/tunnels-and-accounts.md)。

## 为什么刚创建完的服务器，朋友连不上局域网？ {#firewall}

常见有两个原因：

1. **Windows 防火墙拦住了入站连接**：第一次启动某台服务器时，Windows 防火墙通常会弹出安全警报窗口，务必允许并点 **「允许访问」**。若之前点成了取消，请到 Windows 防火墙允许对应的 `java.exe` 通过专用/公用网络。
2. **连接地址看成了后台管理地址**：`27333` 端口是 MineDeck 自己的网页与手机远程管理地址，好友进游戏要连接的是服务器自己的游戏端口（通常是 `25565` 或页头上显示的「连接地址」）。

## 支持哪些 Minecraft 版本与核心？ {#versions}

支持 Minecraft **1.12.2 到最新正式版**（包含按年份编号的 `26.x`），共内置 12 种服务端核心：原版 `Vanilla 原版`，插件服 `Paper`、`Purpur`、`Leaves`、`Folia`，模组服 `Fabric`、`NeoForge`、`Forge`，混合服 `Mohist`、`Banner`，以及群组代理端 `Velocity` 和 `Waterfall`。同时也支持直接导入 Modrinth（`.mrpack`）与 CurseForge（`.zip`）整合包，以及作者打包好的现成服务端压缩包。详见 [新建服务器：从零创建](../server-setup/create-server.md)。

## 新建服务器后「白名单」为什么默认是关的？ {#whitelist}

从 Minecraft 26.3 起，服务端自己默认会打开白名单，以前不单独提醒，新手开服后容易把朋友挡在门外。从 `v3.2.0-beta.3` 起，从零创建、导入整合包、用已有地图开服这三步会给出 **「只允许白名单里的玩家进入」**，默认关闭。导入交接包沿用包里的配置，没有这个开关。接管已有服务器只读出原来是开还是关，不在接管表单里改。需要限制玩家时，到服务器详情 **「玩家」** 里打开白名单并加入玩家名。

## 服务器起不来，控制台报错看不懂怎么办？ {#crash}

先看控制台顶部的报错横幅。MineDeck 有 13 条诊断规则，速查表列出 14 种结果（Java 版本不对和 JVM 参数不被支持来自同一条规则）。缺少前置模组、客户端模组放进服务端、装错加载器、Java 版本不匹配、端口被占、内存不够这些，不配置 AI 也能直接看到原因和改法。逐条对照看 [控制台报错横幅索引](../troubleshooting/error-banner-index.md)。

如果配置了自己的 AI Key，横幅旁还可以点 **「让 AI 分析」**，或者在右上角打开 **「AI 助手」** 直接提问。

## AI 功能要另外花钱吗？会不会未经同意乱改服务器？ {#ai}

- **完全可选、不填 Key 不联网**：不配置 AI 服务商时，MineDeck 不会连任何大模型接口，一切基础开服管理功能照常使用。
- **费用归属于你自己的服务商账号**：填入 DeepSeek、通义千问、Kimi、智谱、小米 MiMo、OpenAI、Claude 或本机 Ollama 地址，消耗按你选择的账号计费；MineDeck 会估算每日消费并提供功能级每日额度上限控制。
- **改写操作必须人工确认**：AI 助手可以自己看日志和配置文件，但只要涉及修改配置、更换 Java、重启、装模组或删操作，一律先在面板上弹出一张确认卡片，**必须你亲手点确认才会执行**；`游戏内 AI` 也只有你勾选授权的玩家可以触发白名单命令，且严禁执行 `op`、`execute` 等危险命令；`eula.txt` 必须由人决定，AI 不会代为同意。

## 用「AI 伙伴」或「音乐共享」时，好友客户端要装东西吗？ {#friends}

- **AI 伙伴**（支持 NeoForge 1.21.1 与 Forge 1.20.1）：服务端由房主在详情页 **「扩展 → AI 伙伴」** 一键安装；**每个进服的好友也必须在客户端 `mods` 目录装上同版本的伙伴模组 jar**（下载页有提供）。PlayerEngine 与 Architectury API 只装服务端，好友不用装。
- **音乐共享**：服务端和好友客户端都需要安装兼容同一版本的 **Simple Voice Chat** 模组；MineDeck 自己的语音桥接模组只安装在服务端，好友不用装。另外 Windows 10 上采集音频只能录制整机混音（Windows 11 可仅录制单个音乐软件），不在同一局域网时还需配置 UDP 语音隧道。

## 「待装清单」是不是以前的「购物车」？「没装上的文件」是什么？ {#terms}

是的。自 `v3.2.0-beta.3` 起界面做了一轮直白用语整理：
- 原先的「模组购物车」改称 **「待装清单」**，原先分开的「资源」与清单页已合并成详情页上的 **「插件」** / **「模组」** / **「插件和模组」** 标签。
- 原先任务页里的「待决文件」改称 **「没装上的文件」**，即使关掉重开软件，没处理完的提示依然会保留在服务器页头，随时能补齐或跳过。
- 原先「允许局域网访问」设置分区改称 **「设置 → 手机远程管理」**。

## 备份里包含模组、插件和配置文件吗？ {#backup}

**不包含。** 服务器详情 **「世界与备份 → 备份」** 所做的热备和还原**只备份当前世界存档文件夹**，不含 `mods`、`plugins`、`server.properties` 或其他配置。如果你希望连存档、模组、插件与配置一起整体打包带走或转交给朋友，请使用服务器卡片或页头 **「···」→「导出交接包…」**。

## 稳定版、测试版怎么选，如何更新？ {#beta}

日常稳定开服请选择 **稳定版**。测试版会提前放出新功能试用，可能仍存在未在真实客户端或全平台实测完的边界。测试版请放进独立文件夹测试，并预先备份原有服务器。有关更新渠道切换、SmartScreen 拦截和升级方法，请看 [下载与安装（含 SmartScreen）](../getting-started/download-install.md)。
