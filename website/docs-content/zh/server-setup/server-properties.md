打开服务器详情页的 **「设置」** 标签（注：**Velocity** 与 **Waterfall** 代理端只有「启动与内存」子页，没有 `server.properties`），可以在两个子页分别调整常见项与全量底层配置。

## 「设置 → 常用」：7 大中文分组 {#common}

程序内置梳理了 **`server.properties` 中最常用的 78 项配置**，翻译为中文名称并补充说明与生效提示，按用途拆成 7 组：

1. **基础与玩法**：世界名称、游戏模式、难度、极限模式、最大人数、MOTD（支持选色与即时预览、正确写入中文与 Emoji 表情）等。
2. **世界生成**：世界种子、生成结构、世界类型、视距与模拟距离等。
3. **玩家与权限**：正版验证（`online-mode`）、白名单开关、默认 OP 权限等级、PVP、允许飞行等。
4. **性能**：实体追踪、网络压缩阈值、同步块写入等。
5. **网络与远程管理**：服务器端口（`server-port`）、`server-ip` 绑定、Query 与 RCON 开关及密码。
6. **资源包**：强制资源包地址、SHA-1 校验与提示文字。
7. **安全与杂项**：出生点保护半径、记录管理员指令等。

> [!TIP]
> - **自动隐藏不适用项**：如果你运行的是老版本或新版本 Minecraft，「设置 → 常用」会自动隐藏当前版本并不支持的选项，避免调了不生效的参数。
> - **需要重启才生效的项**：界面上会在对应条目旁明确标记；改完后需要重启一次服务器才能套用。
> - **MC 1.21.9+ 游戏规则即时切换开关**：从 **Minecraft 1.21.9** 起，原本属于 `server.properties` 的部分开关（例如 **PVP**、**启用命令方块**、**生成怪物**）在游戏内改由 Gamerule 控制——在「设置 → 常用」中这些项会变成实时开关：**服务器运行中直接点击即可立即生效，无需重启**（服务器处于停止状态时无法操作这些游戏规则项）。
> - **MC 26.1+ 难度同步**：自 `26.1` 起部分版本仅改配置文件不会刷新现有世界难度，MineDeck 会在开服后自动补发一条 `difficulty` 指令与当前配置保持一致。

## 「设置 → 全部配置」：全键值直接检索 {#raw}

如果有偏冷门的插件兼容项或自定义扩展字段没出现在「常用」分组中：

- 切换到 **「设置 → 全部配置」**，这里逐行列出 `server.properties` 现存的所有键值对；
- 已知的常用键同样附带中文说明，你可以直接在顶部搜索框**输入英文键名或中文关键字**快速定位修改并保存。

## 注意事项与排错 {#notes}

- **端口冲突检查与页头「改端口」**：如果你在 **「设置 → 常用」** 里改了 `server-port`，或因同机另一台服务器已占用了当前端口被控制台提示拦下，点击页头的 **「改端口」** 按钮可以直接跳转并自动滚到端口输入栏高亮提示。
- **文件被只读或外部锁占用**：在 Windows 下，如果你之前用记事本打开过 `server.properties` 未关闭，或目录权限把它标成了只读，保存配置（包括地图导入/备份期间读配置）时界面会明确提示占用或只读原因——关掉外部编辑器、取消文件只读属性后再保存即可（自 `v3.2.0-beta.4` 起，对只读属性文件已改进报错与保留写入保护）。
- **`server-ip` 建议默认留空**：除非你的电脑装有多张网卡且明确要限制仅监听其中某一张内网 IP，否则保持 `server-ip` 为空即可，乱填公网 IP（尤其是搭配内网穿透时）会导致服务器根本绑不上端口直接启动失败。
