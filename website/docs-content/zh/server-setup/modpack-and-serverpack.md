在侧栏 **「新建服务器 → 导入整合包」**，支持三类常见压缩包格式（文件上限 **4 GiB**）：

- **Modrinth 整合包（`.mrpack`）**：自动识别核心、游戏版本并下载服务端需要的文件，**仅客户端使用的模组会自动跳过**。
- **CurseForge 整合包（`.zip`）**：清单最外层或外层多套一层文件夹（如 `整合包名/manifest.json`）都能识别，按类型自动分放进 `mods`、`resourcepacks`、`shaderpacks` 与 `datapacks`。
- **作者打包的现成服务端压缩包（`.zip`）**：包里没有整合包清单，但已含 `mods`、`plugins`、`server.properties` 或服务端 jar（同样支持套一层文件夹）。

> [!WARNING]
> **客户端整合包 ≠ 服务端整合包**
> CurseForge 上的许多 `.zip` 整合包是给玩家客户端用的，里面往往混有小地图、光影菜单、鼠标手势等**仅客户端模组**。MineDeck 导入时不会提前剔除它们；若启动崩溃，控制台会由 [报错横幅](../troubleshooting/error-banner-index.md#client-only) 认出是哪几个文件引起的，把它们在「模组」页点 **「停用」** 即可。大型整合包建议优先去整合包发布页下载作者专门提供的 **Server Pack**。

## 导入流程与 CurseForge API Key {#import-flow}

1. 打开 **「新建服务器 → 导入整合包」**，选择本地的 `.mrpack` 或 `.zip` 文件。
2. 填写 **名称**、**端口**、**内存** 与 **存放位置**；如你本地下载了整合包附带的额外文件，可在高级选项填入 **「本地来源文件夹」** 优先本地匹配。
3. 勾选同意 Minecraft EULA 后开始导入，进入任务页查看下载与解压进度。

### CurseForge API Key 说明 {#cf-key}

因为 CurseForge 下载接口要求使用 API Key：
- 如经常导入 CurseForge 整合包，建议在全局 **「设置 → 下载与网络 → CurseForge API Key（选填）」** 免费申请并填入你自己的 Key（使用 Windows DPAPI 本地加密保存）。
- **不填 Key 也能正常导入**：清单中无法自动解析下载的文件不会令整个任务失败，而是统一列进下面要说的 **「没装上的文件」**（同时会在服务器目录写入 `未解析模组清单.txt` 方便查阅）。
- **Modrinth `.mrpack` 无需任何 Key**，直接导入即可。

## 导入「作者现成服务端压缩包」的边界 {#serverpack}

把作者发出来的整套服务端 `.zip` 丢进来导入时：
- **不会重新下载核心**，直接整包解压、只自动修正端口、并按需要添加 `log4shell` 参数，沿用包里原有的正版验证与允许飞行设置。
- **前提条件**：包里必须**已经带齐服务端核心和装好的 `libraries` 文件夹**（Fabric/Paper/Vanilla 需带核心 jar，Forge/NeoForge 需包含已安装完 `libraries`）。
- 若你拿到的 Server Pack 压缩包里**只有安装器、`start.bat` / `run.sh`，要首次跑脚本才会现下安装器**，MineDeck 会识别不出而拒绝直接导入——请先把压缩包解压到单独文件夹，手动跑一遍里面的安装脚本直到真正能开服，再回来用 [接管已有服务器](./adopt-and-handover.md) 收进列表。
- 压缩包里原有启动脚本或 `user_jvm_args.txt` 的额外 JVM 参数不会自动并入，需要时导入后在 **「设置 → 启动与内存」** 补充。

## 逐个处理「没装上的文件」 {#pending}

当整合包里某些文件因为：**① 未填 CurseForge Key ② 下载链接不在允许域名 ③ 缺少校验值或非 https ④ 下载校验不一致** 而没能自动装进服务器时，它们会被记录在服务器目录的 `.minedeck/import-pending.json`（及人读版 `导入待决清单.txt`），称为 **「没装上的文件」**（早期版本文档曾称「待决文件」）。

> [!NOTE]
> 这些未完成项会持久保存——关闭 MineDeck 再打开也不会丢。只要还有「没装上的文件」，这台服务器页头会常驻提示，你可以随时在 **任务页**、**页头提示** 或详情页 **「模组 / 插件 → 整合包里没装上的」** 区块逐个处理，支持三种方式：
>
> 1. **用本地文件补齐**：选择你从官网/网盘自己下载好的单个文件，或直接指定一个包含多个 mod 的文件夹让程序按文件名原样拷入（原样拷贝的文件在任务警告中会标为未校验）。
> 2. **信任站点后下载**：若链接本身是 `https` 公网地址且带有校验值，阅读弹窗中的安全风险提示并确认后即可允许本次及后续同一主机的可信下载（主机域名会记入 `config.json` 的 `trustedHosts`；**界面目前未提供撤销信任按钮**，需要撤销时可在停止程序后手动编辑 `config.json` 移除对应主机项）。
> 3. **跳过**：暂不安装；如果以后改变了主意，已跳过的条目依然可以在「整合包里没装上的」区域改用本地文件重新补上（注：**Vanilla 原版**因为没有插件/模组页，跳过后界面无法再二次补回）。

另外请注意：

- **数据安全限制**：「没装上的文件」不允许把内容覆盖写进世界存档或 `server.properties`。
- **完整入列条件**：整合包导入过程中若网络中断，已下载的文件有缓存，直接重试即可；只有整次初始化流程全部完成后，这台新服务器才会正式加入列表（未完成前不出现在列表）。
- **数据包注意**：如果 CurseForge 清单里有数据包落入 `datapacks/` 目录，MineDeck 不会主动去修改已有世界里的数据包启用开关。
- **Windows 特殊文件名保护**：包里如果出现 `CON`、`COM1` 等 Windows 设备保留名、末尾带点或空格的文件，或者仅有大小写差异的同名文件，会按 Windows 规范过滤或保留并在任务日志中写明。
