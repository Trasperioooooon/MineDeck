先分清两个最容易弄混的地方：**「设置 → 手机远程管理」是用手机或别的电脑管你的 MineDeck 网页后台**，和让朋友进 Minecraft 游戏的「连接地址」不是同一件事！让朋友进游戏，请发[服务器连接地址](./lan-and-ports.md)或[内网穿透公网地址](./tunnels-and-accounts.md)。

## 一、开启「手机远程管理」 {#remote-admin}

打开侧栏 **「设置 → 手机远程管理」**（原老版本称「远程访问」）：

1. **先设置访问密码**：开启前必须填写管理密码（密码在本地以 `bcrypt` 哈希保存，不存明文）。
2. 打开 **「开启手机远程管理」** 开关，并**重启一次 MineDeck** 生效（注意：开启开关须重启才绑定所有网卡 `0.0.0.0`，关掉开关则立即失效并让已有局域网登录全部退出）。
3. 重启后回到该设置页，就能看到可供手机直接扫描打开管理后台的 **局域网网址与二维码**（只要手机和开服电脑在同一个路由器 / Wi-Fi 下即可直接访问）。

### 安全边界：哪些事不能在手机远程页面做？ {#remote-bounds}

为了防止把控制权限暴露给非本机用户，即使输对访问密码登录进来，以下涉及系统磁盘目录与本机凭据的高敏感操作 **仍然只允许坐在这台主机的 MineDeck 上做**（手机端只读或隐藏入口）：

- **不可在手机上修改的内容**：更改全局「存储位置」路径、添加本机 Java 运行时路径、「接管已有服务器」、处理需本机路径的待装文件、导出保存至本机目录、「换地图」选中电脑上的文件夹（手机上只许上传 `.zip` 地图包）、**AI 服务商设置与 Key**、**MCP 接口开关/令牌**、**OpenFrp / 樱花平台账户绑定建隧道**；此外 Webhook 地址的令牌部分也会自动屏蔽显示为 `***`。
- **可以在手机上做的事**：看服务器列表、启停与重启、发控制台指令、改「常用 / 全部配置」、切服务器自带内存与已有 Java、添加/停用/删除或上传 `.jar` 模组、备份与还原、查看已绑定好的内网穿透状态（若全局开了 **「局域网可用 AI 助手」** 也能使用房主的 AI 助手，按需在设置关闭）。

> [!CAUTION]
> 通过局域网网页后台已经能够启停服务器、添加插件或修改 JVM 参数（本质上就能在宿主电脑运行新程序）。**因此访问密码请只告诉可信任、能共同管电脑的人**，不要发到无关群聊中。此外，手机端页面已在安卓浏览器做过常见适配（含横屏与底部安全区避让），iPhone 真机尚未实测完所有细节，如有界面遮挡欢迎到 [反馈页](/feedback/) 报告。

## 二、发给好友的进游戏前核对清单 {#friends-checklist}

开好一台服准备叫好友来玩时，建议顺便发去下面这几条关键信息免得大家各自踩坑：

1. **Minecraft 版本与核心加载器**：例如「Java 版 1.21.1，使用 NeoForge（或原版不用装加载器）」。
2. **是否需要装客户端模组或整合包**：
   - 如果是**纯原版或纯插件服（Paper / Purpur 等）**：朋友用同版本原版客户端即可直接进；
   - 如果是**模组服**：需要和服务端完全一致的模组（见 [工具箱导出 `.mrpack`](../management/toolbox.md) 或 [打包发给朋友怎么选](./share-with-friends.md)）；
   - 如果这台服开了 **AI 伙伴**：好友客户端**必须加装同版本伙伴模组 jar**（见 [AI 伙伴与伙伴模组安装](../in-game/companion-mod.md)）；
   - 如果这台服开了 **音乐共享**：好友客户端需要加装**同版本 Simple Voice Chat 模组**（桥接模组不用装），否则仍可进游戏但听不到共享音乐（见 [音乐共享与语音聊天桥接](../in-game/music-sharing.md)）。
3. **进服连接地址**：同局域网发 `局域网IP:端口`，异地联网发内网穿透给出来的公网地址（樱花穿透类似 `xxx.natfrp.cloud:12345`）。
4. **是否在白名单中**：若你按推荐开启了白名单，先在 **「玩家」** 里加上好友准确的游戏名（离线服区分大小写拼写）。
