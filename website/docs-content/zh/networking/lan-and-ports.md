当开服电脑与朋友的电脑连在**同一台路由器、同一个家庭 Wi-Fi 或同一局域网（含已正常连好的虚拟局域网组网工具）** 下时，**不需要开启内网穿透**，直接用局域网 IP 加上游戏端口即可连接（延迟更低、也不限流）。

## 查看并发送连接地址 {#lan-address}

1. 在 **「服务器」** 列表或进入具体服务器详情页，先点击 **「启动」** 等到控制台出现 `Done (...)!`。
2. 开服者自己在本机客户端填 `127.0.0.1` 进服（若服务器端口改过且不是默认 `25565`，则填 `127.0.0.1:端口`）。
3. 同一局域网里的朋友：直接复制详情页头或服务器卡片上显示的那串 **`局域网IP:端口`** 连接地址（点击即可复制到剪贴板）。

> [!TIP]
> **多网卡 IP 切换**：如果你的电脑同时插着网线、连着 Wi-Fi 或装了虚拟机（VMware / Hyper-V / WSL / 虚拟网卡），MineDeck 默认会把常见家用/校园局域网段（如 `192.168.x.x` / `10.x.x.x`）排在前面；如果展示出来的默认 IP 朋友依然连不上，点击页头右上角 **「···」**（部分卡片状态栏亦可选切换）换另一张网卡显示的局域网 IP 试试（该选择会记住在当前这台设备浏览器中）。

## 首次启动的 Windows 防火墙放行 {#firewall}

- **第一次启动具体某台服务器**时，Windows Defender 防火墙通常会弹出安全警报，询问是否允许 Java（`OpenJDK Platform binary` / `javaw.exe`）使用网络。
- 请勾选网络类型并点击 **「允许访问」**。如果当时顺手点成了取消或只允许了其中一类网络，同一局域网下的朋友就会卡在「正在连接服务器」直到超时。补救步骤见 [端口占用、局域网连不上与 frpc 被拦](../troubleshooting/port-firewall-frpc.md)。

## 端口分配与同机避让 {#ports}

- **新建自动避让**：在 **「新建服务器」** 中填写端口时（默认 `25565`），MineDeck 会自动跳过同列表里已有服务器占用的端口以及本机当前正在监听的端口，避免多台开服撞车。
- **启动前试绑检测**：点开服时程序会再照服务端绑定地址试绑一次；如果正好被别处占用，控制台横幅会拦下并发起一键 **「改端口」** 提示（群组代理端及端口为 `0` 除外）。
- **Windows 系统保留端口限制**：Windows 在开启 Hyper-V、WSL2 或 Docker Desktop 后会由系统保留出成段端口区间，这些系统保留段目前无法在界面向导阶段提前预查——如果开服时报 `Permission denied` 或 `Address already in use`，换个其他区间端口（如 `25575`～`25699`）重开即可。
- **不在同一个网络怎么办？**：若朋友在异地家中、且你没有固定公网 IP，请使用 [内网穿透与平台账户](./tunnels-and-accounts.md)。
