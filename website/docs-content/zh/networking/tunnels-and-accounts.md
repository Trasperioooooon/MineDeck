> [!NOTE]
> **同一个局域网里的朋友不需要配置内网穿透**（例如同一台路由器或宿舍内网），直接把服务器页头上显示的 `局域网IP:端口` 发给对方即可连接。只有跨网络联机、且主机没有公网 IP 时，才需要使用内网穿透。

打开左侧栏 **「内网穿透」**，可以把本机服务器映射出公网连接地址。目前支持 **OpenFrp**、**樱花穿透（SakuraFrp）** 和 **自定义 frps**。

## 添加隧道的两种方式 {#ways}

你可以根据使用习惯二选一：

### 方式 A：通过「平台账户」授权并在 MineDeck 内新建/导入（自 v3.2.0 起） {#account}

不想手动来回复制隧道 ID 和密钥时，可以在页面下方 **「平台账户」** 分区绑定自己的穿透账号：

- **OpenFrp**：点击 **「浏览器授权」**，在浏览器完成登录确认，MineDeck 不保存你的账号密码。
- **樱花穿透（SakuraFrp）**：到樱花官网后台复制你的访问密钥粘贴进来。

连上账户后，可以在页面卡片里看流量和账户概览，也可以打开官网自己签到或购买（MineDeck 不代签，也不代下单）。新建隧道时可选 TCP 或 UDP，也可以把平台上已有的隧道导入进来。樱花穿透的新建对话框标题是「在 樱花frp 创建并导入」，里面有 **「这是公开服务器」**：把连接方式发到论坛、服务器列表，或在公开平台招人时要勾上，并且只能用名称里带「多线」或公开游戏标记的节点，用错节点会被封号且不退款。只和熟人联机可以不勾。这个开关不在上面的「添加隧道」表单里。

> [!WARNING]
> **安全边界**：连接或断开账户、新建或导入隧道等会改动凭据的操作，**只能在运行 MineDeck 的这台主机本机进行**；通过手机远程管理页访问时仅可查看状态。另外，平台账户功能的真实线上联调覆盖仍在持续收集反馈。

### 方式 B：在上方 **「添加隧道」** 表单手动填写 {#manual}

点击列表上方的 **「添加隧道」**，选择对应服务商：

| 服务商 | 需要填写的信息 | 客户端准备 |
| --- | --- | --- |
| **OpenFrp** | 在 OpenFrp 控制台先建好一条本地端口对应服务器端口的 TCP 隧道，填入 **用户密钥** 和 **隧道 ID** | MineDeck 自动下载对应客户端 |
| **樱花穿透（SakuraFrp）** | 在 SakuraFrp 网站建好隧道，填入 **「访问密钥」** 和 **「隧道 ID」**。公开服节点要在平台账户的「在 樱花frp 创建并导入」里勾选，手动添加这一表单没有那个开关 | 需按界面指引自行下载一次客户端放到提示的目录中 |
| **自定义 frps** | 填写自建 `frps 服务器地址`、`frps 端口`、`auth token`、`公网远程端口` 与 `本地端口` | MineDeck 自动下载 `frpc`（注意：`本地端口` 不能填 MineDeck 自己的网页端口） |

## 绑定服务器与「跟随服务器启动」 {#bind}

填写或导入隧道时，建议直接选定要服务的目标 **「绑定服务器」**，并开启 **「跟随服务器启动」**：

- 绑定的服务器开服后，隧道会自动跟着拉起；如果服务器崩溃触发自动重启，隧道会保持连接不会反复开关。
- 服务器停服超过约 5 秒且没有重新启动后，隧道才会跟着停掉。
- **获取公网地址**：隧道启动后，公网连接地址会显示在隧道卡片和服务器列表卡片上（有域名时优先显示域名），点一下即可复制发给朋友。

> [!TIP]
> 关于 **「音乐共享」** 使用的远程语音隧道（UDP 协议）：OpenFrp 的 UDP 语音隧道目前尚未在真实玩家环境完成实测；如需远程传输语音和共享音乐，请查看服务器详情 **「扩展 → 音乐共享」** 页面内的提示并按实际网络情况测试。

## 常见问题：frpc 被杀毒软件拦截或公网地址异常 {#troubleshoot}

- **凭据过短提示**：自定义 `frps` token 等凭据若短于 6 个字节，为了不在日志里反推泄露密钥，隧道日志中含该凭据的整行会被隐藏，建议换用更长的凭据。
- `frpc` 无法运行或文件消失：卡片上的中文提示只在两种情况下出现。一是 Windows 报 225 或 226（文件被拦成病毒或可能不需要的软件，226 还表示文件已被删掉）。二是 frpc 刚才还在、转眼文件没了。别的错误不会出这句。提示只说明程序认出了这两种情况，不能当成「一定是误报」。要继续用之前，先看 MineDeck 给出的下载来源，有校验值就对一下，再决定要不要到 Windows 安全中心的 **「保护历史记录」**，或到所用杀毒软件的隔离区里还原。不要只因为出现了这句提示就允许运行。
- **公网地址显示异常或启动报错**：可直接在隧道卡片查看具体失败原因和隧道日志；若出现旧版本把程序位置打进地址的现象，请升级到 `v3.2.0` 及以上稳定版。

如果仍排查不通，可前往 [端口占用、局域网连不上与 frpc 被拦](../troubleshooting/error-banner-index.md#port-in-use) 或查阅 [常见问题 FAQ](../faq/general-faq.md)。
