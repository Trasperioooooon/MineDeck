# 用已有的地图开服、换地图

这份说明写给玩家：手里有一张地图，想拿它开服，或者想把服务器正在用的地图换成它，换了以后还想换回来。

## 什么样的东西能导入

能导入的是完整的 Java 版世界：一个文件夹，里面有 `level.dat`，通常还有 `region` 之类的文件夹；或者把这样的文件夹打成的 `.zip`。下载来的冒险、空岛、跑酷地图，自己单人玩了很久的存档（在 `.minecraft\saves` 里），朋友发来的旧服世界，都是这种。压缩包里地图外面套了几层文件夹、旁边放着说明书和资源包，都没关系，MineDeck 会自己找；一个包里有好几张地图，会列出来让你挑。

这些不是完整的世界，MineDeck 会告诉你它是什么、该去哪：

- `.mcworld`，或者手机、主机、Win10/11 版的存档：这是基岩版，格式和 Java 版不同，改扩展名转不过来。
- `.schem`、`.schematic`、`.litematic`：这是建筑蓝图，要在游戏里用 WorldEdit 或 Litematica 粘贴到世界里。
- 资源包、数据包、整合包、`.mdpack` 交接包：各有自己的入口（资源包装在客户端，数据包放进世界的 `datapacks`，整合包和交接包在「新建服务器」里导入）。
- `.rar`、`.7z`、加了密码或者分卷的压缩包：先用解压软件解开，再选解出来的地图文件夹。
- 只有一个种子：种子里没有建筑和玩家进度，新建服务器时把种子填进去就行。

## 用地图开一台新服务器

在「新建服务器」里选「用已有地图开服」，先选地图，MineDeck 读出地图最后是用哪个版本存的、用过什么核心，替你预选同样的版本和合适的核心（原版地图选原版，用过 Fabric、Forge 这类模组加载器的选对应的核心）。不会自动给你换成最新版本：冒险地图往往只在作者用的那个版本上好玩。接着照常走完新建的步骤。地图会在服务器建好之前放进去，放不进去整台服务器就不建，不会出现一台看着建好了、一启动却生成随机新世界的服务器。建服没成功（比如核心没下载下来），回到「新建服务器」时第一步会问要不要接着用这张地图，不用再选一遍、再传一遍。

## 把服务器现在的地图换掉

在服务器详情里打开「地图」页，点「导入并替换当前地图」。在这台电脑上可以直接选地图文件夹，在别的设备上用网页打开的话，上传地图的 ZIP（最大 8 GB，更大的请在这台电脑上选文件夹）。

选好以后先看预览。预览里写着地图最后保存的版本和服务器的版本、找到了哪些维度、带了哪些数据包和资源包、有没有用过模组的迹象、会换掉哪些文件夹、哪些设置保持不变，以及需要你注意的地方。红色的是不能导入的原因，黄色的需要你勾选「我已了解」才能继续。地图建议改的服务器设置（比如难度、默认游戏模式）默认不勾，你勾了才改。

服务器开着时，要选「停服并导入」：MineDeck 会让服务器自己存盘退出，两分钟内没停下就放弃这次导入，什么都不换，也不会强行结束服务器。复制地图这一步服务器照常开着，可以随时取消；真正开始换地图以后会做完（或者退回）再结束。

换的时候，服务器原来的地图连同下界、末地整体移进「恢复点」，一个文件都不删；新地图换上去以后服务器保持停止，状态写的是「地图文件已导入，尚未启动检查」。启动以后进服看看是不是这张图。

服务器文件夹里多世界插件建的其他世界不会被动；服务器的核心、版本、Java、内存、端口、正版验证、模组和插件、白名单、管理员名单和其他设置都保持原样。

## 版本对不上怎么办

- 地图比服务器新（比如 26.3 的地图放进 1.21.11 的服务器）：不能导入。请新建一台和地图同版本的服务器。不要想办法把存档改成旧版本号硬开，那样会损坏地图。
- 地图比服务器旧：可以导入，但要你确认。服务器第一次启动时会把导入的这份副本升级成新格式，升级以后不能再给旧版本用（原来的地图文件不受影响）。老地图的机关、命令、数据包在新版本里不一定还好用，想原汁原味地玩，就开一台和地图同版本的服务器。
- 认不出版本、是快照（测试版）存的：要你确认，MineDeck 没法保证兼容。
- 地图用过模组：MineDeck 只能从存档里看出用过哪类加载器（Forge、NeoForge、Fabric），看不出具体是哪些模组。目标服务器的核心对不上时会提醒你；对得上时，也要你自己装好和原来一样的模组，否则模组的方块、物品、维度会丢。

## 单人存档转服务器：背包和经验接不接得上

世界、建筑、箱子里的东西都会保留。单人角色身上的背包、经验、末影箱和位置，要看主人用哪个账号进服：

- 服务器开着正版验证、主人用玩单人时的同一个正版账号进服：一般能接上，服务器会读存档里那个账号的玩家文件。
- 服务器关着正版验证（离线模式）：进服的身份是按名字算的，和正版账号不一样，接不上。想接上，可以让主人先进一次服再退出，停服后，把世界里原来那个玩家文件复制一份，改成新生成的那个文件的名字（先把新生成的那个备份一份），再启动。预览里会写明具体是哪个文件。
- 服务器在代理（Velocity、BungeeCord）后面：身份由代理决定，代理开着正版验证时一般能接上。

首版不会自动改写玩家文件。地图带的其他玩家的进度文件也原样保留，同一个账号进服会接上自己的进度。

## 冒险地图要注意的

- 地图带的数据包会在服务器加载世界时生效，导入本身不运行任何东西。
- 地图带的资源包（`resources.zip`）服务器不会自动发给玩家：要大家看到正确的材质，请把它放到大家都能下载的地址，在设置里填资源包地址，或者让每个人自己装。
- 地图用命令方块的，要确认服务器允许命令方块运行。老版本在 `server.properties` 的 `enable-command-block`，新版本改成了游戏规则（1.21.11 起叫 `command_blocks_work`）。MineDeck 不会替你打开。
- 说明书（地图包里的 README 之类）可以在预览里看，里面写的推荐版本、人数、设置值得看一眼。

## 换回原来的地图

「地图」页下面列着每次导入留下的恢复点。点「恢复导入前的地图」（服务器要停着），原来的地图会搬回原位，导入时改过的设置也会改回去（之后你自己又改过的不动）。导入的那张图，包括启动以后玩出来的进度，不会删，留在旁边；确认不要了，可以点「删除恢复点」把它和旧地图的副本一起删掉（服务器同样要停着），删了就不能再换回。

同一台服务器换过好几次地图，就有好几个恢复点。换回要从最近的一次开始，一次一次往前：只有最近那个恢复点上有「恢复导入前的地图」按钮，换回它以后，前一个恢复点的按钮才会出来。这样每一步搬回来的都是那时候真正在用的地图，中间哪一张都不会丢。

用「用已有地图开服」建的服务器，第一张地图之前没有别的世界，它的恢复点没有可以换回的东西，只能删。

恢复点不会被定时备份挤掉，会一直留到你手动删除；页面上写着每个恢复点占了多大地方。

## 出了问题

- 「这份存档来自更新版本，当前服务器不能安全读取」：见上面「版本对不上怎么办」。
- 「旧地图……没有替换任何文件」：导入在开始换之前就停下了，服务器还是原来的地图。
- 「导入中断，已恢复到导入前的世界」：换到一半出了问题，已经自动退回，服务器还是原来的地图。
- 「恢复未完成，服务器已暂停启动」：自动退回也没成功（通常是有别的程序占着世界文件夹，比如在 MineDeck 外面手动启动的服务器、打开着的资源管理器或者杀毒软件）。所有文件都还在，「地图」页里写着具体的文件夹。关掉占用的程序以后点「重试恢复」。
- 换地图时 MineDeck 被关掉或者电脑断电：下次打开 MineDeck，它会先把这台服务器恢复到换图之前，恢复好之前这台服务器不能启动。
- 恢复点标着「记录读不出来」：MineDeck 不知道那次换地图走到了哪一步，为了不在半成品的世界上开服，这台服务器暂停启动。页面上写着那次的文件夹，里面的世界一个都没删。这种情况很少见（通常是磁盘出错，或者有人动过那个文件夹），需要人去看：把文件夹里的世界搬回服务器文件夹以后，把这个文件夹移出 `.minedeck`，再点「重试恢复」。拿不准的话先别动，找懂的人帮忙。

## 几种会被直接拦下的情况

选的文件夹里世界太多（超过 256 个）时，MineDeck 不会逐个去认，而是让你直接选其中一个世界的文件夹，也就是里面有 level.dat 的那一层。比如想导入单人存档，就选 `.minecraft\saves` 下面具体的那一个存档，不要选整个 `saves`。

压缩包里的文件多得不正常，或者里面记的文件大小加起来大得离谱，也会整份拦下：这样的包不像一张地图，多半是下载的时候坏了，或者被人动过手脚。

磁盘空间不够时不会开始导入。做预览时会查一次；从预览到点确认之间要是空间被别的东西占掉了，开始复制之前还会再查一遍，复制大文件的过程中也会隔一段看一次，不够就停下，原来的地图不动。

有的盘查不出还剩多少空间（少数网络盘、特殊的挂载方式）。这时候预览里会多出一条要你确认的事项，写着这张地图要占多大。请自己看一眼放不放得下，勾上确认再导入；不勾是导入不了的。如果预览时能查到、执行时才查不到，任务会停止。上传缓存所在的磁盘查不到余量时也不会收下上传文件。

地图、上传、备份和解包等需要往同一个磁盘大量写文件时，会排队进行；任务日志会说明正在等待。不同磁盘可以同时进行。地图导入和新建任务在可取消阶段可以从任务页取消，清理完成后才结束。

服务器正在备份、正在保存设置或者正在改配置文件时点导入，MineDeck 会让你等它做完，不会为了导入去停服务器。反过来，换地图的过程中，备份、保存设置、改配置文件、删除服务器也都要等。

服务器文件夹里的 `server.properties` 或决定世界位置的配置文件被别的程序占着、读不出来时，导入、换回和备份都会停下并告诉你原因。MineDeck 要靠这个文件知道世界文件夹叫什么名字，读不出来的时候不会去猜。关掉占用它的程序（常见的是编辑器或者杀毒软件）再试。

检测一个很大的压缩包时把页面关掉，检测会停下来，上传的那份文件会在最后一个使用者释放后删除，不会删掉另一个检测或任务仍在使用的文件；一时删不掉的会留给后续清理。只是在页面上退出了导入的窗口、页面还开着的话，这一次检测会做完，做完以后同样把上传的文件删掉。

## 换地图没走完的时候

如果一次导入或者换回出了岔子，自动退回也没成功，服务器会暂停启动，「地图」页上会出现「重试恢复」。这时候请先点它，把这一次处理完。若暂存区的数据无法确认为来源副本，MineDeck 会保留它，并在地图页列出占用容量；删除恢复点之前请先查看这些文件，保留自己还需要的内容。在处理完之前，别的恢复点都不能换回、也不能删：那些文件夹里可能正放着要靠它们救回来的地图。

点了「取消导入」并且提示取消成功，地图就一定没有被换。如果提示「已经不能取消了」，说明已经开始换图，等它做完或者自动退回就好。

整合包初始化全部完成以前不会出现在服务器列表中；待决补装不接受世界文件和 server.properties，请分别使用地图导入和设置入口。热备过程中服务器若重启，这次备份会作废，避免把不一致的存档当成完整备份。
