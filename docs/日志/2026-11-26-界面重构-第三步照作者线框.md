# 界面重构：第三步照作者的线框画成 C

接着 `2026-11-26-界面重构-第三步两种排法.md`。只动了草图 `design-system/redesign/wizard.html` 和计划书，程序一行没动，活是主会话自己做的。

## 要做什么

作者看了 A、B 两种排法以后，贴了一张自己画的线框，说「你按照这个来设计一版看看」。线框是一整块：上面一条像游戏里多人列表那样的身份行（图标跨两行，名称、介绍上下两行，右边文件夹名和端口），中间「运行内存」带图例、格子、数字框和快捷预设，下面「游戏规则」两个分段选并排、允许飞行一行带说明，EULA 是面板下面的一个勾选框。

## 做了什么

照着画成第三种排法 C「照草图」，现在打开第三步默认就是它，右上角的开关里 A、B 还能切过去比。面板里三段用细线隔开。身份行的名称、介绍、端口做成点了就能改的字，平时不画框，悬停出底色，点进去才出框，这样看上去就是朋友在多人列表里会看到的那一条。运行内存的图例跟着分配实时变，剩余是可用减分配，分配超过可用时这一项变成红的「超出」，快捷预设点了直接改分配，选中的那个高亮。允许飞行这次是开关，说明照线框写在名字下面。EULA 改成面板下面的勾选框，没勾时照旧拦下一步、标红。

栏的内边距改成 20，图标离栏的角 20，不小于栏的圆角 18，按规矩图标的圆角就不受同心限制，不用为了贴角把图标做成方的。

有两处照线框画了、但和计划书开头的规矩不一样，留给作者定：图例里的「分配 4G」和数字框里的 4096 是同一个数说了两遍；允许飞行的说明写在了页面上。另外线框里 EULA 右边画了「创建服务器」，可向导第三步后面还有一步「让朋友连进来」，所以这一步右下角仍是「下一步」；要是想在这一步就创建，得再定第四步怎么办。

## 验证了什么

1280×800 下原版、Paper、NeoForge、Velocity 都量过，面板 473 高，EULA 那一行到 681，不滚动；A、B 切过去也还正常。快捷预设、超过可用、端口填错、名称空着、EULA 没勾、允许飞行开关都点过，拦下一步的几种都拦住了。新加的报错监听没收到报错。

途中预览窗口有一阵被系统当成看不见的页面，动画被压慢，连点两下「下一步」只走了一步，截图也是旧的。量数据改用脚本直接画到第三步，最后一次截图是在窗口看得见时截的。

## 没做完或没验证的

等作者在 C、A、B 里挑一种，挑定以后拿掉另外两种和右上角的开关。上面说的两处和规矩不一样的地方、要不要在这一步就创建，也等作者说。

## 留给下一位的

先读计划书开头「每画一页都要对一遍的规矩」。草图用 `python design-system/redesign/serve.py` 打开，按 1280×800 看，第三步右上角切换排法，地址加 `?s3=a` 或 `?s3=b` 打开另外两种。决定不等于开工，动程序之前先问作者。
