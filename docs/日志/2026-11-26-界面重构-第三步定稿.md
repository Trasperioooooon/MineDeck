# 界面重构：第三步定稿（顶上照 C，下面照 A 分两栏）

接着 `2026-11-26-界面重构-第三步照作者线框.md`。只动了草图 `design-system/redesign/wizard.html` 和计划书，程序一行没动，活是主会话自己做的。

## 要做什么

作者比过 A、B、C 三种排法，截了 C 的顶部和内存、A 的两栏，说：「我知道怎么设计了，顶部按照 C 来设计，下方像 A 设计成左右两栏，左边栏是设置内存、存储位置、端口号，右侧是 A 的右边栏设计。」中间作者还问了服务器介绍能写多长，主会话查了资料答了（游戏没有明确的字数上限，Wiki 上只有一句超过 59 个字符可能出错，没写版本；列表里最多显示两行），这件事没改草图。

## 做了什么

照作者说的拼成一版，A、B、C 三种和右上角的开关都拿掉了，代码里只剩这一种。顶上一块横跨两栏，是 C 那条像多人列表的身份行：图标跨两行，名称和服务器介绍点了就能改。原来在这一行右边的文件夹名和端口挪到了下面的左栏。

下面两栏各三行，每行一样高，左右三行对齐。左栏「服务器」依次是运行内存（标题右边图例，格子加数字框）、快捷预设、存放位置和端口。快捷预设原来在 C 里是一排小胶囊，这次做成和右栏一样的分段选，好让左右三行是同一种东西；分配正好是哪一档就亮哪一档，不在档上就都不亮。存放位置做成和输入框一样的框，点了换位置。端口和上面的数字框一样宽、对齐。右栏照 A：难度、默认游戏模式、允许飞行。EULA 照 C，是面板下面的勾选框。三块的左右内边距统一成 20，图标、栏里的字、EULA 的勾选框左边在同一条线上。

## 验证了什么

1280×800 下原版、Paper、NeoForge、Velocity 都量过，不滚动，面板 422 高，EULA 那行到 630。用脚本量了左边线（都在 128）、竖缝（470|484 上下对齐）、左右三行的高低（框都在 366、446、526）。快捷预设点了选中块滑过去，打一个不在档上的数时都不亮，分配超过可用时图例出红的「超出」，端口填错、名称空着、EULA 没勾都拦住了，允许飞行的分段选正常。真点「下一步」从第一步走到这一步也正常。新加的报错监听没收到报错。

## 没做完或没验证的

图例里「分配 4G」和数字框的 4096 说了两遍、这一步右下角是「下一步」不是线框里的「创建服务器」，这两处上一次跟作者说过，作者这次没提，先照现在这样。换服务器图标、存放位置真的去选文件夹，草图里都只是样子。
