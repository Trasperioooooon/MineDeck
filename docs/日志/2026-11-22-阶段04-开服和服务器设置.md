- **A04（新建与导入时的端口预查三处漏洞）**：
  1. **识别 Windows 系统保留端口段**：在 `internal/inst/portcheck.go`、`portcheck_windows.go`、`portcheck_unix.go` 新增 `parseExcludedPortRanges`、`loadExcludedPorts` 与 `IsPortReserved`。Windows 上用 `procutil.HideWindow` 不弹窗调用 `netsh interface ipv4/ipv6 show excludedportrange protocol=tcp`（3 秒超时），解析器只认两列起止端口号（及可选第 3 列 `*`），不依赖中英文表头，结果缓存 1 分钟，失败时退回无保留段。`DefaultPortSkipping` 在 `busy != nil` 时一并跳过保留段；`checkBindPort` 命中保留段时明确报「在系统保留的端口范围里（Hyper-V、WSL 等保留），换个端口试试」；`internal/web/assistant.go` 的 `GET /api/ports/suggest` 在起始端口落入保留段时返回 `fromBusy: true, fromReserved: true`。
  2. **提交新建、导入表单时复查端口**：`Manager.CheckFormPort` 读取实时 `PortsInUse`（允许已停止的服务器共用端口，只拦正在运行或启停中的服务器）、系统 TCP 监听表（Windows 调 `iphlpapi.dll` 的 `GetExtendedTcpTable`，macOS 调 `lsof`，不试绑通配地址，不触发防火墙弹窗）与 `IsPortReserved`。`internal/web/instances.go` 在 `handleCreateInstance` 与 `handleImportModpack` 提交时先调 `CheckFormPort`（导入在落盘临时压缩包前就拦截），被占或保留时返回 HTTP 409 与 `portBusy`（含空闲建议端口），前端 `wirePortField` 原地给出提示与「改成 N」按钮，不建服务器。
