# 界面重构：夜里各页第一稿，和三处程序改动（2026-11-27 夜里到清晨）

## 要做什么

作者 11-27 夜里睡前说（原话）：

> 不改程序，你继续委派子代理，再做剩下的其他的几个页面，我先睡觉去了。本地起一个每个页面对应要我敲定的、你替我定的的记录文档，我醒后我们逐页进行审查。这个服务器详情页如果画完了，就继续画下一个页面以及它的子页面，我让你停下的时候会跟你说的。每次最多委派子代理数量不超过3个，画界面的子代理每次画的页面不超过3个。同时你再排子代理去增加设置minedeck根目录为windows白名单，解决用户反馈的"定时任务那里可以搞点新功能吗，想一键设置1个小时存一次档，1个小时扫一次地，再搞个任务分类文件夹，把扫地的指令单独放一个，存档的单独放一个。"、"每次返回到备份的存档，会把服务器设置重置，正版验证、最大视距这些，这个算bug吗"、"可以设置自动多少时间一次存档"这些需求和反馈。

前面一句「不改程序」指的是界面重构不动程序；后面点名的三件（白名单、定时任务、还原备份）是要改程序的，各在自己的分支上做、开 PR，合不合等作者。

## 做了什么

**记录文档。**新开了 `docs/计划/2026-11-27-界面重构-待作者审.md`，按页面排，每页「要你敲定的」「我替你定的」两块，夜里每画完一页、每改完一处程序就往里加，作者醒来照它逐页审。这份日志不重抄那些条目，只记过程。

**草图（全在 `design-system/redesign/`，程序一行没动）。**

- 服务器详情页剩下的标签都画了第一稿：世界与备份（备份、换地图）、插件 / 模组、定时任务、设置（常用、启动与内存、全部配置）、扩展（游戏内 AI、AI 伙伴、音乐共享）。各标签一份 `detail-<标签>.js / .css`。定时任务照夜里程序分支上的新做法画（每天 / 每隔、文件夹、两颗预设）。几页带多字段表单的，保存条都放成内容面板里最下面一条（胶囊压不到），这个做法后来全局设置里也照用。
- 全局设置页（`settings.html`）：外壳主会话搭（分类在左边，同详情页；不写页头），十个分类（外观、下载与网络、存储位置、Java 运行时、内网穿透、手机远程管理、通知与集成、AI（可选）、启动与托盘、更新与关于）分四批派子代理画，各一份 `settings-<分类>.js / .css`。首页、详情页、工具箱胶囊里的「设置」接到这页。
- 计划书里「要作者一页一页看的」另外三页也画了第一稿：后台任务进度页（`task.html`，九种任务、八种状态，版面同向导）、第一次打开的引导和用户协议（`welcome.html`，协议正文和程序逐字比对过）、AI 助手面板（`assistant.html`，抽屉和整页两种）。
- 最后派子代理把各页之间的入口接上：向导「创建服务器」、导入四条路、首页任务浮层、详情页换 Java / 装清单 / 导出 → 进度页，各页胶囊里 AI 那颗 → AI 助手。
- 主会话自己改的几处：联机页删除确认框的遮罩和投影没定义（外壳里没有 `--scrim`、`--elev-4`，照共用件页定在遮罩上）；全局设置外壳关不掉胶囊里 AI 那颗（`.cap a` 的 display 盖掉了 hidden）；定时任务和备份页、内网穿透和联机页、世界与备份和常用这几处示例数据对齐；两个外壳的草图切换条说明改成「各标签 / 各分类第一稿」。

**三处程序改动（各在自己的分支，开了 PR，都没合）。**

- 还原备份以后设置被重置：用 MineDeck 自己做的备份复现不了（备份从 v2.0.0 起就只装世界）。修的是两处确实会出事的地方：放进备份文件夹的整包 zip 以前会整包解进服务器文件夹、把 server.properties 这些都盖回去；备份以后改过世界名的，以前会还原到旧名字下面。现在还原只从包里认出世界、放进现在的世界名下面。PR [Trasperioooooon/MineDeck#34](https://github.com/Trasperioooooon/MineDeck/pull/34)，分支 `fix/restore-world-only`，提交 5c4b3b0、1b5a898、8b5fcef、c3d850c。
- 定时任务：每天 / 每隔两种、任务文件夹、一键「每小时存档」「每小时扫地」；配置多 `every`、`group` 两个字段，老配置不变。PR [Trasperioooooon/MineDeck#36](https://github.com/Trasperioooooon/MineDeck/pull/36)，分支 `feat/schedule-every-groups`，提交 8f7003d、5326044、a6e50d5、b39cffd、5b6444c、0112620。
- 把程序数据文件夹加进 Windows 安全中心（Defender）排除项（主会话把「Windows 白名单」理解成这个，不是防火墙）：设置 → 存储位置一行，点了弹 UAC、跑 Add-MpPreference，能撤销。草稿 PR [Trasperioooooon/MineDeck#35](https://github.com/Trasperioooooon/MineDeck/pull/35)，分支 `feat/defender-exclusion`，提交 444c2dd、3fd1913、aadf7e9、150da6f（最后一个是主会话改的）。真机没跑过，所以是草稿。

每处改动都经过：子代理写 → 主会话读 diff、自己跑测试 → Gemini 4 Argon 跨家族只读复审 → 交回原子代理照改（主会话核过哪些要改）→ 主会话再跑测试，有的走了两轮复审。三个 PR 两两之间、和 main 之间都没有冲突。

## 验证了什么

- 草图：每一页主会话自己用无头浏览器扫过（1280×800，深浅两色，几种核心和状态）：页面本身不滚、没有页面报错、没有空图标、没有剩下的 `i[data-ic]`，截图裁出内容面板看过。子代理各自跑的更细（模拟操作、只换变了的那一处、量尺寸），结果写在各自的汇报里，主会话抽看了截图。
- 还原备份：主会话在 Windows 上跑 `go build ./...`、`go vet ./internal/inst/`、`go test ./internal/inst/`（整个包）、`go test ./internal/worldimport/`，每轮都过。子代理每条修复都把产品代码换回上一轮确认新测试会失败。
- 定时任务：主会话跑 `internal/inst`、`internal/ops` 整个包的测试，和 tools/ui-dev 里定时任务、无障碍、手机布局 16 条界面测试，都过。子代理做了八种调度的反向验证。
- 白名单：主会话 Windows、Mac 两边 `go build ./...`，`go vet`，`cmd/minedeck`、`internal/app`、`internal/web` 整个包的测试，存储位置的 3 条界面测试，都过。有一个测试会不提权地跑拼出来的 PowerShell 脚本（Defender 命令全换成同名假函数），主会话看过它怎么起进程、确认起不了提权、真命令不提权也改不了设置以后才跑。第二轮复审的两处是主会话改的，新测试换回旧代码会失败。从头到尾没有真的跑过 Add-MpPreference、Remove-MpPreference、Set-MpPreference，没弹过 UAC。
- 三个 PR 合在一起（临时检出，跑完删了）：Windows、Mac 两边编过，`go vet ./...` 干净，`go test ./...` 46 个包都过。
