# 界面重构：第四步局域网和自建 frps 并成一页

接着 `2026-11-26-界面重构-第四步拿掉提醒和筛选过渡.md`。只动了草图 `design-system/redesign/wizard.html`、计划书和现状，程序一行没动，活是主会话自己做的。

## 作者要改的

作者截了第四步「局域网」和「自建 frps」两页，问能不能合并：两页都很空，一页只有一个地址，一页只有四个框，下面大半块空着。

## 做了什么

顶上的卡片从四张变成三张，第一张叫「局域网 / 自建 frps」，第二行把作者原来给两张卡定的话接起来，「同一 Wi-Fi / 连接自有服务端」。点它，下面是左右两块一样高的面板。左边是局域网：小标题、「朋友填这个地址」和一行大字的地址，旁边一个复制。右边是自建 frps：开关在字的左边，和底部「谁能进」的开关一个样子，默认关着；关着时四个框淡一些，点那一块任何地方都会打开，打开后光标直接落在服务器地址里。打开了却没填服务器地址，点「创建服务器」会被拦下，框标红、晃一下；关着就不拦。代理端的端口要第一次启动才知道，所以自建 frps 和另外两个穿透一样灰着打不开。

第一版主会话自己在两块的标题右边加了「同一 Wi-Fi 的朋友」「外地的朋友也能进」，卡片第二行写了「不经穿透平台」，又把「连接自有服务端」删了。参谋提醒这正是作者前两轮一直在删的那类说明，而且丢了作者定过的字，于是改回只用作者的原话。两块原来包在一层里，换卡时整页当一块挪；拆开以后，换卡时两块一前一后进来，和别的页一样。圆角从 16 改成 12，和上面卡片的底色一致。

## 还空着的地方

合并以后两块里上下还有空。原因是面板高度给节点面板定死在 540（换卡时面板不跳），而这一页的东西只要不到 200 高。要更满有两条路：这一页让面板变矮，代价是换卡时整块会跳；或者往里放东西。主会话想到两样可以放的，没有画，等作者说：左边列出本机的几个地址（家里的 Wi-Fi，还有 Radmin、ZeroTier 这类虚拟局域网，程序已经拿得到全部 IP，详情页头也能换，只差网卡的名字），点了换大字那个；右边开着时把朋友要填的公网地址拼出来给人复制。

## 验证了什么

1280×800 下深色、浅色都看了。用真鼠标点了开关，开关变开、四个框不淡了、光标在服务器地址；空着点「创建服务器」被拦下、框标红；再关上，红框消掉、不再拦；关着时点那块空白处会打开。填了服务器地址就放行。代理端（Velocity）下开关画成关着、那块点不开、局域网地址写「端口启动后才知道」、不拦下一步。从 OpenFrp 换回这张卡时，两块的不透明度先后是 0.40 和 0.05、0.75 和 0.56，一前一后进来。控制台只有一条 404，是主会话自己开错了一次地址，页面本身的资源都是 200。
