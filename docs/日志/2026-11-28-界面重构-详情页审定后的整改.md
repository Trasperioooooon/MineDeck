# 2026-11-28 界面重构：详情页审定后的整改

## 要做什么

作者审完服务器详情页（见 `2026-11-28-界面重构-作者审完服务器详情页`）以后，又逐节补了自己对各节「要你敲定的」的决定，原话摘几句：

- 玩家：「踢人、封禁需要有二级弹窗确认；在线的人那一栏需要有直接封禁的按钮；栏名叫「管理员 OP」不变。」
- 联机：「新建隧道「跟随服务器启动」默认关。」
- 备份：「需要加。」（下载备份和自动备份开关两样，作者确认主会话的理解对。）
- 换地图：「可以删掉一处，你来定具体删掉哪一处；没画的什么时候画？」
- 插件 / 模组：「要增加更新插件 / 模组，同时更新了一个，还要自动更新其他可能关联的mod」；空清单那句不留；不换样本；没画的几种也要画。
- 定时任务：「改了先进草稿、点保存才生效，如果用户改了，但是想刷新页面或者切出去，弹窗提醒是否保存改动——所有有关修改保存的都这么做」；不加「只执行一次」；不改步进；「每隔」的档位行；代理端的备份灰掉，程序要跟着改；文件夹「要有折叠、改名、整个删除」。
- 常用、启动与内存：内存照原方案；指定构建要做；白名单两处都留；「要点步进中间的数字就地打字（关于步进的，你觉得可以这样处理的都这样处理）」；-Xmx 的提示改成「请在左侧设置内存」一类。
- 全部配置：「行。」
- 扩展：「需要点保存才生效；留在页面上；留哪一处你定；要只标没在白名单里的；淡淡的小字留着；不用改示例数据了。」

作者还问了几件事：页头常驻提示和游戏内 AI 问答记录里的字为什么还是口语（「要不再跑一轮，我需要全都改掉」）；点「白名单」几个字也会切换开关是不是 bug。后一件主会话答了不是 bug、是开关连名字做成一颗按钮，作者定了「只点开关才切换」。

## 做了什么

全是草图（`design-system/redesign/`）、计划文档和一个不进 git 的文案审查脚本，程序一行没动。各页作者定的都写进了 `docs/计划/2026-11-27-界面重构-待作者审.md` 对应各节，每条后面标「作者 11-28 定」，改完的写了怎么画的和替作者定的（可否决）。

**共用件（`kit.js`、`kit.css`）。** 加了四样，各页以后都调这一份，规范第九节记上了：

- 共用确认框 `KIT.confirm`，样子同共用件页；以前各页各有一份一样的。
- 离开前拦未保存：页面在登记的那一份上带 `dirty()`、`save()`、`discard()`，外壳在换标签、换子页、换设置分类、F5 和 Ctrl+R、点胶囊跳页、脚本跳页之前先问「有未保存的修改」（取消 / 不保存 / 保存）；关窗口交给浏览器的 beforeunload。详情页和设置页的外壳都接上了，页面里用脚本跳页走 `ctx.go`。
- 步进中间的数字就地打字 `KIT.numEdit`：填错整个框描危险色、马上提示范围和单位。
- 开关只认开关本身：在捕获阶段拦掉点在名字、说明上的点击，覆盖 role="switch" 的按钮、向导一类的 `.tg`、EULA 整条；键盘照常能切。各页整行开关的悬停底色一并去掉了。

**各页。**

- 玩家（主会话做）：踢出、封禁先确认，在线一栏加封禁，封禁名单里打名字也确认。
- 联机（主会话做）：新建的游戏隧道、语音隧道默认不跟随服务器启动。程序现在的向导不建隧道，向导第四步建隧道是这次新加的；向导和导入第四步里那几句「并随服务器一同启动」去掉了。
- 世界与备份（子代理画、主会话审）：
  - 下载备份、自动备份开关。主会话审时把默认改成每天 04:00（子代理画的每小时一份会在 10 小时内把手动备份挤掉），关开关要拿掉的不止它自己加的那一条时先确认。
  - 换地图删掉第五步「完成」，后台任务页的换地图进度跟着改成四步。
  - 补画读取失败、任务出错、正在更换、需手动处理、从别的设备打开五种状态。随交接包带来的地图画在备份页顶上那句里。
- 插件 / 模组（子代理画、主会话审）：
  - 更新，更新一个时把关联的一起更新。
  - 空清单只留一句淡字。
  - 补画新建时选择的尚未安装（A31）和前置检查的可选前置、冲突、未找到。冲突和新版本号是编的，可选前置是从 Modrinth 公开接口查的真依赖。
- 定时任务、常用、启动与内存、全部配置（子代理画、主会话审）：
  - 文件夹能收起、重命名、整个删除，都进草稿。
  - 四页接上离开前拦。
  - 步进都能打字，内存照拖动的规矩对齐 0.5 GB。
  - 启动与内存有一行 JVM 参数标红时保存被拦下。
  - -Xmx 提示改成「请在左侧设置内存」。
- 扩展（子代理画、主会话审）：
  - 游戏内 AI、AI 伙伴两段设置改成先进草稿、点保存才生效。哪些进保存是主会话照程序定的：总开关、伙伴的动作、音乐整页照旧即时。
  - 白名单小标签只标「非白名单」。
  - 音乐页「重启服务器后生效」只常显检查清单那一行。
  - 步进都能打字。
- 全局设置和向导（子代理画、主会话审）：
  - 存储位置、更新与关于、通知与集成、手机远程管理、AI、内网穿透这几类里有草稿的项接上离开前拦。
  - 保留份数、向导和导入第三步的内存能打字。
  - 内存不在档位上时点加减往那个方向落到最近一档，原来是四舍五入。

**文案。** 页头常驻提示四条、报错横幅四种示例、控制台那行端口被占照 Gemini 改成书面口吻。当时 Gemini 因为「程序原话」标了需作者定而跳过；横幅四种 Gemini 只给了方向，句子是主会话补的。问答记录里引用的命令模板旧名字跟着 Gemini 的新名字改了。游戏内 AI 记录里别的口语没改：Gemini 把示例数据整块跳过了，要等第三轮。
