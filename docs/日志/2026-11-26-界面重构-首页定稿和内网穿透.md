# 2026-11-26 界面重构：首页基本定稿，内网穿透改成跟着服务器走

接着 `2026-11-26-界面重构-头像定稿和叫停.md`。这一段全是草图和记录，程序代码一行没动。每一步的细节和作者原话都在 `docs/计划/2026-11-25-界面重构.md` 的「窗口尺寸基准」「首页」「内网穿透跟着服务器走」三节，这里只记经过。

## 要做什么

作者一处一处提意见，主会话出草图。按顺序：顶上「服务器」大标题、一行统计和最右边的搜索框「会不会太突兀了，有没有更好的呈现方式？」；随后自己给了主意「像 minecraft 一样的文字设计，页面上半部分写 MineDeck，然后下面紧跟一条概览条」，又调了几轮大小和留白，最后要字标「再缩小一档或者两档，让整个页面呈现梯形」。收藏超过三台时「能不能设计这样的交互——局部的左右滑动？然后左右两边的渐变虚化？」，接着「我不想有吸附的这个效果，无极滑动会更好一点」，又发现鼠标一移上去就是拖动的手形；「其他」也要「最多显示两行，改成同样的局部无极平移滑动，以竖着的方式排列」。作者问作为独立的应用程序最小页面和默认页面多大，要主会话规定基准，「第一次打开时，这个基准下，我不想有上下滚动，然后底部的导航栏也不能叠加在其他服务器小卡片上方」。底部导航「可以直接放图标，不用文字了」。内网穿透：「我觉得我们的内网穿透逻辑很奇怪……内网穿透的每个隧道也应该是跟着对应的服务器，我们这里单独开一个页面，感觉很奇怪」，最后定下「底部导航栏完全不需要单独的『内网穿透』了，放到设置里面连接账户其实就可以了……这一块就这么定下来」。

## 做了什么

页头先画了三种（A 一句话当标题、B 统计和搜索装进概览条、C 拿掉页头把统计和搜索放进标题栏，对比页 `design-system/redesign/head-options.html`，`d907ac0`），再按作者的主意画 D：自己一格一格排的块状像素字标 MINEDECK（`design-system/redesign/wordmark.js`，往下挤出两格、深色描边，MINE 草绿、DECK 白；不照 Minecraft 的标志描，免得像官方），下面紧跟概览条（`22b4f44`）。D 改过两版（字放大、留白加大、概览条不铺满，`9b61640`），作者说可以，首页草图默认就是 D（`73a3cc4`）；最后按作者的梯形主意把字标缩到每格 5 像素，三档可切，作者选了最小的（`ef237f7`、`a4e91cc`）。

收藏超过三台时上面一排变成能左右滑的一条：往页边伸 40 像素，渐隐只落在露出来的邻卡上，悬停出箭头，可拖动（`73a3cc4`）；去掉吸附、加了松手后的惯性（`6167748`）；悬停不再是手形，真拖起来才变，拖完松手不算点卡片（`6394de1`）。「其他」改成最多两行、按列排（上 1 下 2、上 3 下 4），多了同样左右滑，和收藏那一排共用一套滑动代码，假数据加到 16 台（`db6b3d7`、`ace5949`）。

窗口尺寸：程序现在最小 1024×576（16:9），第一次打开 1280×850（约 3:2，`cmd/minedeck/webview_windows.go`）。主会话定的基准是 1280×800（16:10）：1920×1080 的屏开 125% 缩放时工作区只有约 816 高，850 放不下。基准下所有页面第一次打开不滚动，胶囊和内容之间至少留 16。首页草图照这个收紧了间距、标题栏改成和真程序一样的 40，顺带发现「其他」小块的同心圆角一直被一条写在后面的旧样式盖着，改回外圆角 20、内边距 8（`773fe40`）。

底部胶囊只放图标，字收进悬停提示（`58522f4`）。内网穿透先画了提议页 `design-system/redesign/tunnels.html`：向导最后一步「让朋友连进来」、服务器详情一个「联机」标签、平台账户收进设置（`58522f4`）。作者问「导入」是什么，又说登录了账户还要去网页建隧道、回来填 ID 很奇怪；查代码发现连上账户后直接在平台上建隧道的能力 v3.2.0-beta.1 起就有，只是藏在穿透页最下面，最显眼的「添加隧道」走的是手填表单。草图改成连上账户就一键「新建隧道」（名字、节点、本地端口替人填好），平台上已有的叫「用已有的」排在下面；语音隧道只在装了 Simple Voice Chat 的服务器上出现（`afc6dde`）。作者定下方向后，胶囊里去掉「内网穿透」，设置里那一块放平台账户和「全部隧道」总览（本次提交）。

## 谁做的

主会话：Claude Code 桌面端，Claude Opus 5.5（会话环境给出的模型名），全部自己做，没有委派。

## 验证了什么

草图都在内置浏览器里看过、控制台没有报错。按 1280×800 量过首页：整页高 800、不滚动，「其他」第二行底边 714、胶囊上沿 730；三档字标都不滚动。滑动用模拟拖动测过：慢拖 150 像素停在 150（不吸附），快甩松手后继续滑一段停下；箭头一次挪一张或一列；换排序方式两排都回到最左；悬停时光标是普通箭头、拖起来才变抓手；拖完松手那一下的点击被拦下。

## 没做完或没验证的

首页还剩两处没定：一台服务器都没有时长什么样；向导的「下一步」条、设置的保存条也在底部，胶囊让开还是合成一条。程序都没改，等全部页面定完再一起改，其中这一段新定下的要改程序的有：第一次打开的窗口改成 1280×800 并收到屏幕工作区以内（现在超出工作区不会收）；内网穿透整个挪到服务器身上和设置里；首页、头像、胶囊照草图。

## 留给下一位的

作者的节奏是一页一页在草图上定，决定不等于开工，动程序之前先问（见计划文件开头和上一份日志）。草图用 `python design-system/redesign/serve.py` 打开，首页是 `home.html`（左下角能切字标大小、收藏超过三台、配色），内网穿透是 `tunnels.html`，页头的几种写法在 `head-options.html`。往后看草图都按 1280×800。
