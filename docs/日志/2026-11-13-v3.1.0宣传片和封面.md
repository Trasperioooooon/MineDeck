## 2026-11-13 v3.1.0 宣传片和封面（Claude 写）

作者要一支九十秒左右的宣传片，讲 v3.1.0 的主要新功能，配乐自己在 Gemini 里生成，封面要横竖两张。先出了方案和提示词（`tools/promo/video-v3.1/方案.md`、`配乐提示词.md`、`封面.md`），作者生成了配乐和两张封面底图，让我自己选做法、直接开做，文字参照「MineDeck开服工具 V3.1.0抢先预览」。

做法沿用 v3.0 那支（`tools/promo/video/`）：仿真后端上拍真实界面，`renderAt(t)` 逐帧渲染，ffmpeg 编码、合配乐。没有用 Remotion：现成这套已经跑通过，换一套要装一整串依赖，得不到更多东西。新目录是 `tools/promo/video-v3.1/`，v3.0 那支原样留着。双击目录里的 `make-video.bat` 能从头重出（约 15 分钟），各脚本的用法、节拍和段落、改了哪些仿真数据，都写在那个目录的 `README.md`。

配乐 Morning on the Balcony 量出来是 123.99 BPM（提示词写的 120，和上次一样偏快），速度很稳，结构是 7 小节前奏、16 小节律动、4 小节安静的过渡、16 小节主段落、收尾。这次没有像上次那样把曲子放慢去迁就画面，而是画面按曲子的实际速度和段落排：从曲子第 3 小节截起，图标落在低音进来那一下，第一章跟着鼓进来，「自己的服不想开了？」落在安静的那 4 小节，交接包的动画落在主段落。成片 84 秒，比方案的 90 秒短一点，是曲子的长度决定的。量曲子的脚本是 `analyze-music.py`，以后换曲子先跑它。它原先按低频起音找小节的第一拍，在这首曲子上差了一拍，当时是另外看和弦在哪个拍位上换、段落从哪一拍起才定下来的；现在这套判断已经写进脚本，跑出来就是片子用的 1.372 秒，README 的「配乐和节拍」有经过。

成品都在 `tools/promo/video-v3.1/out/`（不进 git）：`MineDeck-v3.1-promo-1440p60.mp4`、`MineDeck-v3.1-promo-1080p60.mp4`、`封面-16x9.png`、`封面-9x16.png`，另有联系表 `contact-sheet.png`。配乐和封面底图在 `music/`、`cover/` 里，进仓库，重出要用。

替作者拿的主意，都可以改：只做了横版视频（竖版每一镜都要重新构图）；片尾加了一行「非 Minecraft 官方产品，与 Mojang、微软、网易无关」；砍了方案里「CurseForge 文件各归各位」那一小节（律动段只有 16 小节）；类别筛选没单独拍，因为仿真后端筛出来的模组名是占位的「Hot Mod 005」。「补前置」那一镜没用仿真后端写死的「Architectury API 是 JEI 的前置」（现实里 JEI 不要前置，懂模组的人看得出来），换成在 Modrinth 上核对过的真实的一对：REI 在 Forge 1.20.1 上必装 Cloth Config API 和 Architectury API；后面安装任务的步骤和日志也照真后端的写法改了。封面写「V3.1.0 抢先预览」（照作者给的字），片子开场的标签写「v3.1.0 正式版」，要统一改一行就行，位置见 README 最后一节。
