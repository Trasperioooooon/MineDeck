### 阶段 19：AI 额度口径、损坏配置提示与 CI 校验（2026-11-24）

收尾 backlog 最后一批条目：把 AI 每日额度统一切成「只算输入和输出」（A100），让 `instance.json` 读不出来或格式损坏的服务器文件夹在列表页以只读提示卡现身而不是悄然消失（A104），并把嵌入式模组 jar 的一致性校验接进 GitHub Actions CI（A105）。Forge 伙伴模组的 `displayTest`（A103）按计划标为有空再做，因离线环境无法重编并更新内置 jar 留待后续在有网络的 JDK 环境下处理。

**改动内容**

1. **AI 每日额度口径调整（A100）**
   - `internal/ai/ai.go` 与 `internal/ai/usage.go`：新增 `Usage.QuotaTokens()`（只返回 `Input + Output`；主流推理模型的 `Output` 已含思考部分，缓存命中与写入不占每日额度）；费用估算仍保留原有的输入、输出、缓存读/写与推理分项计算不受影响。
   - 兼容磁盘既有 `usage.json` 且不改写未触动的老记录：`Totals.quotaTokens()` 对未携带 `quotaOnly` 标记的存量条目只计 `Input + Output` 与历史未拆分部分（`Tokens - (Input+Output+CacheRead+CacheWrite)`）；当当天有新请求落盘 (`Totals.add`) 时先按上述口径规整一次 `Tokens` 并记上 `quotaOnly` 标记（返回给前端和统计视图的 `clone` 中清掉该内部标记），避免「同日既有早年未拆分记录、升级后又追加带缓存请求」时误把新缓存从老账里扣掉。
   - 顺带同步游戏内 AI 用量累加 `internal/chatai/answer.go`（改调 `QuotaTokens()`），并将 `internal/ops/catalog/aiops.go` 与 `internal/web/ui/app.js` 额度说明改清「只算输入和输出，缓存不计入」。
   - 更新 `TestLedgerQuotaAndCost` 并新增 `TestQuotaOnlyCountsInputAndOutput`（验证带缓存/推理请求只按输入+输出扣额度、缓存仍正常计费、磁盘既有拆分与未拆分混合 `usage.json` 只读不改写及同日跨口径叠加重启不丢账）。

2. **损坏配置目录提示与本机打开（A104）**
   - `internal/inst/inst.go` 与 `internal/inst/proc.go`：`Manager` 启动加载时记录虽带 `instance.json` 但读取/JSON 解析失败或缺少 `name` 的文件夹，通过 `BrokenInstances()` 返回 `{id, folder, reason}`（仅文件夹名、稳定哈希编号 `__broken__:<hash>` 与面向用户的中文原因，不暴露完整磁盘路径），一旦目录被修好、删掉 `instance.json` 或整体移除即自动消失；健康服务器照常加载。
   - 复用现有 `Manager.OpenDir` 与 `POST /api/instances/{name}/opendir`（未新增路由，维持原有 62 条路由表与局域网鉴权/仅本机约束）：`OpenDir` 识别 `__broken__:` 前缀并拒绝传入 `sub` 子目录参数；`Get`、`Start`、`Delete` 照旧拒认该编号。
   - `internal/web/instances.go` 在 `GET /api/instances` 顶层增加 `broken` 与 `local`（顺带更新 `docs/设计与参考/API.md`）；`internal/web/ui/app.js` 为损坏目录绘制带「无法读取」标识和错误原因的只读提示卡，点卡片空白处不进详情页，本机显示「打开文件夹」、局域网隐藏按钮改提示到主机处理，仅有损坏目录时不误显空态页；`tools/ui-dev/server.js` 与 `tools/ui-dev/tests.js` 同步补齐 `A104` 用例。

3. **嵌入式模组 jar CI 检查（A105）**
   - `.github/workflows/test.yml`：在不改动既有 `go`（Windows）与 `go-macos`（macOS）两个任务的前提下，新增 `embedded-jars` 任务（`ubuntu-latest`），使用官方 `actions/checkout@v7` 与 `actions/setup-java@v4`（Temurin JDK 17 与 21，`cache: gradle`），通过 `GRADLE_OPTS` 暴露两个工具链环境变量后依次执行 `./companion/update-embedded.sh --check` 与 `./bridge/voicechat/update-embedded.sh --check`。
   - 当前离线 Windows 沙箱缺少 bash/Gradle/在线 Maven 环境无法直接重跑 `--check`，合入并推送至 GitHub Actions 后即可验证实际运行结果。

4. **Forge 伙伴模组 `displayTest`（A103，跳过）**
   - `companion/forge-1.20.1/src/main/resources/META-INF/mods.toml` 目前未写 `displayTest`，默认 `MATCH_VERSION` 会在跨版本进服列表显示红叉（仅显示问题，不影响进服）；按 A103 改写后需要联网重编 Forge/NeoForge 伙伴模组 jar 并更新 `internal/companion/jar/manifest.json`，本机离线沙箱不具备构建环境，按本轮约定跳过。
