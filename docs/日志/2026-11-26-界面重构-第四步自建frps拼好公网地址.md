# 界面重构：第四步自建 frps 那块拼出朋友要填的地址

接着 `2026-11-26-界面重构-第四步局域网加虚拟局域网地址.md`。只动了草图 `design-system/redesign/wizard.html`、计划书和现状，程序一行没动，活是主会话自己做的。

## 作者要改的

主会话问自建 frps 那块要不要把朋友要填的公网地址拼出来给人复制，作者说加上。

## 做了什么

自建 frps 那块现在和左边局域网一个排法：「朋友填这个地址」下面一行大字地址，旁边复制，隔一道线，下面是原来的四个框。大字是服务器地址加公网端口，公网端口空着就用第三步的本地端口，边填边跟着变。服务器地址还没填时，那一段用淡字「服务器地址」占着，复制灰着点不了。开关关着时大字和框一起淡下去。

服务器地址这样会在大字和框里各出现一次，和计划书开头「一个值只说一次」有出入。主会话上一轮提过这个取舍，作者看过以后说加上，理由是朋友要的是拼好的一整串，这一点记进了计划书。

两块原来是上下居中排的，两边内容高低不一样时，两行大字会错开。改成从上往下排、离小标题一样远，左右两块的「朋友填这个地址」、大字和那道线现在都在同一高度。

代理端的本地端口要第一次启动才知道。公网端口也空着时，大字只写到冒号，复制灰着，和局域网那行一样。这一处是主会话在浏览器里试代理端时发现的：第一版照样写了第三步的端口，那个数对代理端是假的。

## 验证了什么

1280×800 下深色、浅色都看了。用真鼠标打开开关、打了服务器地址和公网端口，大字跟着变成「地址:公网端口」，复制给的是这一整串，下一步不再拦。清掉公网端口回到本地端口，清掉服务器地址回到淡字、复制变灰。关着时点那块，打开后光标落在服务器地址。代理端下只写到冒号、复制灰着。打了一个五十多个字符的地址，大字末尾省略，复制按钮还在块里面。两块的小标题、大字、分隔线逐个量过，高度一样。页面资源没有出错的。
