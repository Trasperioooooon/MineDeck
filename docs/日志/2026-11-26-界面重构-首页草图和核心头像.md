# 2026-11-26 界面重构：首页草图和核心头像

11-25 晚上清账收口之后接着开始的界面重构，一直做到 11-26 凌晨。讨论的来龙去脉、每一版改了什么都写在 `docs/计划/2026-11-25-界面重构.md`，这份只记这一段工作本身。

## 要做什么

作者看了向导的选核心、选模组两页，说「我感觉现在的 UI 有些地方没有层次感……很多选项也都是简单的全部铺成开……解释性的文字非常的多，我们为什么不能让 Icon 发挥它自己本身的解释作用呢？」，又说左边两列导航把右侧内容挤得很窄。随后定下做法：「我想彻底重构一下 UI 层级这些，要不你先简单记录现在的这些问题，我们从首页开始，一页一页的设计，我来讲，你来做 visual」。首页的方向是作者给的：「全屏 + 悬浮胶囊导航栏」，打开就是服务器这页；上面三张大卡放最近玩的或玩得最多的，多的用小卡；AI 助手放进胶囊；大卡挑哪三台让用户自己选（游玩时长、最近启动、收藏）。之后一版一版提意见（同心圆角、底下一排的顺序、在线人数绿色高亮、一键复制隧道链接、「停止」要醒目等，原话摘在计划文件里）。

头像这一段，作者先问能不能找现成的或者直接用 Minecraft 自己的方块图标，看了几套现成素材都不满意，最后说：「哎，看来看去还是你画的好，但是你能不能再精细化一点？美化一点现有的所有的这些图标，然后放在一页上给我看看，我觉得不舒服的不好看的你重新画」。作者还转述了用户反馈：想在 MineDeck 里改服务器图标（server-icon.png）。

## 做了什么

先把已经看出来的界面问题记成 U01–U08（`bb78762`），然后在 `design-system/redesign/` 下搭了草图的底子：`kit.css`、`kit.js` 直接用程序自己的配色、主题和图标，`serve.py` 是不缓存的静态服务，作者那边刷新就是最新的。

首页草图 `home.html` 从第一版（全屏、悬浮胶囊，`ed4e48b`）改到第九版（`4031839`），中间的提交依次是 `95aff41`、`10508fb`、`017221f`、`8a896e1`、`e86651e`、`80d8684`、`63833ea`、`488dafb`。现在的样子：大卡外圆角 26、内边距 8，里面贴边的东西圆角都是 18，和外框同心；头像和名字放在核心色的封面条里；两格数字（开着是在线人数和运行时间，停着是上次玩和时长总计）；底下一排是控制台、运行状态、停止或启动三个等宽，右下角一个复制链接的圆钮。`home-cards.html` 留着几种写法的对比。后来发现草图漏了真程序的连续曲率圆角（`corner-shape: superellipse(1.7)`），补进 `kit.css`（`37a1809`）。

头像：`avatars.html` 对比了现在的像素图、名字首字、服务器自己的 server-icon.png，以及在「···」菜单里加「更换服务器图标…」的位置（`95d7296`）；查过的素材和不能打包原版贴图的原因记在计划文件里。作者选了继续手画之后，重画了一整套 16×16 的核心头像：`pixel16.js` 是画法，`icons.html` 是对比页，新的一整排、新旧逐个对比（每个写了改了什么）、放进大卡和小块里的样子都在一页上（`c3b3270`）。每个核心具体改了什么写在计划文件里；Velocity 最后画成闪电、Waterfall 画成水滴，是试过箭头和石崖水柱在 16 格里都认不出之后换的。

## 谁做的

主会话：Claude Code 桌面端，Claude Opus 5.5（会话环境给出的模型名），全部自己做，没有委派。草图都是纯前端的设计稿，没有动真程序的代码。

## 验证了什么

草图都在内置浏览器里按 1264×830 打开看过，控制台没有报错。首页大卡的同心圆角在页面上量过，三张卡左下按钮、右下状态、左上封面的圆心和卡片圆角的圆心重合到像素（`?guides=1` 能打开辅助线）。新头像里最后改的三个（闪电、水滴、紫珀块）按 16 格的像素排列逐格查过，十三个都放大到 128 像素看过一遍；对比页在 Nord 深色和方块浅色下都看过，描边让浅色的图标（纸飞机、线轴、紫珀块顶面）在浅底上也分得清，GitHub 浅色没开。没跑任何测试，因为没改程序代码。

## 没做完或没验证的

新头像作者还没看。头像用哪种做法没定：有 server-icon.png 时要不要优先用它，「更换服务器图标…」做不做。首页还没定的几件：胶囊放底部还是放进标题栏，只显示图标还是图标带字，向导和设置页底部的操作条和胶囊怎么相处，一台服务器都没有时首页长什么样。首页要的后端数据（存最近启动时间、累计运行时长、收藏标记）还没做。

## 留给下一位的

草图的打开方法：在仓库根目录运行 `python design-system/redesign/serve.py`，浏览器开 `http://localhost:27395/design-system/redesign/` 下的页面，`?scheme=`、`?theme=` 换配色，`?corner=round` 换回普通圆角对比。头像定稿后要替换的是 `internal/web/ui/pixel.js` 里的那套（12×12 的 MOTIF），新的格子是 16×16，显示尺寸要取 16 的整数倍才锐利，用的地方的尺寸要跟着改。首页定完接着按作者的意思一页一页往下做；所有页面的结构定了再统一改设计系统 MASTER 和代码。
