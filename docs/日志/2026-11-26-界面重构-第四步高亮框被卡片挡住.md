# 界面重构：第四步顶上的高亮框滑动时被卡片挡住

接着 `2026-11-26-界面重构-第四步照官网排节点和谁能进挪到底部.md`。只动了草图 `design-system/redesign/wizard.html`，活是主会话自己做的。

作者截图指出：第四步顶上四张卡（局域网、OpenFrp、樱花穿透、自己的 frps）换选择时，滑动的高亮框显示层级不对，滑过别的卡时有一截颜色不一样。

原因是每张卡自己带着底色，又压在高亮框上面。选中的那张底色是透明的，没选中的不透明，所以高亮框一滑进旁边那张卡的范围就被它的底色挡住一截；选中状态又是一点就换，框还在半路上，新旧两张卡的底色已经换好了。

改成叠三层：最下面四块单独的底色，中间是滑动的高亮框，最上面是卡片上的字，卡片本身透明。底色和卡片用网格的同一格叠在一起，不另外算位置。

验证：1280×800 下，临时把滑动放慢到 4 秒（只在浏览器里加的，没写进草图），用真鼠标从局域网点到樱花穿透，滑到一半截图，高亮框完整地盖在两张卡之间，没有被挡；去掉放慢以后来回点了几次，八个元素都在同一行，三层的叠放顺序是底色、高亮框、卡片，没有报错。
