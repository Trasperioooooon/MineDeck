## 作者问：改程序时不能像草图这样放收款码吗

不能照搬。草图里的收款码只放在作者这台电脑上，被 .gitignore 挡在仓库外面。能这样做，是因为草图只有作者自己在这台电脑上看。程序不一样：正式版是推了标签以后，GitHub 上的 CI 从仓库里的文件编出来的，见 `.github/workflows/release.yml`。界面的文件用 go:embed 打进程序，见 `internal/web/server.go`。仓库里没有的文件，CI 编不进去，发出去的程序里就没有收款码。如果只在本机把图放进界面目录，本机编的有、发出去的没有，两边还对不上。

另外一层：只要程序里给用户看收款码，谁装了程序都能拿到这些图。.gitignore 能做到的只是不让它们出现在 GitHub 的仓库页面和提交历史里。

所以改程序时只有两条路。一条是把图提交进仓库，打进程序。这样最简单，离线也能用，代价是图会留在公开仓库和历史里。另一条是放在官网 minedeck.cn 上，程序打开浮层时去取。图不进仓库，以后换码也不用发版；代价是要联网，取不到时要有个退路，比如提示打开官网的赞赏页。主会话倾向第一条：用户本来就会看到这些码，第二条多出来的好处只是不进 GitHub 和换码不用发版，却要多写联网和取不到的处理。最后选哪条等作者定。
