# 界面重构：详情页重启、启动挪到状态旁边，提示浮层最多露两条半

接着 `2026-11-27-界面重构-详情页常驻提示进页头第二行.md`。只改了草图 `design-system/redesign/detail.html`，以及计划书和现状，程序没动，活是主会话自己做的。

## 作者要的

一是把「重启」和「启动 / 停止」挪到运行状态和联机地址中间，这样看着整齐一点。二是常驻提示那块浮层，高度最多容纳两条半，不能无限往下长，超过两条就在里面上下滑。

## 改了什么

页头第二行现在的顺序是：状态、重启、启动或停止、联机地址、提示胶囊，右边空着。重启和启动按作者说的顺序排，重启在前。

浮层改成三条以上时只露前两条加第三条的一半，一眼看得出下面还有。每条的字数不一样，行高也不一样，所以高度是按前两条加第三条的一半量出来的，不是写死的数。多出来的在里面上下滑，用首页提示浮层那套细滚动条：系统滚动条藏掉，右边一根细条，鼠标移上去或正在滚时才出来，能拖；上面或下面还有没露出来的，那一头淡出。关掉一条时，浮层保持原来滚到的位置。

为了能看到滚动，草图切换条上加了「四条」：四种提示一起出来，同时切到 Forge。后两种是「有 3 个整合包文件没装上」和「有模组要求 Java 21，现在是 Java 17」，字照程序原话；只有整合包装的模组服才会有，所以切到 Forge。

## 验证了什么

在右侧浏览器里按 1280×800 看了 Forge 四条提示的样子。第二行从左到右是已停止（108）、重启（201）、启动（290）、地址（379）、提示胶囊（600），页头仍是 120 高。

点胶囊上的「+3」弹出浮层：四条各高 82、82、62、62，列表露出 203 高，正好是两条加第三条的一半；能滚的总高 300。用真鼠标滚轮往下滚，滚到底（97），上面淡出，页面本身没有动。放大看过浮层和第二行。看完右侧浏览器留在深色。
