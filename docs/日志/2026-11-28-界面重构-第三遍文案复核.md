# 2026-11-28 界面重构：第三遍文案复核

作者白天看详情页时发现页面上还有口语，比如游戏内 AI 的命令模板叫「改自己的游戏模式」、报错写「AI 服务商没有回应（等了 60 秒）」，问是不是 Gemini 没改到位，要求「全都改掉」。漏掉的原因有两种：一种是程序原话，第二遍被 Gemini 标成「需作者定」跳过了；另一种是示例数据里 MineDeck 自己说的话，被当成不许动的示例数据。主会话照这个重写了提示词的第十一节、备好第三遍的 bat，晚上作者双击跑完了。跑的是 agy 里的 Gemini，模型是作者在窗口里选的，记录里没写，实际模型未确认。

## Gemini 这一遍改了什么

范围是 `design-system/redesign/` 下的二十一个草图文件，共两百七十多处，按页面分成八组各改各的，最后由它的主代理做了一轮全站对齐。程序原话、MineDeck 写进日志和提示里的话、AI 的示例回答都改成了书面、冷静的说法，玩家自己打的话、服务端的英文日志、协议正文和作者定过的原话没动。跨页对齐的几件：换地图四步的名字和过程日志在详情页和任务页逐字一样；Java 坏了的原因、检查、重新下载三页说法一致；单人存档的提醒、缺维度的说明在导入页和详情页逐字一样；`API Key`、「今日」「次日」在三页统一；隧道状态统一成「运行中 / 连接中 / 已停止 / 连接失败」；去掉了「方可」「须」「亦」这类公文腔；十一月二十八日新加的几个确认框标题补了问号。逐条记录在作者电脑上不进 git 的 `.claude/copy-review/记录/第三遍-*.md`。

控制台报错横幅的按钮从「怎么修」改成了「修复建议」，展开后的小标题叫「修复步骤」。「怎么修」是十一月二十七日主会话起的名字，在待审文档里等作者看；作者已经说详情页审完了，又说口语全都要改，所以照收，待审文档里那句和 `detail.html` 开头的说明也改了。这是主会话替作者定的，作者想留「怎么修」可以否决（上一遍复审时它和「谁能进」「开服后才能发命令」归在一起保留，那两处这次仍然没动）。

## 主会话复核

整份 diff 逐行看过一遍，按字比对，不只看 Gemini 的汇总。护着的东西都在：协议正文和同意句那个文件、共用件 `kit.js` 一字没动；发给 AI 的提问原话没动；玩家的提问、问答记录里的「问」、服务端英文日志没动。

Gemini 有五处动的不只是字，逐个核过。导入页第三步内存的悬停原来是一句笼统的建议，它照向导那份已有的写法改成按核心分支（模组核心建议 4 GB 及以上，其余建议 2～4 GB），预设按钮的字也照向导从「4G」换成「4 GB」，两页现在一样，截图看过放得下。联机页换平台按钮的悬停里加了「创建 / 绑定」两种说法，用到的变量就在同一个函数里，平台名两边的空格照旧。任务页「卡住多久」那句、AI 设置里外部工具弹窗的标题，都只是把拼字符串改成了模板写法。这几处都留着。

主会话补改了这些：AI 助手里「当前会话不可续用」改成「当前会话已失效」（两处。「续用」读着别扭，但 Gemini 这么改是因为原来的「不可继续使用」在 440 宽的抽屉里会折出一个孤字「用」，所以换了一个同样短的说法，截图看过是一行）；Paper 和 Fabric 对比表里「仅服务端」补成「仅服务端安装」；隧道方案页那段说明被删掉了「隧道名称取服务器名的拼音」这个事实，补回来；任务页「已按接管本地服规则识别」给入口名加了引号；全局设置里自建 frps 的说明「仅在拥有自有 frps 服务端时使用」改成「仅在已有自建 frps 服务端时使用」；换地图完成页的副标题「服务器当前保持停止」改成「服务器目前处于停止状态」。另有两句是 Gemini 按规矩没碰的：发给 AI 的排错资料里，本地规则的两条结论还是「create 需要 flywheel，但没有装」「25567 已经被别的程序占着，服务器绑不上」。这两句会出现在「查看待发送的排错资料」里给用户看，又和页头提示、报错横幅出自同一套诊断规则，横幅已经改成书面的了，所以这里跟着改成「create 依赖 flywheel，但未安装」「25567 已被其他程序占用，服务器无法绑定该端口」，同一段里 MineDeck 写的小标题「只留 WARN / ERROR、异常和最后几行」也改成了「仅保留 WARN / ERROR、异常与最后几行」。开头那句「请帮我分析这台服务器的问题。」是替用户填好的提问、用户能改，算用户的话，没动。改程序时诊断规则的原话和这段资料的格式（`internal/assistant/turn.go`）照草图改。AI 新建服务器那段回答里「MineDeck 便携版 Java 21」改成「MineDeck 下载的 Java 21」，和各页的叫法一致。全局设置 Java 页的确认框和读屏标签里还叫「便携 Java 17」，那一页作者还没审，记在待审文档 Java 那节，审时一起定。

截图时顺带看到一个老毛病：报错横幅展开以后，标题行里的结论淡掉了，省略号却还挂着一个「…」，因为省略号是外层元素画的，不跟着里面的字一起淡。补了一行样式，展开时不画省略号。这和这次改字无关，是十一月二十七日那版就有的。

Gemini 列的「拿不准」那十几条照它的处理留着：作者同意过的「开服后才能发命令」、规范点名的「端口启动后才知道」、首页空状态那句、「没装上的文件」这个专名、定时任务里的「今天 HH:MM」「明天 HH:MM」等。全站再搜了一遍「这台」「别的」「不用」「怎么」「连不上」这类字，剩下的都在代码注释、草图切换条、用户自己的提问和给用户点的建议问题里，这些照规矩不改。

## 验证

全部草图的脚本和页面里的内联脚本过了一遍语法检查，没有错误。截图核对了控制台报错横幅（Java 坏了、两个问题，收起和展开）、导入页第二步和第三步、任务页（接管部分成功、换地图完成）、全局设置的内网穿透、存储位置、AI 三类、详情页扩展、AI 助手的表格回答，AI 助手设置改过以后那一行、任务页导入服务端的日志、隧道方案页，深浅两色各一张，页面都不滚动、没有报错（隧道方案页本来就是长页）；被截断的只有原来就有、配了悬停的几处（长会话标题、命令模板、自填单价）。这十几个状态是抽查，加上 Gemini 自己截的两百多张，并不等于二十一个文件的每个状态都看过。
