### 发完以后的核对

发布页不是预发布也不是草稿，`releases/latest` 指向 v3.1.1，正文开头就是 `docs/releases/v3.1.1.md`，里面没有（待补），后面接着 GitHub 自动生成的改动列表。四个附件下载到了 `D:\MineDeck-v310-test\release-v3.1.1`，exe 和两个伙伴模组的哈希都和 `SHA256SUMS` 一致，两个 jar 的大小和哈希也和标签里的清单一致，和 3.1.0 是同一份。exe 是 15,967,744 字节，SHA-256 是 `63de0c0c5833c49b8572bfbb81b072b80cf2a745ecdbef529d193bee2eb933c2`。它是窗口程序，在空文件夹里用 `-nogui` 起来报 3.1.1。又拿这个下载回来的 exe 跑了一遍端口检查：端口被占着时马上报错，放开以后服务器真的起来。
