## 做了什么

PR #28（分支 `cursor/ui-review-fixes-9a55`，一个提交 `2c48c08`）是 Cursor 的代理在 11-16 上午开的，基于 beta.4 的 `03ca31f`，只改界面：详情页头的主按钮跟着状态走、矮窗口控制台、复制失败不再假报「已复制」（弹手动复制框）、手机远程管理页的防火墙命令和管理页地址可以复制、隧道报错加「复制原文」、方块深色的边框、搜索框和网格、新建页三张卡排一行、AI 面板打开时主区让位、禁用的主按钮变灰。它自己只在仿真界面上跑过界面用例（248 条），没在 Windows 上跑过。

在集成工作树 `.claude/worktrees/r320`（分支 `release/v3.2.0`，从 main 的 `afcf74d` 拉出）里用 `--no-ff` 合进来，合并提交 `04551cc`，没有冲突，用例 244 加 4 条，没有被合并吞掉的。

然后两路同时审：opus-max 子代理只读复审，在仿真界面上逐页量；主会话用这次的代码编出程序，在真窗口里量。两边查出的问题一致，挡合并的三处：

- 矮窗口（高不超过 680 的鼠标窗口，最小窗口 1024×576、1366×768 屏放大到 125% 都算）里，PR 给 `#main` 设了 `overflow:hidden`。页头提示条多、或者控制台的报错横幅展开时，命令框和「发送」被裁到窗口外、滚不到；按「/」聚焦命令框以后，滚轮也滚不回页头。
- AI 面板一打开就把主区推开面板那么宽：1024 宽、默认 440 时主区只剩 350 左右、内容横向溢出，面板拖到最宽只剩 72px；宽窗口里左右留白还是按外层宽度算，内容缩成中间一条。
- `#main` 底部留白从 24 改成 72（PR 没写原因）：吸底的保存条、向导底栏离窗口底悬空 72px；控制台、外观、备份、服务器列表、新建、内网穿透在常规窗口里多出 13 到 49px 的整页滚动（真窗口里 1280×800 的控制台多 29px）。

另有几处应改：矮窗口里保存条改回文档流（常用设置要滚四五千像素才看得到「保存」）；禁用的主按钮看着像能点的次要按钮；方块深色的边框写在 `app.css` 末尾、绕开了 `themes.css`，而且 .16 和 `--border-strong` 的 .18 几乎一样，悬停看不出来；隧道公网地址的复制失败时照样变成「已复制」；复制以后键盘焦点丢到页面上；手动复制框只写了 Ctrl+C（手机上没有）；新建页三张卡在 760px 的父级里挤成很窄的三列、1100 以下又叠成一列；PR 新加的两条版面用例守不住各自的改动。

主会话在 `release/v3.2.0` 上改了：

- `d1445c7`：去掉 `overflow:hidden`，矮窗口里日志区按 0 起算、最少 64px 填剩下的高度，`#tab-body` 只长不缩，放不下时整页滚动；删掉保存条改文档流那一行；底部留白改回 24，日志区高度保留 `100dvh-460`、最小高度改回 240；AI 面板改成 `assistant.js` 的 `fitMain()` 判断，让出以后主区还有 720px 才让（`body.ai-push`），让位时左右留白按让出以后的宽度重算；复制以后把焦点还回去，隧道地址的复制改走 `copyFlash`，手动复制框加上手机的说法；禁用主按钮保留灰底、透明度沿用 .48；边框挪进 `themes.css`，`--border-strong` 从 .18 调到 .26（悬停的变化保持约 1.4:1）；新建页三张卡改回两列；提示区上边距跟着页头下边距调；服务器列表空状态的副文案、连接地址旁的说明按 `docs/文案重写/` 的定稿改回；过时的注释跟着改。
- `32ef54e`：用例改成守得住上面这些（矮窗口没有提示时不滚就看得见命令框、报错横幅展开时能滚到命令框也能滚回页头；AI 面板 1600 宽让位、拖到最宽和 1280 宽时浮在上面；复制失败以后焦点回到复制键；新加隧道公网地址复制失败的一条），共 249 条。
- `b707234`：Codex 复审（见 `2026-11-17-v3.2.0正式版`）又查出 PR #28 带来的一处：选核心的卡片最小宽度从 260 提到 340，360、320 宽的手机竖屏上卡片超出主区、整页能横着滚。改成 `minmax(min(100%, 340px), 1fr)`，放不下 340 时缩成一列；加了 360、320 宽的用例，旧样式下 360 宽溢出 4 像素，用例当场失败。

PR #28 里取了的：页头主按钮、矮窗口控制台（改了做法）、复制的那几处、方块深色的边框（挪了位置）、搜索框、选核心的卡片最小宽 340（窄手机上缩成一列）、AI 面板让位（加了条件）、禁用主按钮变灰（改了透明度）、页头紧凑一点。没取的：新建页三张卡排一行、`#main` 底部 72px、矮窗口保存条改文档流、两处文字改动。

合进 main：发版的改动都在同一支上，14:00 把 main 从 `afcf74d` 快进到 `release/v3.2.0` 的 `3a5e856` 推上去。GitHub 随即把 PR #28 记成已合并（合并提交认的是 `04551cc`），远端分支 `cursor/ui-review-fixes-9a55` 按仓库的设置自动删了。发版见 `2026-11-17-v3.2.0正式版`。
