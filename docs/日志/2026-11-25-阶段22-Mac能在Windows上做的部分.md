# 2026-11-25 阶段 22：Mac 能在 Windows 上做的部分（A92、A93）

## 要做什么

完成在 Windows 环境下可以推进与交叉验证的 Mac 跨平台准备任务（分支 `gemini/v328-stages`，基线 `6f6ceb5`）：
1. **A92（五项非 Windows 改进 + 既有 `!windows` 文件审计）**：防打开命名管道/设备文件阻塞、`Fstat` 普通文件校验；Unix 通配端口额外探测 `127.0.0.1` / `::1`；Darwin 测试锁改用 `O_EVTONLY` + `Fchmod` / `Fchflags`；`update.Apply` 非 Windows 提前拦截；`app.SamePath` 按平台拆分并审计全部调用点；对 PR #32 既有 `//go:build !windows` 文件做只读复查（只回报不改）。
2. **A93（Mac 上 6 个测试包失败）**：修改 `app`、`inst`、`ops/catalog`、`transfer`、`tunnel`、`web` 中硬编码 Windows 路径/命令的测试为跨平台写法，并对尚无 Mac 钥匙串（D01）或 Windows 专属行为的用例加 `runtime.GOOS != "windows"` 跳过。不改动 `go.mod` / `go.sum`，不碰待作者拍板的 A90，仅动计划允许的两处共用非测试微调。

## 做了什么

在分支 `gemini/v328-stages` 上（随本日志一同提交）：

1. **A92 五项非 Windows 改进**：
   - **A92.1**：更新 `internal/inst/realpath_darwin.go`（`OpenFileInside` 使用 `ignoringEINTR` + `unix.O_RDONLY|unix.O_NONBLOCK|unix.O_CLOEXEC`，立即 `unix.Fstat` 断言 `S_IFREG`，经 `fdPath` + `InsideReal` 校验后再 `unix.SetNonblock(fd, false)` 返回 `os.NewFile`）与 `internal/worldimport/lock_unix.go`（`sessionLockHeld` 同样非阻塞打开、处理 `EINTR` / `ENOENT`，断言 `S_IFREG` 后调用 `unix.FcntlFlock(..., unix.F_GETLK, ...)`）。
   - **A92.2**：在 `internal/inst/portcheck.go`（共用非测试代码允许的两处微调之一，零 Windows 行为变化）拆出 `probeResolvedBindPort` 并追加遍历 `extraBindHosts(t.network, host)`；`internal/inst/portcheck_windows.go` 返回 `nil`；`internal/inst/portcheck_unix.go` 在 `""`、`0.0.0.0`、`::` 时补测 `127.0.0.1` 和/或 `::1`，新增 `internal/inst/portcheck_unix_test.go`（`TestExtraBindHostsAndLoopbackConflict`）。
   - **A92.3**：更新 `internal/inst/testlock_darwin_test.go`（`lockExclusive`）与 `internal/worldimport/locks_darwin_test.go`（`hold`），改为持有 `unix.O_EVTONLY|unix.O_CLOEXEC` 句柄后全程用 `unix.Fchmod` / `unix.Fchflags` 加锁与清理，避免路径 TOCTOU。
   - **A92.4**：更新 `internal/update/update.go`（共用非测试代码允许的两处微调之一，零 Windows 行为变化），在 `Apply` 内将 `runtime.GOOS != "windows"` 返回 `errNoSelfUpdate` 提前到 `AssetURL` / `SHA256` 校验之前。
   - **A92.5**：抽出 `internal/app/path_windows.go`（`strings.EqualFold`）与 `internal/app/path_other.go`（`filepath.Clean` 逐字比较），从 `internal/app/app.go` 移除单一 `SamePath`；审计全部 5 处调用点（`internal/app/app.go` 的 `RememberInstanceDir`、`ForgetInstanceDir`、`RememberCreatingRoot`、`ForgetCreatingRoot`，以及 `internal/inst/creating_leftover.go` 的 `cleanCreatingRoots`），确认在区分大小写 APFS 卷上五处均应保持区分大小写；调整 `internal/app/app_test.go` 并新增 `TestSamePathCaseSensitivity`。

2. **A93 六个包测试跨平台改造**：
   - `internal/app/secret_test.go`：无钥匙串（D01）跳过 `TestMigrateCFKey`、`TestSetCFKey`。
   - `internal/ops/catalog/catalog_test.go`、`phase3_test.go`：跳过依赖加密凭据的 `TestTunnelFollowWritesOpLog`，并按系统切换 `java.exe` / `java`。
   - `internal/transfer/transfer_test.go`、`hardening_test.go`：非 Windows 假 Java 改用 `java`、`jar:../../outside.jar`，盘符与反斜杠 `level-name` 样本限定在 Windows。
   - `internal/web/routes_test.go`、`web_test.go`：`newFullEnv` 与 `TestConfigResponsesHideCFKey` 为 `!windows` 跳过尚无 Mac 钥匙串（D01）的用例。
   - `internal/tunnel/`（15 个测试文件）：为依赖 DPAPI `secret.Seal` 的用例及 2 处将宿主机 `ping` 伪装成 PE `frpc.exe` 的用例补充 `!windows` 跳过说明。
   - `internal/inst/`：`install_test.go` 与 `adopt_test.go` 引入 `fakeJavaBin()` 按平台生成 `java` / `java.exe`；`beta3_detail_test.go`（`\Device\HarddiskVolume3\...`）与 `runbat_injection_test.go`（`cmd /c run.bat`）补充 `!windows` 跳过；`portcheck_test.go` 将 `127.0.0.2` 测试包进 Windows；`control_test.go`、`levelname_test.go` 将依赖 Windows `filepath.IsLocal`、盘符/UNC/ADS/保留设备名及反斜杠分隔的样本限定在 Windows。

3. **PR #32 既有一批 `!windows` 老文件只读复查结论（仅记录，未改）**：
   - `internal/atomicfile/replace_other.go`：原子替换后未对父目录 `fsync`；`canonicalPath` 未做大小写规范化（默认不区分大小写 APFS 可能与大写别名不一致）。

   - `cmd/minedeck/singleinstance_other.go`：占位实现恒返回 `true`，非 Windows 端暂未做文件锁防双开。
   - 其余 8 个平台占位桩（`secret/dpapi_other.go`、`hostdlg/hostdlg_other.go`、`autostart/autostart_other.go`、`music/music_other.go`、`errhint/os_other.go`、`modcart/notfound_other.go`、`tunnel/notfound_other.go`、`atomicfile/links_other.go`）符合当前降级/空桩定位。

## 验证了什么

全部验证均在 Windows 开发机、最后一次编辑后完成：
- `gofmt -l .`：无输出。
- `GOOS=darwin GOARCH=arm64`：`go vet ./...`、`go build ./...` 及全部 8 个修改包的 `go test -c`（`app`、`inst`、`ops/catalog`、`transfer`、`tunnel`、`update`、`web`、`worldimport`）均编译通过，临时测试二进制已清理。
- Windows `go vet ./...`：通过，无输出。
- Windows `go test -count=1`：
  - 沙箱内通过：`internal/app`、`internal/transfer`、`internal/web`。
  - 沙箱因 `mklink /J`、`t.Chdir`、监听表及自更新重启批处理阻止后，在沙箱外重跑其余 5 包：`internal/ops/catalog`、`internal/update`、`internal/tunnel`、`internal/worldimport` 一次通过；`internal/inst` 首次遇到 `TestStartPortBusyNamesOtherServer`（Windows 临时端口瞬时被占）抖动，单独 `-count=5` 全通过后重跑完整 `./internal/inst/` 通过。
