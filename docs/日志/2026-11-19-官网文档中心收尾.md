# 2026-11-19 官网文档中心收尾

## 要做什么

按任务说明（由 `docs/测试与评审/评审-官网文档中心与跨页过渡-2026-11-19.md` 与 `docs/日志/2026-11-19-官网文档中心按复审修改.md` 遗留项整理），在分支 `docs-center`（基准 `b697834`）上完成 Grok 留下的五件官网文档中心收尾改动：

1. 产物检查把第三方资源的约束执行完整（复审 Low 第 5 条）：`website/lib/checks.mjs` 对自动加载资源（`<script src>`、样式表 `<link href>`、`<img src>` 与 `srcset`、CSS `url()`、JS `fetch()` 等）改为只允许同源相对地址或显式允许名单，并在不合规时报错指出文件与地址。
2. 导航型外链统一走 `extLink()`：Markdown 渲染出来的外链和顶栏 GitHub 链接改用 `extLink()`，产出属性与 `extLink()` 一致。

4. 文档模板 `website/docs-content/_template.md` 操作步骤第二步的「创建」改为界面上的「开始创建」。
5. 英文 FAQ（`website/docs-content/en/faq/general-faq.md`）按中文 FAQ 的防火墙小节直译补上对应小节与锚点，并把英文帮助页旧锚点指到该节；界面文字以 `internal/web/ui/*.js` 为准。

只改 `website/` 和本日志，不新增依赖、不改产品源码、不改 `docs/现状.md`、不 push、不部署。
