# 2026-11-23 官网部署 v3.2.5（Claude 写）

## 要做什么

v3.2.5 发出以后，主会话问要不要重新部署 minedeck.cn，作者答「部署」。

## 做了什么

照惯例用仓库外的发布脚本（`publish.ps1`，不带参数，没有先干跑）部署，官网源码取本机 main 检出，当时在 `c31644e`。整个流程顺利：

1. 从 GitHub 拉版本数据，写进 `website/data/`。仓库信息里的许可证已经认成 AGPL-3.0。
2. 构建、检查产物：占位字样都是 0 处。
3. 镜像同步：96 个文件里 92 个已有且对得上，下了 v3.2.5 的 4 个（17.6 MB）。
4. 上传新镜像文件和官网包，服务器按清单把镜像全量核对一遍，切换 `current`。
5. 线上核对：
   - 从本机取回全站 186 个文件，没有问题。
   - 首页页脚是「© 2026 MineDeck 贡献者 · AGPL-3.0」。
   - 96 个镜像链接的状态和大小都对。
   - 服务器经自己的 Nginx 把 v3.2.5 的 4 个文件完整下载一遍，SHA-256 都对。

线上切到了 `20261123-153716`，最新稳定版是 v3.2.5。上一版 `20261121-203624` 记成回退目标，这次没删任何旧目录。
