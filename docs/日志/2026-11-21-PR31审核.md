## 做了什么

分支 `cursor/user-feedback-eight-0dab`（PR #31，初始 `aebf487`，基线 `5d569dd`），没有合并、打 tag、发版或部署。先拉取确认远程无新增提交，再完成全量真 Windows 基线验证和逐提交代码审核，随后按主题提交了以下修改：

1. **下载与重定向报错脱敏**（`f616ac9`，`internal/dl/`）：`HTTPSRedirect` 原先在遇到 `https -> http` 降级重定向时把完整 `req.URL` 拼进报错，会泄露目标地址里的 `user:pass` 和签名查询串，且未拦截同协议但带 `userinfo` 的重定向；`Fetch.OnRetry` 和 `FetchBytes` / `FetchJSON` 也未剥掉 `*url.Error` 外壳里的完整 URL。改为拦截带账号的重定向、报错只保留 `scheme://host`，统一经 `sanitizeNetErr` 剥掉完整 URL，并新增只跟安全 HTTPS 跳转的 `FetchBytesHTTPS`。
2. **NeoForge 安装器校验边车收紧**（`54b1db9`，`internal/mcsrc/`）：`parseSHA1Sidecar` 原先接受多行文本首段，拉取官方 `.sha1` 未限 HTTPS 重定向且默认最多等满两轮 30 秒，版本号也未拦 `.` / `..`。改为严格单行 `.sha1` 校验、10 秒超时加 `FetchBytesHTTPS`、校验版本号字符集与 `.` / `..`，并修掉测试清理顺序在包目录留下 `config.json` 的问题。
3. **便携 Java 官方校验与卸载防护**（`bcb9723`，`internal/java/`、`internal/inst/manage.go`、`internal/ops/catalog/mc.go`）：
   - `fromTUNA` 原先优先采信清华镜像自身的 `.sha256.txt`（当时恰巧 404 才落到 Adoptium）、按字母序选包（会把 `17.0.9` 排在 `17.0.14` 后面）、正则未拦斜杠或设备名，且未遵守 `OfficialOnly()`；`fromAdoptium` 回退到 `jdk` 时把清华路径写死成 `/jre/`。改为 `winname.OK` 过滤、按数字段排序选最新包、一律向 Adoptium 官方接口（`FetchJSONHTTPS`）核对同名压缩包的 SHA-256（不再信镜像自证文件）、遵守「仅官方源」，并按实际 `imageType` 拼镜像路径。
   - `RemovePortable` 原先只查 `os.ModeSymlink`，未查 Go 在 Windows 上给目录联接（`mklink /J`）标的 `fs.ModeIrregular`，也未查子目录联接；`Lstat` 遇非「不存在」错误会静默返回 `nil`；删到一半留下 `.incomplete` 后设置页看不见该项，无法按报错提示重试；运行中改过 Java 配置（`i.JavaPath` 已变但进程仍占着便携 Java）、后台正在新建/导入服务器、或实例通过目录联接/8.3 短名指向便携 Java 时，卸载前未拦住。全部补齐，并在 `java.list` 返回 `incomplete` 供设置页清理残留，占用统一回 `409`。
4. **半成品清理、接管排序与项目页字段修正**（`599f55a`，`internal/inst/`、`internal/ops/catalog/creating.go`、`internal/transfer/export.go`、`internal/modcart/`）：
   - `leftoverDir` 原先未调 `winname.OK`：传入 `"0/."` 时 `filepath.Rel(root, root)` 为 `"."` 且 `filepath.IsLocal(".")` 为真，会直接指向服务器根目录本身；Windows 下 `"0/.. "` 还会被系统去掉尾空格解到父目录。同时补上 `fs.ModeIrregular` 目录联接及子联接拦截、`instance.json.bak`（移出列表留底）与 `instance.json.tmp` 保护、`Lstat` 非 `ErrNotExist` 保守拒绝、占住 `m.creating` 锁完成删除、识别自定义 `level-name` 世界、`instance.creating.list` 标 `NoLog: true` 免刷操作日志，以及交接包 `regenerable` 忽略 `.minedeck-creating`。
   - `adopt_scan.go` 原先同分排序在跨核心夹着同核心多版本时违反严格弱序（如 `[a-paper-1.20.1, b-velocity, c-paper-1.21.1]` 漏选新版 `1.21.1`），`velocity.toml` 加分 `+15` 与混合端 `45` 平分，普通 Fabric/Forge 服配原版 `server.jar` 会误弹混放提示，启动脚本点名 `paper.jar` 时提示仍说按 `velocity.toml` 预填，且把界面字段「启动文件」写成了「启动方式」。一并修正。
   - `modcart/modrinth.go` 把未接线的 `ProjectPageURL` 填入搜索结果 `Hit.ProjectURL`，并去掉接口缺 `project_type` 时拿查询参数回填的做法。
5. **界面与官网文案润色、分批容错与界面测试**（`de357ed`，`internal/mcsrc/registry.go`、`internal/web/ui/`、`website/content/`、`tools/ui-dev/`）：
