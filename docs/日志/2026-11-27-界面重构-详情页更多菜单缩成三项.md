# 界面重构：详情页「···」缩成三项，文件夹挪进各自那一页

接着 `2026-11-27-界面重构-详情页标签放左边.md`。上一份里主会话提的改法，作者说照这样改。只改了草图 `design-system/redesign/detail.html`，以及计划书和现状，程序没动，活是主会话自己做的。

## 改了什么

页头的「···」只剩管整台服务器的三样：打开服务器文件夹、导出交接包…、删除服务器…。服务器开着时，导出和删除灰掉，悬停写「需先停止服务器」，同首页大卡那张菜单。原来「打开文件夹」那一组，以及组标题都拿掉了。首页大卡的「···」没动，因为首页没有标签。

原来那组里对着某个标签的几个文件夹，挪进了各自那一页。按钮放在页面那一栏的右上角，是 28 见方的图标按钮，离栏的右上角 8，圆角 10，照同心：
- **控制台**：崩溃报告和日志两个，悬停写「打开崩溃报告文件夹」「打开日志文件夹」。代理端只有日志，原来的菜单里代理端也没有崩溃报告。终端是深色的，所以这里的按钮用终端的字色。
- **世界与备份**：「备份」子页里是备份文件夹，「换地图」子页里是世界文件夹。
- **插件 / 模组**：插件或模组文件夹，跟着核心叫。

这几页里面还没画，按钮先放在空着的那一栏的角上，标出它会在哪。

页头有两处能点去对应的标签了。在线人数那块悬停出底色，点了去「玩家」；代理端没有「玩家」，这块就不能点。联机地址悬停出底色，点了去「联机」；复制照旧是地址右边的图标，两者分开。页头只放一个地址，绑了隧道就用隧道的，同首页大卡；全部地址列在「联机」里。上一份留着的「页头显示哪个地址」就这样定了。

切换标签的那段脚本抽成了一个函数，左边点标签和页头点这两处都走它，选中块照样从原来那行滑过去。

## 验证了什么

用无头浏览器按 1280×800 量了四种组合：Paper 控制台深色；世界与备份的换地图；Forge 的模组；代理端浅色。文件夹按钮都在栏的右上角，离两边各 8，28 见方，圆角 10。代理端控制台只有日志一个，代理端的在线人数也不能点。几张都不滚动，没有空图标，没有报错。截图放大看过深色和浅色的页头和按钮。

在右侧浏览器里用真鼠标点了：「···」里是打开服务器文件夹，以及灰着的导出交接包…、删除服务器…；点在线人数到了「玩家」，点地址到了「联机」，选中块都滑到了对的那一行。看完右侧浏览器留在深色。
