# 2026-11-29 界面重构：卡片透明度、三个设置分类合成「关于与其他」

接着上一份（`2026-11-28-界面重构-全局设置第一轮`）。作者看了背景图的效果，提了两件事：背景图那里加一项改卡片透明度，让背景图能从卡片后面隐约看到；「启动与托盘」「通知与集成」「更新与关于」合成一页，叫「关于与其他」。

## 卡片透明度

外观页背景图下面加了「卡片透明度」，四段：不透明、15%、30%、45%，点了马上生效。铺着背景图时，面板和卡片的底色按这个比例变透明，背景图就从卡片后面隐约透出来。字本身不透明；弹窗、悬停提示、下拉菜单照旧是实底，因为它们盖在别的东西上面，透了就看不清。没选背景图时这一项淡掉、点不动，悬停说选了背景图以后才能调。默认是「不透明」，和程序现在一样。

做法放在共用件里：`kit.css` 在 html 上先记下当前主题里面板颜色的不透明值，再在 body 上把 `--surface`、`--surface-2` 改成按比例透明的，各页的面板照常用这两个颜色，不用一页一页改。卡片里面那一层内框也是用这两个颜色调出来的，两层叠起来比外面一圈更不透，所以内框里的图比边上淡一些，45% 时还看得出来。`kit.js` 加了 `KIT.setCard`，草图参数是 `card=15|30|45`，铺着背景图时点去别的草图页会带上。截图看过：深色 30%、45% 时图隐约可见，字照样清楚；浅色 45% 时云的方块透得比较明显，读字不受影响。四档的取值是主会话定的，可否决。

## 合成「关于与其他」

三页内容都少：「启动与托盘」两个开关，「通知与集成」一个 Webhook 地址，「更新与关于」是版本、更新渠道、启动时检查更新和右边的关于。交给一个子代理在独立工作树里合（Claude 子代理 fable-high，汇报里写的模型是 Fable 5.2），主会话审过后合进来。

版面以原来的「更新与关于」为底，右栏「关于」不动。左栏从上往下：Logo、版本块、更新渠道，然后三个开关（启动时静默检查更新、关闭窗口时最小化到托盘、开机自动启动），再是「Webhook 事件推送（选填）」，最下面「退出 MineDeck」贴底，642 高里放得下，没删任何一项。开关之间靠间距分成两组，没加细线，是子代理照这一页别处的排法定的。开机自启写注册表失败的样子、Webhook 地址填错就地拦下、局域网打开时遮掉地址，都照原来两页的做法搬过来。Webhook 是这一页唯一要点保存的项，改了没存就离开照样先问。托盘那一行的悬停原来说去「更新与关于」底部退出，现在改成「在本页底部」。

分类 id 沿用 `about`，有新版本时分类后面的小点照旧挂在它上面。左栏现在八个分类：内网穿透、下载与网络、Java 运行时、存储位置、AI（可选）、手机远程管理、外观、关于与其他。老地址 `?sec=startup`、`?sec=notify` 打开会落到这一页，地址栏也跟着换成 `sec=about`。共用件页（`commons.html`）关窗确认框里「可在设置 → 启动与托盘修改」改成了「关于与其他」。原来两页的文件删了。

## 验证

全部草图脚本过了语法检查，没有错误。主会话在主检出上截了：外观页没选背景图时（卡片透明度淡掉）、点选背景图再点 30% 以后（地址带上 `bg=1&card=30`）、浅色 45%、设置页和首页、详情页带卡片透明度、「关于与其他」深浅两色（含有新版本的小点）、带背景图和卡片透明度的「关于与其他」、老地址 `sec=notify`。页面都不滚动，没有报错和截断。子代理另外用脚本点过三个开关、开机自启失败、检查更新、Webhook 保存和填错被拦、离开确认框、退出确认框，结果都对；局域网那条路只截了图，没用脚本点。都是无头浏览器加脚本，没用真鼠标走过。
