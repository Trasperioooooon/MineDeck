这一版主要是界面和文字：试用 beta.2 时提的几条界面问题改了，界面上的文字整个重写了一遍，报错的样子也换了。另外修好了 OpenFrp 的 frpc 下载，导入整合包能认更多种压缩包。beta.1 到 beta.3 的内容见 [v3.1.0-beta.1](https://github.com/Trasperioooooon/MineDeck/releases/tag/v3.1.0-beta.1)、[beta.2](https://github.com/Trasperioooooon/MineDeck/releases/tag/v3.1.0-beta.2)、[beta.3](https://github.com/Trasperioooooon/MineDeck/releases/tag/v3.1.0-beta.3) 的发布说明。

## 界面

- **选文件夹不再冒出黑窗口。** 以前点「浏览」「更改…」会先闪出一个命令行窗口，把它关掉界面还会报错。现在用的是 Windows 自带的选文件夹窗口，标题是中文，挂在 MineDeck 的窗口上。
- **窗口最小 1024×576**，再拖小也不会把页面挤乱。
- **新建服务器的四种方式**排成两组一样大的卡片：「从零创建」「导入整合包」，「导入交接包」「接管已有服务器」。首页没有服务器时，主按钮直接进「从零创建」。
- **「购物车」改叫「待装清单」。** 选模组这一步分成两栏：左边一打开就是当前核心和版本下的热门模组（按下载量，可以按类别筛、往下翻），右边是待装清单。自己下载的 jar 可以「从电脑添加」，装的时候一起放进去，前置模组照样自动检查。
- **内网穿透页**的添加表单挪到了列表上面。
- **界面上的文字重写了一遍**：统一说「服务器」「文件夹」，去掉了绕弯子的说法。常用设置和全部配置里有十来项的说明也重写了，motd 的中文名统一叫「服务器介绍」。

## 报错

- **报错先说没做成什么**，比如「无法启动服务器」。后端给的原因是一句看得懂的中文时，接在后面一起显示：「无法启动服务器：端口 25565 已被其他程序占用……」。原因里带着文件路径、英文的系统报错时，正文只写结论，完整的原文点「详情」就能看到、能复制。
- **页面上的报错框**（比如服务器列表拿不到时）是一句结论加一个「复制报错信息」按钮，原文一字不少，发给别人帮忙看时直接粘贴。
- **AI 服务商的报错**直接说原因：「连接失败：Key 不对或已失效」「账户余额不足」这类，状态码和服务商的原话在复制出来的原文里。
- **启动时的几句报错说清楚了**：服务器已经在运行、正在启动或正在停止时又点启动，会直接说是哪种情况；找不到这台服务器用的 Java 时，直接说去「内存 / 启动」里重新选一个。

## 内网穿透

- **OpenFrp 的 frpc 下载不下来的问题修好了。** 以前拼出来的下载地址不对，几个下载源都是 404，Windows 上用 OpenFrp 一直装不上 frpc。多个下载源都失败时，报错会按下载源列出各自的原因。
- **frpc 被杀毒软件拦下或删掉时，会说清楚。** frp 这类内网穿透程序常被杀毒软件当成风险软件（Windows 自带的防护会报 `PUA:Win32/FRProxy` 之类），以前只看到一句英文的系统报错。现在隧道卡片上会说「frpc 被杀毒软件拦下了」或「frpc 不见了，多半是被杀毒软件删掉了」，告诉你到 Windows 安全中心的「保护历史记录」里允许或还原它（别的杀毒软件到它的隔离区里恢复），以及 frpc 在哪个文件夹。

## 导入整合包

- **清单套了一层文件夹的整合包能导入了。** 以前只认压缩包最外层的 `modrinth.index.json` 或 `manifest.json`，作者把整合包文件夹再压一层（`整合包名/manifest.json`）就报「无法识别」。现在套一层也认。
- **作者给的现成服务端压缩包可以直接导入。** 比如 CurseForge 上大型整合包另外提供的 Server Pack：压缩包里没有整合包清单，但有 `mods`、`plugins`、`server.properties` 或服务端 jar，就直接解压成一台新服务器，不重新下载核心。核心和版本用「接管已有服务器」的办法识别，认不出来会说明缺什么，并指给你「接管已有服务器」这条路。
  - 压缩包里已经有 `server.properties` 的，只改端口，**正版验证和允许飞行沿用包里的**，导入页上的这两项不起作用（要改到「常用设置」里改）。这样原来正版验证的服务器不会被改成离线，玩家的背包、白名单、管理员都对得上。
  - 1.12 到 1.16.5 的老服务器和新建时一样，加上 log4shell 漏洞的防护。
  - 包里原来的启动脚本（`run.bat`、`user_jvm_args.txt`）不采用，内存按导入页上填的；只写在原来启动脚本里的 JVM 参数要自己到「内存 / 启动」里加。
  - 解压出来的服务器算 MineDeck 新建的：删除时文件夹会一起删（你手里的原压缩包不受影响）。
- 导入失败时，提示里先说一句人话，比如「无法导入整合包：没认出这个压缩包，既没有整合包清单，也看不出是服务端」，怎么办的长说明点「详情」看。

## 其他修复

- 导入交接包失败时，先把装了一半的文件夹清理干净，再显示失败。以前偶尔会出现失败框写着「已经清理干净，可以重试」、文件夹其实还没删完的情况。

## 这一版实际试过的

- 自动测试：Go 测试全部通过；界面交互测试 126 条、界面原型 107 个场景，在仿真后端上全部走通。
- **OpenFrp 的 frpc 下载**：在一台 Windows 11 上按程序的真实代码走了一遍接口和三个下载源，能下到真的 frpc 并解压出来。
- **frpc 被杀毒软件拦下**：用杀毒软件的标准测试串让 Windows 自带的防护真的拦了一次，隧道报出来的是那句中文说明。
- **导入现成服务端压缩包**：用编出来的程序走了一遍接口，一个套了一层文件夹的 Paper 服务端压缩包导入成功，正版验证保留原样、端口改成了导入页填的，包里的启动脚本和 MineDeck 自己的登记文件没有被采用；一个什么都不是的压缩包，报出来的是那句人话。用的是造出来的服务端，没有拿真的 Server Pack 开服进游戏。
- **选文件夹的窗口、最小窗口**：在真程序里试过，选文件夹挂在主窗口上、开着时主窗口不能点，窗口拖到最小停在 1024×576。
- 代码由别家模型交叉审过：界面优化由 Gemini 审过，文案和报错这一轮由 Codex 审了四轮，导入现成服务端这一块由 Claude 的独立评审员审过、修改后又交 Codex 审了一轮，找出的问题都改了。

## 已知情况

和 beta.2 相同的几条见 [v3.1.0-beta.2 的发布说明](https://github.com/Trasperioooooon/MineDeck/releases/tag/v3.1.0-beta.2)里的「已知情况」（交接包不能超过 8 GB；CurseForge 上的整合包多数是给客户端用的，装出来的服务器常常开不起来）。这一版新增的：

- **整合包和现成服务端压缩包**：包装文件夹只认一层；整包里只能有一处整合包清单；几个文件夹都像服务端时不猜，会让你只打包一台。Quilt 仍不支持。服务端的版本如果只写在 `logs/latest.log` 里，这次认不出来，用「接管已有服务器」自己填。
- **报错的长说明**：后端给的原因带着文件路径、英文的系统报错，或者超过 60 个字时，提示里只写结论，原因要点「详情」看。隧道卡片上的失败原因照旧整句显示。
- **常用设置里 1.21.9 以上的几个游戏规则开关**（命令方块、PVP、下界、刷怪）：开关的初始状态按 `server.properties` 里的旧值显示，不看服务器当前的游戏规则。文件里没有这一项时，命令方块会显示成关，其实游戏里默认是开。
