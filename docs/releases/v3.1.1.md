这是 MineDeck v3.1.1，修了 v3.1.0 里的几个问题，另外收紧了几处安全上的细节，没有新功能。

## 怎么升级

用着 v3.1.0、v3.0.0 或者 3.1.0 测试版的，打开「设置 → 更新与关于」，点「检查更新」就能升到 3.1.1。服务器、Java、设置和 AI Key 都会接着用。更新前先停掉正在运行的服务器。

有一件事要先知道：点了更新以后，换程序的是旧版本自己带的更新脚本。v3.1.0 和以前的这个脚本有毛病，有两种情况换不了程序（见最后「已知情况」第一条），从这些版本升到 3.1.1 时还可能碰上，照那里的办法处理就行。3.1.1 自己的更新脚本已经修好，以后从 3.1.1 往后升级就不会了。

## 修了什么

- **点了更新换不了程序**：以前的更新脚本把程序所在的文件夹直接写进脚本，中文系统读这份脚本时，中文路径会变成乱码；开机自动启动的 MineDeck，当前目录又不在自己的文件夹里，于是程序换不了，关掉以后也不会再打开。文件夹名字里有 % 也会这样。电脑的 PATH 里要是有别的 `find` 程序排在系统自带的前面，脚本不等旧程序退出就去换，同样换不成。现在这几种情况都能换好。实在换不成（比如杀毒软件一直锁着文件），会把旧版本重新打开，不会什么都没有；旧程序一直没退出的话，也不会再打开第二个。
- **窗口版里的外部链接用你自己的浏览器打开**：以前点 EULA、申请 CurseForge Key、openfrp.net 这些链接，弹出来的是 WebView2 自带的简易窗口，用不了自己浏览器里的密码管理器、扩展和登录状态。现在交给系统默认浏览器，Ctrl 点、中键点也一样。从局域网用浏览器打开 MineDeck 时照旧。
- **窗口版里把文件或链接拖进窗口，窗口不会跳走**：以前把文件或网页链接拖到窗口里（待装清单以外的地方），WebView2 会把整个窗口换成那个文件或网页，窗口版没有返回键，只能退出重开（待补：3.1.0 上的这个旧行为还没在真窗口里核实，手测清单第 7-0 步做对照）。现在没地方接的拖放，光标显示不能放，松手没有反应。待装清单的「从电脑添加」照旧能把 jar 拖进去，输入框照旧能拖进文字。
- **端口被占着时马上提示**：以前别的程序只占着 0.0.0.0、127.0.0.1 这类地址上的同一个端口时，MineDeck 查不出来，点「启动」照样起服务器，要等服务器自己报错。现在照服务端绑端口的办法查，被占着就直接说「端口 25565 被别的程序占着」。崩溃自动重启和定时重启碰上端口还没放开，会先等几秒，不再连着撞三次。
- **自定义 frps 的凭据能清掉**：存过 token 的自定义 frps 隧道，卡片上多了「清除凭据」，清掉以后启动不带 token。以前只能删掉隧道重建。
- **run.bat 里的感叹号**：有人在注册表里给 cmd 全局打开了延迟展开的话，手动双击 run.bat 时，名字和参数里成对的感叹号之间的字会被换掉。现在不会了。

## 几处安全加固

都是 v3.1.0 正式版前检查时记下、说好下个版本收掉的，前提都比较少见。

- **读写配置不会顺着目录联接跑到服务器文件夹外面**：服务器文件夹里有指到外面的目录联接或符号链接时，经过它的配置文件，在 MineDeck 里读不了也改不了。以前这一步查不清就放行了。
- **换 AI 服务商时写盘失败，不会把旧 Key 发到新地址**：设置和 Key 要么一起生效，要么都不生效。
- **局域网登录的设备看不到完整的 Webhook 地址**：只显示地址的开头，后面常带着令牌的部分藏起来了，要改就整个重填。本机照旧看完整的地址。
- **导入时统一检查 Windows 文件名**：现成服务端压缩包、整合包和交接包里，`CON.txt`、`COM1.log` 这类设备名，结尾是点或空格的名字，不再收下。只差大小写的两个文件在 Windows 上是同一个，以前后一个悄悄盖掉前一个，现在会写进任务日志。

## 升级以后要留意的

- 服务器文件夹里用目录联接把 config 或 world 挪到了别的盘的，经过联接的配置文件在 MineDeck 里读不了也改不了，要直接去那个文件夹里改。
- 交接包里有 `CON.txt` 这类名字的，整个包导入不进来。这类名字在 Windows 11 上建得出来，3.1.0 在这种电脑上导出的包里可能有。在原来的电脑上把那个文件改个名字，再导出一次就行；3.1.1 导出时会把这类文件留在包外，写进剔除清单。
- 从局域网打开「通知与集成」时，Webhook 地址只显示开头。
- 端口被占着时，「启动」直接报错，不再先起服务器。

## 已知情况

- **从 3.1.0 及以前的版本升级时，可能换不了程序**：换程序的是旧版本的更新脚本，它在两种情况下换不成。一种是 MineDeck 装在名字里有中文（或者别的非英文字符）的文件夹里，而这次的 MineDeck 是开机自动启动的：点了更新以后程序关掉，就不会再打开，也没有提示。另一种是电脑的 PATH 里有别的 `find` 程序排在系统自带的前面（装过 MSYS2、Cygwin 一类工具的电脑可能这样）：程序会重新打开，但还是旧版本。两种情况下，新版本都已经下载好、校验过，放在 `MineDeck.exe` 旁边，叫 `MineDeck.new.exe`，服务器和设置都不受影响。第一种情况，双击 `MineDeck.exe` 打开，再点一次更新就行。两种情况都可以手动换：先退出 MineDeck（在托盘图标上右键退出），把 `MineDeck.exe` 删掉，再把 `MineDeck.new.exe` 改名成 `MineDeck.exe`。
- 和 v3.1.0 相同的几条（交接包和整合包的大小上限、客户端整合包、待决文件只在这次运行里有效、没有数字签名等）见 [v3.1.0 的发布说明](https://github.com/Trasperioooooon/MineDeck/releases/tag/v3.1.0)。
