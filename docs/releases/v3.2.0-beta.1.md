> **这是测试版**，给自己和好友试用、找问题的，可能还有毛病。
> - 请放进一个新的空文件夹里运行。要拿已有的服务器试，先把整个服务器文件夹备份一份；这一版新加的「换地图」会搬动世界文件夹，更要先备份。
> - 用着 v3.1.2 的不会收到这个版本的更新提示，要试的话手动下载下面的 `MineDeck.exe`。
> - 正式版会是 v3.2.0，装了测试版的人到时能在「设置 → 更新与关于」里直接更新。

和 v3.1.2 比，这一版加了三样东西：拿一张已有的地图开服、给服务器换地图；在 MineDeck 里连上 OpenFrp 和樱花的账户；内置 AI 助手的显示和对各家服务商的兼容。另外收紧了「仅本机」的判定，下载、备份、上传这些写磁盘的地方也整个加固了一遍。

## 用已有的地图开服、换地图

手里有一张 Java 版的地图（下载来的冒险、空岛地图，自己单人玩了很久的存档，朋友发来的旧服世界），现在可以直接拿它开服，或者把服务器正在用的地图换成它，换了以后还能换回来。完整的说明在[《用已有的地图开服、换地图》](https://github.com/Trasperioooooon/MineDeck/blob/main/docs/地图导入-使用说明.md)，这里说要点。

- **拿地图开一台新服务器**：在「新建服务器」里选「用已有地图开服」，先选地图。MineDeck 读出地图最后是用哪个版本存的、用过什么核心，替你预选同样的版本和合适的核心。地图在服务器建好之前放进去，放不进去整台就不建。
- **给现有的服务器换地图**：服务器详情的「地图」页，点「导入并替换当前地图」。在这台电脑上可以直接选地图文件夹；别的设备上用网页打开的，上传地图的 ZIP（最大 8 GB）。
- **先看预览再动手**：预览里写着地图的版本和服务器的版本、找到了哪些维度、带了哪些数据包和资源包、有没有用过模组的迹象、会换掉哪些文件夹。红色的是不能导入的原因，黄色的要勾「我已了解」才能继续。
- **旧地图一个文件都不删**：换的时候，原来的地图连同下界、末地整体移进「恢复点」。「地图」页下面列着每次导入留下的恢复点，点「恢复导入前的地图」就能换回去。恢复点一直留到你手动删除。
- **换到一半出了问题会自动退回**。换图的时候 MineDeck 被关掉或者电脑断电，下次打开时它会先把这台服务器恢复到换图之前，恢复好之前这台服务器不能启动。
- **版本对不上**：地图比服务器新的不能导入，请新建一台和地图同版本的服务器；地图比服务器旧的可以导入，但要确认，服务器第一次启动时会把这份副本升级成新格式。
- **认得出不是地图的东西**：基岩版存档、建筑蓝图、资源包、数据包、整合包、交接包，会告诉你它是什么、该去哪；`.rar`、`.7z` 和加密的压缩包请先解开。

这一版不做的：不会改写玩家文件（单人存档转服务器时，背包接不接得上取决于主人用什么账号进服，预览里有说明）；地图带的资源包不会自动发给玩家；世界文件夹本身是链接的服务器不支持换地图；多世界插件建的其他世界不会动。

## OpenFrp 和樱花的账户

这一部分由 [awaxiaoyu](https://github.com/awaxiaoyu) 贡献。

- 在「内网穿透」页的「平台账户」里可以连上自己的 OpenFrp 账户（远程授权）或者樱花的账户（访问密钥），看到账户概览，手动签到，跳到官网的购买入口。
- OpenFrp 的隧道可以直接在 MineDeck 里创建，也可以把平台上已有的隧道导进来。
- 账户的凭据加密保存在这台电脑上。连接账户、签到、建隧道这类会改动账户的操作只能在运行 MineDeck 的这台电脑上做，局域网里别的设备做不了。

## 内置 AI 助手

- **回复的排版**：标题分级显示；表格、列表、勾选框、删除线、斜体按 Markdown 的样子显示；代码块保留语言，带复制按钮，还没写完的代码块会标出来，不再把前面的段落吞掉。回复不渲染图片，链接只认 `http` 和 `https`。
- **思考内容**：模型给出的思考过程会转发出来，默认折叠着。
- **面板可以拖宽**，宽度记在这台设备上。
- **选模型**：模型框可以手填，也可以点箭头拉取服务商的模型列表、在里面搜。服务商不提供模型列表时，退回预设里的建议模型。
- **兼容更多服务商**：OpenAI 兼容的服务商可以选鉴权方式；需要每一轮都把思考内容带回去的服务商（比如 DeepSeek）现在能正常连续调用工具；Key 和地址对不上时会提醒。新加了小米 MiMo 的预设。
- **测试连接**会多走一轮工具调用，能提前发现「第一轮能过、交回工具结果就报错」的服务商。
- 报错的短句分得更细：额度用完、请求太频繁、Key 不对、地址不对分开说。

## 「仅本机」收紧了

- **算本机要两样都有**：连接来自这台电脑，并且带着这次启动的令牌（MineDeck 自己的窗口和启动地址里带着）。以前只看连接是不是来自这台电脑，经本机的隧道程序转发进来的请求也会被当成本机。
- **会变的只有一种用法**：在主机自己的浏览器里不带令牌打开 MineDeck、用访问密码登录。以前这样算本机，现在只有局域网会话的权限，选文件夹、改 AI 设置这类「仅本机」的操作要回到 MineDeck 的窗口里做。局域网设备和 MineDeck 自己的窗口用法不变。
- **隧道不能指向 MineDeck 自己的网页端口**：自定义 frps 隧道的本地端口如果是 MineDeck 这次的网页端口，新增、修改、启动都会拒绝。
- 操作记录里的凭据遮得更全了；隧道日志里也会遮掉这次启动用的凭据。

## 其他改动

- **新建服务器、导入整合包可以取消**：任务页上有「取消创建」，会等半成品清理完再结束。已经开始登记的最后一步不能取消。
- **整合包导入完成之前不出现在服务器列表里**，不会再有一台看着建好了、其实文件还没放全的服务器。导入失败时半成品会清掉。
- **待决文件**只能补进 `mods`、`plugins`、`config`、`resourcepacks`、`datapacks` 这类普通文件夹；世界和 `server.properties` 请走「地图」页和设置页。
- **备份**：同一台服务器的两次备份排队做；服务器在热备的过程中重启了，这次备份会作废、不留半份。还原之前先检查压缩包能不能打开、里面的路径对不对，检查没过不会动现有的世界。
- **磁盘**：复制地图、备份、解包这类大量写文件的操作，落在同一个磁盘上时排队进行，开始前和过程中都会看磁盘还剩多少。磁盘剩余不到 256 MB 时，下载和备份会直接告诉你空间不够。
- **上传**（地图、整合包、交接包、本地模组）：30 秒没有收到新数据会停下并提示重新上传；超过上限的当场拒绝，不用等传完。
- **打开压缩包之前先看它申报的大小**：包尾写着几百万个文件的压缩包会直接拒掉，不会先按这个数去要内存。导入、还原备份、下载来的 Java 和 frpc 都过这一道。
- 保存设置和配置文件时，两个窗口同时改不会再互相盖掉；程序被打断时不会留下写了一半的文件。

## 已知情况

- **AI 的一次回复有大小上限**（8 MiB，按收到的原始数据算）。带很长思考过程的模型，一次回复有可能碰到上限，这时这一轮会停下并提示「回复内容过多」。碰到了请告诉我们用的是哪家的哪个模型。
- **隧道的凭据短于 6 个字符时**，日志里凡是包含它的行会整行换成「日志含凭据，已隐藏」。凭据特别短的话，会有不少不相干的行被隐藏，排查问题时不方便。
- **查不出剩余空间的磁盘**（少数网络盘、特殊的挂载方式）：地图导入会多一条要你确认的事项；上传地图会被拒绝，请改成在这台电脑上直接选文件夹。下载和备份照常。
- **备份的文件名变长了**，时间后面多了一串数字，是为了让同一秒里的两次备份不重名。
- **整合包导入到一半时程序被关掉**，会在存放位置里留下一个文件夹，不出现在列表里，可以直接删掉。
- **没有数字签名**：第一次运行时，Windows 可能提示「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。
- v3.1.0 发布说明里「已知情况」的其余几条（交接包和整合包的大小上限、CurseForge 整合包多数是给客户端用的、待决文件要在这次运行里处理完等）仍然适用，见 [v3.1.0 的发布说明](https://github.com/Trasperioooooon/MineDeck/releases/tag/v3.1.0)。
