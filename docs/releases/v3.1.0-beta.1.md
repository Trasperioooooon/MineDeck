> **这是测试版**，给自己和好友试用、找问题的，可能还有毛病。
> - 请放进一个新的空文件夹里运行。要拿已有的服务器试，先把整个文件夹备份一份。
> - 用着 v3.0.0 的不会收到这个版本的更新提示，想试要手动下载 `MineDeck.exe`。
> - 正式版会是 v3.1.0，装了测试版的人到时能在「设置 → 更新与关于」里直接更新。

这一版加了三个功能：把一台服务器整个打包交给别人接着开；自己挑模组放进购物车、前置自动补齐、一次装好；导入整合包时遇到下载不了的文件可以逐个处理。另外带上了 v3.0.0 之后已经合进来、还没发过的几项改动。

## 新功能：把服务器打包交给别人

自己开的服不想开了，可以整台交给朋友接着开；也可以打一份发给朋友，让他照着在自己电脑上开一台。

- **打包的人**：停掉服务器，在服务器卡片的「···」菜单里点「交接给其他电脑…」，选这个包给谁（交给下一任服主，还是发给朋友照着开一台），再选一个文件夹，会生成一个 `.mdpack` 文件。把它发给对方，微信、网盘都行。打包的时候这台服务器不能启动，也不能删除。
- **收包的人**：在「新建服务器」页选「导入交接包」，选这个文件，填名称和端口，等它装完就能启动。Java 和服务端核心按收包那台电脑的情况重新准备，Java 版本可以自己选。给收包的人准备了一份[上手指南](https://github.com/Trasperioooooon/MineDeck/blob/v3.1.0-beta.1/docs/接收者上手指南.md)，可以连同包一起发过去。
- **包里有什么**：存档（多世界插件建的其他世界也带）、`server.properties`、核心自己的配置（`spigot.yml`、`bukkit.yml`、`paper.yml` 这些）、`mods`、`plugins`、`config`、整合包的 `kubejs` 和 `scripts`、白名单和管理员名单。
- **包里没有什么**：日志、崩溃报告和服务端核心。核心在导入时重新下载；勾上「完整模式」就连核心一起带，包会大不少。服务器文件夹里别的东西（比如地图插件在根目录生成的瓦片、自己放的文件）不带，打包时会在日志里一条条列出来，对方需要的话另外拷给他。

收包的人要知道三件事：

- 包里的模组和插件是对方电脑上带过来的程序，启动服务器时会在你的电脑上运行。只导入信得过的人给的包。
- 原来的 JVM 参数、定时任务和崩溃自动重启不会带过来，原来开着的 RCON 会先关掉，导入完成后的日志里会列出原来有哪些，需要的话自己再加。游戏内 AI、AI 伙伴和音乐共享也要在收包的电脑上重新打开。
- 包里原服主同意过 Minecraft EULA 的，导入时可以不用再勾。

打包的人要知道两件事：

- 包里有玩家的存档、白名单和管理员名单，交之前先和服里的人说一声。
- 配置文件是原样进包的，里面写着的密码也会一起交出去，比如 `server.properties` 里的 RCON 密码、插件配置里的数据库密码和机器人令牌。在别处也用着的，先改掉再交。

## 新功能：自己挑模组，放进购物车一次装好

不用整合包、自己选核心开服的时候，以前只能在「资源」页一个一个搜、一个一个装，前置要自己找，装错了服务器起不来。

- **在哪里**：新建服务器的向导里多了可选的一步「选模组」（原版没有这一步）；每台模组服、插件服的详情页多了「购物车」标签。
- **怎么用**：搜到想要的模组或插件，点「加入购物车」，凑齐以后点「安装全部」。安装前可以点「检查依赖」，缺的必装前置会列出来；不检查也会在安装时自动一起装上。向导里挑的会在服务器建好以后自动装。
- **装的是什么**：都从 Modrinth 下载，按当前的核心和 Minecraft 版本挑兼容的版本，下载下来要对得上 Modrinth 给的校验值。服务器里已经有的不重复装；只在客户端用的模组不会放进购物车。
- **AI 助手也能用**：可以让 AI 助手帮你搜、帮你往购物车里放。真正往服务器里装的时候，AI 只能提出来，卡片上会逐个列出要下载的文件，你点了确认才装。购物车在你看过以后被改过的话（比如 AI 又加了东西），点安装会被拦下，让你先看一眼现在的清单。

## 新功能：整合包里下载不了的文件，逐个处理

以前导入整合包时，只要有一个文件的下载地址不在允许的站点里（Modrinth、GitHub、GitLab），或者没有校验值，整个整合包都导不进来。魔改过的模组常常挂在作者自己的网站上，这样的整合包就没法用。

现在整合包照常导入，下载不了的文件列在任务页的「待处理」里，每个文件自己选怎么办：

- **跳过**：不要这个文件。
- **用本地的文件**：给出一个文件或文件夹，原样复制进去，不校验内容。手里有魔改模组的 jar 就用这个。
- **信任这个站点后下载**：只对 https 的公网地址有效，要先看一遍风险说明并确认。下载下来的内容必须对得上整合包给的校验值，对不上不会留下。确认过的站点会记住，以后同一个站点的文件直接下载。

导入表单上多了一个可选的「本地来源目录」：填上以前那台服务器的文件夹，下载不了的文件里凡是那里有的，会自动原样拿过来。

模组声明要用的 Java 比这台服务器现在用的新时（比如 1.20.1 的服配了要 Java 25 的模组），导入完成页和服务器详情页会提醒，并给出去「内存 / 启动」换 Java 的入口。只是提醒，不拦着你启动。

## v3.0.0 之后的其他改动

- **接管已有服务器**：「新建服务器」页可以选一个以前自己开的服务器文件夹，MineDeck 认出核心、版本和启动文件后就地登记进来。文件不搬，存档和配置不动。
- **在界面上换 Java**：每台服务器的「内存 / 启动」页多了 Java 选择框，能选 MineDeck 下载的、电脑上装的，或者现下一个。
- **移出列表**：删除服务器时不勾「同时删除服务器文件夹」，就只是从列表里拿掉，以后还能接管回来。
- **后台任务不再丢**：部署到一半切到别的页面或者刷新，回来还能找到进度。这一项是 awaxiaoyu 贡献的。
- 鼠标移到链接上时，窗口左下角不再冒出网址。
- **修复**：`server.properties` 里的世界目录名（level-name）写成指到服务器文件夹外面时，备份和还原会跟着找到外面去，还原时可能删掉别的文件夹。现在这种写法一律按默认的 `world` 处理。

## 已知情况

- **待处理的文件要在这次运行里处理完**：关掉 MineDeck 再打开，任务页上的待处理清单就没有了，只剩服务器文件夹里的「导入待决清单.txt」，要自己照着把文件放进去。
- **信任过的站点没有地方取消**：目前要手动改 `config.json` 里的 `trustedHosts`。
- **导入交接包被打断**（关程序、断电）时，建到一半的文件夹会留在存放位置里，不会出现在服务器列表中，可以直接删掉。
- **向导里挑的模组放在一辆「草稿」购物车里**，它不记是给哪种核心挑的。挑了模组以后回头换了核心，或者上次挑完没建成服，下次建服时这些模组可能装不上，任务页会写「找不到能装的版本」。遇到了就到新服务器的「购物车」标签里重新挑。
- **购物车一次能带出多少前置没有上限**：前置很多的模组，检查依赖和安装会慢一些。
- **没有数字签名**：第一次运行时，Windows 可能提示「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。
