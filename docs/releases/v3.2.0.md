这是 MineDeck v3.2.0 正式版。

和 v3.1.2 比，这一版加了几样东西：拿一张已有的地图开服、给服务器换地图；在 MineDeck 里连上 OpenFrp 和樱花的账户；AI 助手的排版和对各家服务商的兼容；左侧栏的「工具箱」；检查更新时可以选「稳定版」还是「最新版」。界面按一次可用性走查的结果整理了一遍，「仅本机」的判定收紧了，下载、备份、上传这些写磁盘的地方也加固了一遍。这些在 v3.2.0-beta.1 到 beta.5 里陆续发过测试版，下面合在一起说，每一项更细的说明见 [beta.1](https://github.com/Trasperioooooon/MineDeck/blob/v3.2.0-beta.1/docs/releases/v3.2.0-beta.1.md)、[beta.2](https://github.com/Trasperioooooon/MineDeck/blob/v3.2.0-beta.2/docs/releases/v3.2.0-beta.2.md)、[beta.3](https://github.com/Trasperioooooon/MineDeck/blob/v3.2.0-beta.3/docs/releases/v3.2.0-beta.3.md)、[beta.4](https://github.com/Trasperioooooon/MineDeck/blob/v3.2.0-beta.4/docs/releases/v3.2.0-beta.4.md)、[beta.5](https://github.com/Trasperioooooon/MineDeck/blob/v3.2.0-beta.5/docs/releases/v3.2.0-beta.5.md) 的发布说明。

## 怎么升级

用着 v3.1.2 或 v3.1.1 的，打开「设置 → 更新与关于」，点「检查更新」就能直接升到 3.2.0。服务器、Java、设置、隧道和 AI Key 都会接着用：它们都存在程序所在的文件夹里，换程序不用动它们。更新前先停掉正在运行的服务器，有服务器开着时不会更新；保险起见，可以先把整个 MineDeck 文件夹备份一份。要手动替换 `MineDeck.exe` 的，先完全退出 MineDeck（在托盘图标上右键退出），再替换。

从 v3.1.0、v3.0.0 或者 3.1.0 测试版也可以在程序里直接升。只是这时换程序的是旧版本自己带的更新脚本，它有两种情况换不成；新版本这时已经下载好、放在旁边，处理办法见下面「已知情况」的第一条。

用着 3.2.0 测试版的：

- **beta.3、beta.4、beta.5**：不管更新渠道选的是「稳定版」还是「最新版」，检查更新都能查到 3.2.0，直接升。
- **beta.1、beta.2**：这两版检查更新只看正式版。3.2.0 就是正式版，也能直接查到、直接升，不用再手动换程序。
- **没选过更新渠道的**，升到 3.2.0 以后按稳定版查，只提示正式版。还想接着试以后的测试版，到「设置 → 更新与关于」里选「最新版」。
- **用过 beta.1 到 beta.3、又把服务器里的文件设成过只读的**：那几版保存只读文件时会报成功、其实没存上，文件夹里可能多出一个名字是原文件名后面跟着一串乱码的文件。怎么查、怎么处理，见 [beta.4 的发布说明](https://github.com/Trasperioooooon/MineDeck/blob/v3.2.0-beta.4/docs/releases/v3.2.0-beta.4.md) 里「请留意」那一段。没设过只读的不会碰上。

## 用已有的地图开服、换地图

手里有一张 Java 版的地图（下载来的冒险、空岛地图，自己单人玩了很久的存档，朋友发来的旧服世界），现在可以直接拿它开服，或者把服务器正在用的地图换成它，换了以后还能换回来。完整的说明在[《用已有的地图开服、换地图》](https://github.com/Trasperioooooon/MineDeck/blob/v3.2.0/docs/使用指南/地图导入-使用说明.md)，这里说要点。

- **拿地图开一台新服务器**：在「新建服务器」里选「用已有地图开服」，先选地图。MineDeck 读出地图最后是用哪个版本存的、用过什么核心，替你预选同样的版本和合适的核心，不会自作主张换成最新版。地图在服务器建好之前放进去，放不进去整台就不建。
- **给现有的服务器换地图**：服务器详情的「世界与备份 → 换地图」，点「导入并替换当前地图」。在这台电脑上可以直接选地图文件夹；别的设备上用网页打开的，上传地图的 ZIP（最大 8 GB）。服务器开着时勾「停服并导入」，MineDeck 会让服务器自己存盘退出，等不到它停下就放弃，一个文件都不换。
- **先看预览再动手**：预览里写着地图的版本和服务器的版本、找到了哪些维度、带了哪些数据包和资源包、有没有用过模组的迹象、会换掉哪些文件夹。红色的是不能导入的原因，黄色的要勾「我已了解」才能继续。地图建议改的设置（难度、默认游戏模式这些）默认不改，你勾了才改。
- **旧地图一个文件都不删**：换的时候，原来的地图连同下界、末地整体移进「恢复点」。「换地图」页下面列着每次导入留下的恢复点，点「恢复导入前的地图」就能换回去。恢复点不会被备份轮换挤掉，一直留到你手动删除。
- **换到一半出了问题会自动退回**：换图的时候 MineDeck 被关掉或者电脑断电，下次打开时它会先把这台服务器恢复到换图之前，恢复好之前这台服务器不能启动。
- **版本对不上**：地图比服务器新的不能导入，请新建一台和地图同版本的服务器；地图比服务器旧的可以导入，但要确认，服务器第一次启动时会把这份副本升级成新格式。
- **认得出不是地图的东西**：基岩版存档、建筑蓝图、资源包、数据包、整合包、交接包，会告诉你它是什么、该去哪；`.rar`、`.7z` 和加了密码的压缩包请先解开。

这一版不做的：不会改写玩家文件（单人存档转服务器时，背包接不接得上取决于主人用什么账号进服，预览里有说明）；地图带的资源包不会自动发给玩家；世界文件夹本身是链接的服务器不支持换地图；多世界插件建的其他世界不会动。

## OpenFrp 和樱花的账户

这一部分由 [awaxiaoyu](https://github.com/awaxiaoyu) 贡献。

- 「内网穿透」页的「平台账户」里，可以连上自己的 OpenFrp 账户（在浏览器里授权，MineDeck 不收账号密码）或者樱花的账户（粘贴访问密钥），看账户、流量和平台上的隧道。
- 可以在 MineDeck 里直接到平台上新建隧道（TCP 或 UDP），建好就导进来；平台上已有的隧道也能导进来。樱花建隧道时可以勾「这是公开服务器」，勾了只列公开服专用的节点：这是樱花的规定，用错节点会被封号。
- 签到和购买都是打开官网，MineDeck 不代签、不代下单。
- 账户的凭据加密保存在这台电脑上。连接账户、签到、建隧道、导入隧道只能在运行 MineDeck 的这台电脑上做，局域网里别的设备打开时只能看。断开账户只清掉凭据，已经导入的隧道不动。

## AI 助手

- **回复的排版**：标题分级显示；表格、列表、勾选框、删除线、斜体按 Markdown 的样子显示；代码块保留语言，带复制按钮，还没写完的代码块会标出来，不再把前面的段落吞掉。回复不渲染图片，链接只认 `http` 和 `https`。
- **思考内容**：模型给出的思考过程会转发出来，默认折叠着。
- **面板可以拖宽**，宽度记在这台设备上。
- **选模型**：模型框可以手填，也可以点箭头拉取服务商的模型列表、在里面搜。服务商不提供模型列表时，退回预设里的建议模型。
- **兼容更多服务商**：OpenAI 兼容的服务商可以选鉴权方式；需要每一轮都把思考内容带回去的服务商（比如 DeepSeek）现在能正常连续调用工具；Key 和地址对不上时会提醒。新加了小米 MiMo 的预设。
- **测试连接**会多走一轮工具调用，能提前发现「第一轮能过、交回工具结果就报错」的服务商。
- **报错分得更细**：额度用完、请求太频繁、Key 不对、地址不对分开说。

## 工具箱

左侧栏「内网穿透」下面多了一项「工具箱」，放和朋友一起玩时用得上的小工具。两个工具都不改任何服务器里的文件。生成的文件可以直接下载；在运行 MineDeck 的这台电脑上，也可以顺手存到一个文件夹里。

- **离线皮肤包**：离线模式的服务器上，大家都顶着默认皮肤。把朋友们的皮肤 PNG 放进来，MineDeck 按每个人的玩家名算出游戏会给他用哪一个默认皮肤，把皮肤图换进去，打成一个资源包。每个朋友把这个资源包放进自己客户端的 `resourcepacks` 文件夹并启用，就能看到彼此的皮肤。也可以不按玩家名、按顺序替换。支持 1.8 及以后的版本，老的 64×32 皮肤会自动扩成现在的格式。
  - 默认皮肤的位置是游戏按玩家名定死的：1.19.3 起有 18 个，更早只有 Steve 和 Alex 两个。人一多，两个人撞进同一个位置的机会不小（5 个人大约四成），撞上了只能二选一，页面上会标出来让你选。手臂是粗是细也是游戏按玩家名定的，资源包改不了，对不上的看起来会有点别扭。
  - 想让服务器自动把资源包推给进服的人，要自己把它放到网上能直接下载的地方，再在服务器的「设置 → 全部配置」里填 `resource-pack` 和 `resource-pack-sha1`（生成时附带了 SHA-1）。工具箱不会改服务器的配置。
- **导出整合包（Modrinth 的 .mrpack 格式）**：从已有的模组服务器导出它的模组（可以选带上 `config` 文件夹），或者自己挑模组，MineDeck 找齐必装的前置。导出的文件用 Modrinth App、Prism、HMCL、PCL2 这些启动器都能一键安装。
  - Modrinth 上能找到的模组只写下载地址，朋友安装时从官方下载；找不到的（自己改过的、只在别处发布的）整个打进包里，分享前请留意原作者是否允许转发。
  - `config` 文件夹默认不带。勾上的话，看起来放着密码、令牌、密钥、数据库的配置文件会尽量挑出来不打进包，预览里列出跳过了哪些；认不出的写法难免有，打进去的配置文件也都列在预览里，发之前请看一眼。
  - 自己挑的这份清单是工具箱自己的，和新建服务器时挑的模组分开，只在客户端用的模组（小地图、光影加载器之类）也能挑。音乐共享用的语音桥模组只在服务端用，不会打进包；AI 伙伴模组朋友的客户端要装，照常带上。

## 更新渠道

「设置 → 更新与关于」里可以选「稳定版」或「最新版（包括测试版）」。稳定版只提示正式版；最新版连测试版一起提示，按版本号挑最新的。没选过时，用着正式版按稳定版查，用着测试版按最新版查。不会提示比你现在用的更旧的版本：用着测试版又选了稳定版，在下一个正式版出来之前不会有更新提示。不管哪个渠道，下载的程序都要和官方发布的 `SHA256SUMS` 对得上才会换上。

## 界面：按可用性走查整理了一遍

服务器详情页的标签从十几个收成七个，连接地址、启动失败的原因、端口被占这些「出了事要马上看到」的信息放到了页头上；新建、导入的流程补上了取消、返回修改和没装上的文件的后续处理；各处的叫法统一了一次。

### 服务器详情页

- **标签收成七个**：控制台、玩家、世界与备份、插件 / 模组、定时任务、设置、扩展。原来的「地图」并进了「世界与备份」，叫「换地图」；「资源」和「待装清单」合成一页，上面是已安装的，下面是热门、搜索和从电脑添加；「常用设置」「内存 / 启动」「全部配置」收进「设置」，分别叫「常用」「启动与内存」「全部配置」；游戏内 AI、AI 伙伴、音乐共享收进「扩展」。旧的书签和链接会自动跳到新位置。
- **连接地址在页头和服务器卡片上**：同一个局域网里的朋友要填的 `IP:端口`，点一下就能复制。不在同一个网络的朋友，还是用内网穿透的隧道。
- **出了事放在页头**：上次启动失败的原因、整合包里没装上的文件、Java 找不到了（比如把服务器从别的电脑拷过来）、模组要求更高版本的 Java，有就一直显示在页头的提示区，事情解决了才消失，切到别的页再回来也还在。报错提示落在提示区的下面，不挡「改端口」「去换 Java」这些按钮；开服没成功、原因是找不到 Java 或者端口被占时，提示上直接给「去换 Java」或「改端口」。
- **端口被占了会说清是谁**：被 MineDeck 里另一台服务器占着时，直接说是哪一台，并给「改成 N 并启动」；被别的程序占着时给「改端口」，带你去设置里的端口那一项。
- **加了「重启」按钮**；改了需要重启才生效的设置，保存后的提示和设置项旁边的标注说法一致。
- **服务器信息集中在「设置 → 启动与内存」页顶**：核心、版本、端口、Java、服务器文件夹，能复制、能打开。「打开文件夹」菜单里多了「备份」。
- **备份页写明现在的世界从哪来**：用已有地图新建的、换过地图的，写导入时的来源和时间；换回过的写换回了；从备份还原过的写是哪一份。改过备份存放位置的，写明另有几份旧备份还在原来的哪个文件夹，列表里那几份标着「在原来的文件夹」，照常能还原、能删。
- **还原备份**：还原前要做什么、会不会影响正在运行的服务器，确认框里一次说清。

### 新建、导入和接管

- 「新建服务器」页有五种方式，「用已有地图开服」单独成了一张卡片。
- **默认端口避开被占着的**：新建、导入整合包、用已有地图开服时，默认端口被 MineDeck 里别的服务器、或者这台电脑上别的程序占着的话，换成下一个空着的，端口框下面写明换了、被谁占着；手填的端口被占着会提示一句，不拦你。接管已有服务器时，端口和 MineDeck 里别的服务器撞了的，换成空着的并写明，确认接管时写回它的 `server.properties`；被别的程序占着的只提示、不换（多半是原来那台服务器还开着，先把它停掉）。查的是系统里正在监听的端口，不会让防火墙弹窗。
- **整合包里没装上的文件会一直留着**：以前要在那一次运行里处理完，关了程序就找不回来。现在服务器详情页头会一直提示有几个整合包文件没装上，点开能逐个处理，跳过的以后也能在插件 / 模组页再处理。
- **可以取消、可以返回修改**：新建服务器、导入整合包、导入现成服务端可以在任务页取消，会等半成品清理完再结束，显示「已取消」，不当成失败；点「返回修改」回到原来的表单，填过的都还在。换地图取消了也显示「已取消」，并写明没有替换任何文件。任务页上正在进行的、出了问题的排在前面，做完的折起来。
- 选构建版本默认收进「高级」；选插件这一步能跳过；同意 EULA 的开关不会被底部的按钮挡住。

### 删除、弹窗和提示

- **删除服务器默认只「移出列表」**，文件夹留着（见下面「升级以后要留意的」）。移出接管来的服务器时，会说清楚 MineDeck 在那个文件夹里留下了哪些文件。
- 弹窗里报错时，填好的内容不会丢；弹窗叠着开时，Esc 只关最上面那一层。
- 报错提示至少停留 20 秒，鼠标停在上面或打开了详情时不会消失。

### 内网穿透和设置

- **隧道可以编辑**：名称、绑定的服务器、跟随服务器启动都能改；凭据留空就沿用原来的，换了服务商或服务器地址才要重新填。隧道卡片上信息更全。
- 内网穿透页顶写明：同一个局域网的朋友不用隧道，直接用服务器页上的连接地址。「添加隧道」和「平台账户」是什么关系也写清楚了。
- 设置里原来的「远程访问」改叫「手机远程管理」，说的是用手机或别的电脑的浏览器打开 MineDeck 的管理页，和朋友进游戏的地址无关。
- 「设置 → AI」页顶说明三样 AI 各是什么：标题栏上的「AI 助手」、服务器里的「游戏内 AI」、陪玩的「AI 伙伴」。
- 「点关闭按钮时缩到托盘」开关的说法改清楚了，第一次缩到托盘时会提示一次；侧栏底部加了「退出 MineDeck」。
- 导出交接包时，选的文件夹不存在可以「新建并导出」。存放位置改了以后可以撤销。
- 工具箱「导出整合包」读不出存好的草稿时，页面上常驻一条说明，带「重新读取」。

### 正式版前又改的几处

- **页头的主按钮跟着状态走**：服务器详情页的页头，停着时绿色的主按钮是「启动」，运行中、启动中时是「停止」。以前运行中仍把点不了的「启动」画成绿色主按钮。点不了的主按钮改成了灰色。
- **窗口很矮时，命令框留在窗口里**：窗口很矮时（最小窗口 1024×576，或者笔记本屏幕放大以后差不多这么矮），控制台的日志区让出位置，输入命令的框不会被挤到窗口外面，快捷键提示收起来；页头的提示条多、放不下时，整页照常能往下滚到命令框。
- **真的复制成功才说「已复制」**：剪贴板写不进去时，以前也会提示「已复制」。现在写不进去就弹出「请手动复制」的框，里面是完整原文、已经选中：电脑上按 Ctrl+C，手机上长按选中的文字再拷贝。用手机经局域网打开管理页时比较常见。
- **能复制的多了**：「设置 → 手机远程管理」里，放行防火墙的那条命令和管理页地址都有了复制按钮，复制的是完整原文，不带旁边的说明文字，也不含访问密码。隧道卡片上的报错原文加了「复制原文」。
- **AI 助手面板不再盖住启动、停止**：窗口够宽时（让出面板的位置以后，主区还有 720 像素宽），面板打开时主区让到左边，详情页的启动、停止按钮露在面板左侧。窗口不够宽、或者把面板拖得很宽时，面板照旧浮在主区上面，主区的版面不变。
- 深色的「方块」配色里，卡片的边框更清楚；服务器列表的搜索框变宽了。

## 「仅本机」收紧了

- **算本机要两样都有**：连接来自这台电脑，并且带着这次启动的令牌（MineDeck 自己的窗口和启动地址里带着）。以前只看连接是不是来自这台电脑，经本机的隧道程序转发进来的请求也会被当成本机。这样一来有一种用法会变，见下面「升级以后要留意的」第一条。
- **隧道不能指向 MineDeck 自己的网页端口**，也见「升级以后要留意的」。
- 操作记录里的凭据遮得更全了；隧道日志里也会遮掉这次启动用的凭据。

## 写磁盘的地方加固了

- **同一个磁盘上的大活排队做**：复制地图、备份、解包这类大量写文件的操作，落在同一个磁盘上时排队进行，开始前和过程中都会看磁盘还剩多少。磁盘剩余不到 256 MB 时，下载和备份会直接告诉你空间不够。
- **上传**（地图、整合包、交接包、本地模组）：30 秒没有收到新数据会停下并提示重新上传；超过上限的当场拒绝，不用等传完。
- **打开压缩包之前先看它申报的大小**：包尾写着几百万个文件的压缩包会直接拒掉，不会先按这个数去要内存。导入、还原备份、下载来的 Java 和 frpc 都过这一道。
- **还原之前先检查备份**：压缩包能不能打开、里面的路径对不对，检查没过不会动现有的世界。

## 正式版前修的

下面这些是 v3.1.2 里也有、在测试版期间修掉的。测试版自己带进来、后来又修掉的问题，这里不列，见各测试版的发布说明。

- **隧道卡片上的公网地址不会再显示成 `ext.go:37`**。OpenFrp、樱花的隧道启动以后，卡片上的公网地址以前有时不是能连的地址，而是 `ext.go:37` 这样的一串，那是 frpc 日志里标注程序位置的一小段。现在会跳过这类内容，取这一行里真正的地址；地址后面紧跟着别的字符时，端口也不会被截错。域名和 IP 都出现时照旧优先用域名。
- **隧道配置读不出来时，不会再把原来的隧道盖掉**。以前 MineDeck 启动时，`tunnels.json` 要是刚好被别的程序占着（杀毒软件、同步盘），或者文件坏了，隧道页会显示成一条隧道都没有；这时再添加一条，原来的隧道和保存的凭据就全没了。现在读不出来时，隧道页会直接说明原因，读出来之前不能添加、修改、删除或启动隧道，原文件不动；占用放开或者文件修好以后会自动恢复，不用重启。
- **隧道配置写不进磁盘时会告诉你**。以前磁盘满了、文件被设成只读的时候，添加隧道显示成功，重启以后却不见了。现在会提示这次没有保存。在平台上已经建好、只是本机没存上的那一条，会提醒你去「导入」，不要再创建一次。
- **26.1 起的服务器，改了难度重启以后会生效了**。以前改了游戏里不变：从 26.1 开始，游戏把难度存进了世界数据，服务端只在新建世界时读一次 `server.properties` 里的难度，以后改设置不再起作用。现在 26.1 及以后的服务器开好以后，MineDeck 会按设置里的难度补一条 `difficulty` 命令，控制台里能看到这一句。极限模式的世界游戏锁在困难，不发这条命令。这带来一处变化，见下面「升级以后要留意的」。
- **便携 Java 装到一半中断的，下次会重新装**。以前只要 `bin\java.exe` 在，就算这套 Java 装好了；下载或解压到一半被打断（磁盘满了、程序被关掉），留下的半截会被直接拿去开服，报的是 Java 自己的错误，也不会重新下载。现在开始装之前先放一个「还没装完」的记号（`runtimes\java-N.incomplete`），整套装完才拿掉，记号还在的下次会重装；解压失败时把解出来的一半删掉；一开始就按解开以后的总大小查磁盘空间，放不下就不动原来的文件夹。以前装好的 Java 照旧能用。
  - 以前就装坏的那一份没有记号，MineDeck 认不出来。如果你碰到过开服时 Java 报一串看不懂的错、怎么重试都一样，可以看看 MineDeck 文件夹里的 `runtimes`，把那个版本的 `java-N` 文件夹删掉，下次开服会重新下载。
- **整合包导入完成之前不出现在服务器列表里**。以前导入还没做完，列表里就有了一台看着建好了、其实文件还没放全的服务器。现在导入失败时，半成品也会清掉。
- **保存设置和配置文件时程序被打断，不会留下写了一半的文件**。
- **两个窗口同时开着同一台服务器的设置，「常用」「全部配置」不会再把另一边刚存的改回去**。以前这两页保存时把整页的值都写回 `server.properties`：电脑上改了难度并保存，手机上早就开着的设置页再改人数、保存，难度就被改回原样。现在只写这一页改过的项，两边改了同一项的，以后存的为准。别的几处还会这样，见「已知情况」。

## 升级以后要留意的

- **在这台电脑的浏览器里不带令牌打开 MineDeck、用访问密码登录，现在只有局域网会话的权限。** 以前这样算本机；现在选文件夹、改 AI 设置这类「仅本机」的操作会被拒，要回到 MineDeck 的窗口里做，或者用带令牌的启动地址打开。局域网里别的设备和 MineDeck 自己的窗口，用法不变。
- **隧道不能指向 MineDeck 自己的网页端口。** 自定义 frps 隧道的本地端口如果是 MineDeck 这次的网页端口，新增、修改、启动都会拒绝，以前存下的这种隧道也启动不了。隧道该指向游戏服务器的端口。
- **删除服务器默认只「移出列表」。** 文件夹留着，提示里写出文件夹的位置并能直接打开；要连文件一起删，得另外选上。
- **新建服务器时白名单默认关着。** 26.3 起的服务端自己生成配置时默认开白名单、名单又是空的，以前按默认值开出来的服务器，朋友进不来。现在新建、导入整合包、用已有地图开服的表单上有「只允许白名单里的玩家进入」的开关，默认关，旁边写明了。接管已有服务器沿用它原来的设置。
- **26.1 及以后的服务器，难度以「设置」里的为准。** 以前在游戏里用命令改过难度的，第一次用 3.2.0 开服时，难度会改回「设置」里写的那个。想保留游戏里的难度，先到这台服务器的「设置 → 常用」里把难度改成一样的。
- **备份和还原的几处变化**：
  - 同一台服务器的两次备份排队做。
  - 服务器正在启动或停止时不备份。手动备份会提示稍后重试；定时备份会等服务器启动完或停稳（最多等 15 分钟）再做，最多再试两次，控制台里写明这一次为什么没做成、正在等。别的原因失败的不重试。
  - 服务器开着时备份，备份途中服务器停止或重启了（包括有人点了停止），这一份作废、不留半份，手动备份会提示重新备份。
  - 备份的文件名变长了，时间后面多了一串数字，是为了让同一秒里的两次备份不重名。
  - 服务器开着时点「还原」，会先保存世界、停服再还原，还原完不会自动开服。
- **在 MineDeck 里保存以后，只读的文件不再是只读的。** 比如设成只读的 `server.properties`，在 MineDeck 里保存设置以后就不再是只读的；还想让服务端改不了它，要再设一次只读。
- **整合包里没装上的文件，只能补进普通的文件夹**（`mods`、`plugins`、`config`、`resourcepacks`、`datapacks` 这类）。世界和 `server.properties` 请走「换地图」和设置页。
- **设置要点「保存」才算数。** 设置类的页面改用底部的保存条，Java 的选择也在保存条里一起保存；定时任务点「添加」先进草稿，保存了才算数。
- **有人在线时停服、重启会先问一句。**
- **AI 的回复有大小上限**：按收到以后解码出来的内容算（正文、思考、工具调用的参数和名字这些），一次回复 8 MiB，一轮对话（连同中间的工具往返、重试）合计 32 MiB。正常问答碰不到；带很长思考过程的模型万一碰上，这一轮会停下并提示「回复内容过多」，请告诉我们用的是哪家的哪个模型。

## 局域网访问

打开「手机远程管理」以后，用访问密码登录的人能新建服务器、给服务器装模组和插件、改 JVM 参数和更新源，这些都等于能在这台电脑上运行程序。**访问密码只给信得过的人。** 局域网里登录的设备默认也能用 AI 助手，花的是你的额度；不想这样，在「设置 → AI」里关掉「局域网可用 AI 助手」。

## 已知情况

### 升级和更新

- **从 3.1.0 及以前的版本升级时，可能换不了程序**：换程序的是旧版本自己带的更新脚本，它在两种情况下换不成。一种是 MineDeck 装在名字里有中文（或者别的非英文字符）的文件夹里，而这次的 MineDeck 是开机自动启动的：点了更新以后程序关掉，就不会再打开，也没有提示。另一种是电脑的 PATH 里有别的 `find` 程序排在系统自带的前面（装过 MSYS2、Cygwin 一类工具的电脑可能这样）：程序会重新打开，但还是旧版本。两种情况下，新版本都已经下载好、校验过，放在 `MineDeck.exe` 旁边，叫 `MineDeck.new.exe`，服务器和设置都不受影响。第一种情况，双击 `MineDeck.exe` 打开，再点一次更新就行。两种情况都可以手动换：先退出 MineDeck（在托盘图标上右键退出），把 `MineDeck.exe` 删掉，再把 `MineDeck.new.exe` 改名成 `MineDeck.exe`。来龙去脉见 [v3.1.1 的发布说明](https://github.com/Trasperioooooon/MineDeck/blob/v3.1.1/docs/releases/v3.1.1.md)。3.1.1 起的更新脚本已经修好，从 3.1.1、3.1.2 和 3.2.0 测试版升级碰不上。
- **启动时的后台检查只写进日志**：打开「启动时静默检查更新」以后，程序启动时会自己去查，但结果只写进程序的日志输出，界面上不提示，日志里也不写用的是哪个渠道。想知道有没有新版本，还是到「设置 → 更新与关于」里点一下「检查更新」。
- **没有数字签名**：第一次运行时，Windows 可能提示「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。

### 服务器、备份和磁盘

- **「设置 → 常用」里 1.21.9 以上的几个游戏规则开关**（命令方块、PVP、下界、刷怪）：初始状态按 `server.properties` 里的旧值显示，不看服务器当前的游戏规则。
- **接管已有服务器时，如果它的端口和别的服务器撞了**，MineDeck 会改它 `server.properties` 里的 `server-port`（只改这一项，界面上会说明）。
- **两个窗口同时开着、改同一处设置时**（比如电脑上和手机上各开一个），没刷新的那一边一直显示打开时的值。服务器的「常用」「全部配置」只提交改过的项，两边改了同一项的，以后存的为准；下面这几处仍然整页一起存，后点「保存」的一边会把另一边刚存的改回原样：服务器的「启动与内存」（内存和 JVM 参数一起存）和「定时任务」（崩溃自动重启和整张任务表一起存）、隧道的「编辑」、AI 设置里的服务商和自填单价。改这几处之前先刷新一下页面。
- **存放位置的「撤销」不是完全撤销**：选错了文件夹再撤销，那个文件夹仍会留在扫描列表里。
- 给服务器换一个要现下的 Java 时，下载还没完就重新打开这台服务器的「设置 → 启动与内存」再保存一次，会再建一个下载任务（不会重复下载文件）。
- 备份页页顶「现在的世界从哪来」靠的是「换地图」里的记录，记录删掉以后只能说没有记录。新建向导和「换地图」页里，地图仍显示存档里的名字（多半是 world）。
- **同一个盘上正在做很久的备份、还原或换地图时**，新建服务器（要解压 Java）、第一次启动隧道（要解压 frpc）、添加本地模组，会停下来排队等前面的做完，期间取消不了，界面上也没有「在排队」的提示。
- **C 盘（系统临时文件夹所在的盘）只剩一两百兆时**，上传很小的文件（比如一个几兆的模组）也会被拒收，报错里没说是哪个盘不够。
- **查不出剩余空间的磁盘**（少数网络盘、特殊的挂载方式）：地图导入会多一条要你确认的事项；上传地图会被拒绝，请改成在这台电脑上直接选文件夹。下载和备份照常。
- 程序被强行结束或断电时，正在下载、复制、保存的临时文件（名字以 `.minedeck-` 开头）会留下，不会自动清理。反复强退的话，下载到一半的 Java 包、服务端文件会占着空间，可以手动删掉。
- **文件一直被别的程序占着时，保存的报错会晚约半秒**：保存时碰上文件被占着，会隔一会儿再试，最多约半秒，还不行才报错。比如服务器开着的时候替换一个正在用的模组文件。
- 一个以前就有、要别的程序配合才碰得上的竞态：MineDeck 核对完服务器里的文件夹在哪、真正去读写之前的那一瞬间，要是别的程序正好把这个文件夹换成了指到服务器外面的目录联接，读写配置、补没装上的文件时有可能动到服务器外面。以后的版本把这几处改成按已经核对过的文件夹来操作。

### 导入

- **交接包不能超过 8 GiB，整合包上传不能超过 4 GiB**（地图的 ZIP 是 8 GB）：开了很久的服务器，存档有可能超过。超过的话，把整个服务器文件夹拷到另一台电脑上，用「接管已有服务器」收进来；地图就在这台电脑上直接选文件夹。
- **CurseForge 上的整合包多数是给客户端用的**：里面常有只能装在客户端的模组，照着清单装出来的服务器会开不起来，MineDeck 目前不会提前提醒。大型整合包的作者一般另外提供 Server Pack。
- **整合包和现成服务端压缩包**：包装文件夹只认一层，整包里只能有一处整合包清单；Quilt 仍不支持；服务端的版本只写在日志里的认不出来，用「接管已有服务器」自己填。
- 导入现成服务端压缩包（文件直接放在最外层的那种）时，任务标题显示成一串数字，比如「导入服务端 3045782611」。
- **原版服务器上**，导入整合包时跳过的文件在界面上找不回来（原版没有插件 / 模组页）。
- 信任过的下载站点，目前要手动改 `config.json` 里的 `trustedHosts` 才能取消。
- **导入交接包、导入整合包到一半被打断**（关程序、断电）时，建到一半的文件夹会留在存放位置里，不会出现在列表中，可以直接删掉。
- **新建向导里挑的模组**不记是给哪种核心挑的，回头换了核心，有的可能装不上，到新服务器的「插件 / 模组」页里重新挑。

### 内网穿透

- **OpenFrp 的 frpc 以后可能又下不了**：3.1.2 修好的这一处下载，靠的是下载源的机器人防护眼下认哪种握手，对方哪天换了规则，下载会重新失败。网络出口只支持到 TLS 1.2 的（少数公司网络、代理，或者杀毒软件的「HTTPS 扫描」），这一处下载也会握手失败。照报错里写的办法手动放一次 frpc 就能接着用。
- **隧道凭据短于 6 个字节时**（英文字母和数字一个一字节，汉字一个三字节），日志里凡是包含它的行会整行换成「日志含凭据，已隐藏」，凭据特别短的话，会有不少不相干的行被隐藏，排查问题时不方便。填写和编辑隧道时会先提醒。

### 界面和 AI

- **新建时预查端口查不出 Windows 保留的端口段**。Hyper-V、WSL、Docker 这类会成段保留端口，被保留的端口预查时看着是空的，开服时照旧报「用不了」，页头照旧给「改端口」。
- 新建的表单打开时查过的默认端口（包括自动换成的那一个），表单开着期间被别的程序占上的话，不会再提示，开服时才会报。
- **报错提示的位置**：窗口比较窄（800 像素宽上下）时打开报错的「详情」，提示会盖住弹窗右边一截；窗口很矮、提示退回标题栏下方时，会盖住页头右边的启动这几个按钮；提示落在提示区下面时，会挡住标签栏右端的一两个标签；好几条提示叠在一起、比整个窗口还高时，下面的几条会出屏幕。提示 20 秒后自己走，鼠标停在上面时不走。
- AI 的回复长到超过上限时，如果已经开始输出，界面上可能说成「回复中途断开了」，真正的原因在「复制原文」里。

### 其他

## 还没实测过的，请帮忙留意

下面这些这一版没有实测过，碰到问题请告诉我们。

- **OpenFrp、樱花的真实账户**没有试过：连接账户、去官网签到的引导、在平台上建隧道和导入隧道、樱花流量的单位、隧道卡片上公网地址的显示，测试用的都是照着平台接口写的仿真。哪一步不对，或者卡片上的公网地址还是不对，请把看到的提示和隧道日志里带地址的那几行发给我们，凭据记得遮掉。
- **真实的 AI Key** 没有试过，OpenAI 兼容的和 Claude 的都没有。各家服务商的兼容是按官方文档和录下来的样本测的。
- **用游戏客户端进服**没有试过：导入地图以后主世界、下界、末地是不是都对，单人存档转过来以后主人的背包接不接得上，白名单挡不挡人，朋友连不连得上。导入的地图只在服务端控制台核对过方块。
- **被杀毒软件、同步盘真的占着文件的情况**没有制造过。替换文件时碰上占用会隔一会儿再试，最多约半秒，够不够等过真实的扫描，没有实测数据。
- **工具箱生成的资源包和整合包**没有放进真的游戏客户端、启动器加载过。**老的 64×32 皮肤扩成新格式**的那几步，是照着社区整理的游戏代码说明写的，没有和游戏里的效果逐条对过。
- **第一次缩到托盘时的系统通知**只在测试里确认发出了，没在真窗口里看过它的样子。
- **从 OpenFrp 的下载源真的下一次 frpc**，这一版的程序没有试过。还没下过 frpc 的电脑，第一次启动 OpenFrp 隧道时要是下载失败，照报错里的办法手动放一次，也请告诉我们。
- **磁盘快满时便携 Java 装到一半**的处理（放「还没装完」的记号、下次重装、一开始按解开以后的大小查空间），只在测试里验证过，没在真的快满的盘上试过。
- **服务器放在网络共享、卷挂载点，或者开了区分大小写的文件夹里时**，MineDeck 保存文件时加的那道锁（免得两处同时写同一个文件）能不能认出是同一个文件，没有试过。

遇到问题，欢迎在 GitHub 上提 Issue，写清楚做了什么、看到了什么。**不要贴出 API Key 和各种令牌。**
