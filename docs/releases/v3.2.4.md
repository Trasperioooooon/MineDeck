这是 MineDeck v3.2.4，一个小版本。这一版处理了用户反馈的八件事里能直接动手的几件：整合包里没装上的文件可以一键全选，一次最多处理 500 个；MineDeck 下载的 Java 可以卸载，上次没建完的服务器文件夹可以删掉；便携 Java 和 NeoForge 安装器下载时多核对一道官方校验值；接管 Velocity 认得更准；Banner 改叫 Taiyitist（原 Banner）；装模组、插件的地方能打开 Modrinth 上的项目页。

**下载便携 Java 的路子有变化。** 清华镜像上的 Java 压缩包，以前镜像旁边没有校验文件时就不核对直接用；现在要对上 Adoptium 官方给的校验值才用。连不上 Adoptium 官方接口的时候，清华镜像和 Adoptium 官方源都不再用，直接改用 Mojang 官方运行时（经 BMCLAPI 镜像下载）。下载源选了「官方」的，也不再先连清华镜像。

## 怎么升级

用着 v3.2.3、v3.2.2、v3.2.1 或 v3.2.0 的，打开「设置 → 更新与关于」，点「检查更新」，查到新版本以后点更新就能升到 3.2.4。服务器、Java、设置、隧道和 AI Key 都会接着用。更新前先停掉正在运行的服务器。

用着 v3.1.1、v3.1.2 或者 3.2.0 测试版的，也能在程序里直接升到 3.2.4：3.2.0 的 beta.3 到 beta.5 不管更新渠道选的是哪个都查得到，beta.1、beta.2 和 3.1.x 只看正式版，3.2.4 就是正式版，也查得到。

从 v3.1.0 及更早的版本升级时，换程序的是旧版本自己带的更新脚本，它有两种情况换不成，新版本这时已经下载好、放在旁边。处理办法见 [v3.2.0 的发布说明](https://github.com/Trasperioooooon/MineDeck/blob/v3.2.0/docs/releases/v3.2.0.md)「已知情况 → 升级和更新」的第一条。

从 v2.6.1 及更早的版本升级（那时的程序叫 `AutoMCHUB.exe`），自动更新找不到改名后的文件，请手动下载 `MineDeck.exe` 放进原来的文件夹。旧的开机自启项会被删掉，需要的话在「设置 → 启动与托盘」里重新打开。

## 改了什么

### 整合包里没装上的文件

导入整合包时，下载地址不在允许列表里的文件会记成「没装上的文件」，要一个个选怎么处理。大的整合包这样的文件能有几百个。

- **一次最多处理 500 个。** 以前是 50 个，多了就报「参数 items 最多 50 项」。超过 500 个时界面会分几批提交；中途哪一批出了错，界面会重新读一次清单再显示，已经装好的不会还留在清单里。
- **新加「全选可下载项」。** 只选还没选处理方式、带着校验值、能从外部站点下载的那些。已经跳过的、没有校验值的、你已经选了别的处理方式（比如用本地文件代替）的，都不动。它不会替你确认风险。
- **新加「确认这些站点的风险」。** 一次勾上已选「信任站点并下载」的那些项的风险确认。风险说明照旧写在每一项旁边，勾之前请看一眼。下载下来照旧要对上整合包里的校验值，对不上就不装；站点照旧是下载成功以后才按域名记住。没有把 forgecdn 这类站点加进默认允许的列表。

### Java

- **能卸载 MineDeck 下载的 Java 了。** 在「设置 → Java 运行时」里，每一套便携 Java 旁边有「卸载」。只删 MineDeck 自己下载到程序文件夹 `runtimes` 里的那一套，系统里装的 Java 不动。有服务器还配着这套 Java、正在用它运行，或者有服务器正在新建、导入时，会拦下来，并说是哪一台。文件夹本身或里面有链接、目录联接的，不删。下载或卸载到一半留下的文件夹会列成「残留」，可以点「清理」。卸载和清理只能在这台电脑上做，局域网里打开的界面上没有这两个按钮。
- **从清华镜像下载的 Java，现在要对上 Adoptium 官方的校验值。** 以前镜像旁边没有校验文件（现在就是没有）时，压缩包不核对就直接用。现在不看镜像自己的校验文件，向 Adoptium 官方接口要这个文件名的 SHA-256，对不上或者要不到，就不用这份压缩包。挑镜像里最新的一份时按版本号的数值比，以前按文件名的字母顺序，可能挑到旧的。
- **走 Adoptium 官方源时，也先试清华上的同名文件**，校验值同样是 Adoptium 官方给的；清华上没有或者对不上，再从官方地址下载。
- **连不上 Adoptium 官方接口时，不再空等。** 向它要校验值时每个地址最多等 10 秒；都要不到，就不再试 Adoptium 官方源，直接改用 Mojang 官方运行时（经 BMCLAPI 镜像）。
- **下载源选了「官方」时，不再连清华镜像。** 以前选了「官方」也先连清华。
- 有用户说 Java 8、11、17、21 下载不下来。这一版没能确定那位用户那里的原因，上面这几处改动不保证能解决；如果你也碰到，请把任务日志里下载 Java 那几行发给我们。

### 上次没建完的服务器文件夹

- 新建服务器、导入整合包、导入现成服务端和交接包的时候，在这台服务器登记好之前，MineDeck 会在它的文件夹里放一个 `.minedeck-creating` 记号。中途 MineDeck 被关掉、崩溃、断电，或者失败以后没清干净，留下的这种文件夹会在「服务器」页上方列出来，点「删除这个文件夹」并再确认一次就能删掉。里面已经有世界文件的，确认框里会说。
- 只认这个记号：接管进来的、你自己放进来的文件夹，以及 3.2.4 以前的版本留下的，都不会列出来，也不会自动删。已经登记好的服务器只会去掉记号，不删文件夹。
- 这一块也只在这台电脑上显示，局域网里打开的界面上看不到。

### 接管 Velocity

- 文件夹里有 `velocity.toml` 时，优先认成 Velocity（启动脚本里点名的 jar 仍然优先）。以前同一层还有游戏服的 jar 时，会拿 Velocity 的版本号（比如 3.4.0）和 Minecraft 版本比大小，认成了别的核心。
- 游戏服之间照旧按 Minecraft 版本挑新的；代理端只和同一种代理端比。
- 文件夹里有 `velocity.toml`、最外层却一个能启动的 jar 都没认出来时，报错会说清楚是这个原因。
- 那位用户的服务器文件夹我们没看到，不能确定这样改就对上了他那一台。接管时认错了的，可以在识别页的「启动文件」里自己选。

### Banner 改叫 Taiyitist（原 Banner）

Banner 这个项目已经改名叫 Taiyitist，界面上跟着改成「Taiyitist（原 Banner）」。下载照旧用 MohistMC 上原来 banner 这个项目的构建，Taiyitist 这个名字下面现在还没有构建。接管时，主类是 `com.taiyitistmc.TaiyitistLauncher` 的服务端也认成它。改名不等于换了新的加载器版本。

### 别的

- **模组和插件的项目页。** 「插件 / 模组」标签里搜出来的项目和待装清单里的项目，旁边多了「项目页」，打开 Modrinth 官网上这个项目的页面（窗口版用默认浏览器打开）。地址只用 Modrinth 接口给的项目类型和名字拼，给得不全就不显示这个按钮。
- **NeoForge 安装器多核对一道。** 下载 NeoForge 安装器之前，先向 NeoForge 官方 maven 要这一版安装器的 SHA-1（最多等 10 秒）。要到了就按它核对下载下来的安装器；下载源不是「官方」时，还会在首选的地址（一般是 BMCLAPI）后面加试 `neoforged.forgecdn.net`。要不到，就和以前一样下载、不核对。安装器自己再去拉依赖时，照旧用 BMCLAPI。
- **正版验证的说明写清楚了。** 新建、导入整合包和常用设置里的「正版验证」旁边写明：关掉以后离线账号也能进服，但用的不是正版 UUID，也不显示正版皮肤。有用户问到离线服怎么保留正版 UUID，这件事要靠第三方模组，这一版没有做。
- **下载报错里不再带账号和查询串。** 下载失败时的报错，以前可能带着下载地址里的账号、密码和签名参数，现在只写到站点；跳转到带账号的地址时不再跟过去。

## 给 AI 助手、MCP 和自己调接口的人

- **处理没装上的文件**（操作 `instance.import.pending`、`instance.import.pending.resolve`，`POST /api/import/pending/{taskId}`、`POST /api/instances/{name}/import-pending`）：`items` 最多 500 项，501 项回 400。两个操作都仅人工、仅本机，和以前一样。
- **新加卸载便携 Java**（操作 `java.remove`，`POST /api/javas/remove`，body `{"major":21,"confirm":true}`）：仅人工、仅本机，`confirm` 必须是 true。有服务器配着、正在用、或者有服务器正在新建和导入时回 409。`java.list`（`GET /api/javas`）多了一个 `incomplete`，列出没装完、没删完的大版本。
- **新加没建完的文件夹**（操作 `instance.creating.list`、`instance.creating.discard`，`GET /api/creating-leftovers`、`POST /api/creating-leftovers/discard`，body `{"id":"…","confirm":true}`）：仅人工、仅本机。`id` 只能用列表里给的，不是路径；正在创建的、已经登记的、没有记号的、是链接的都不删，回 409 或 400。
- **Modrinth 搜索**（操作 `modcart.search`）：`hits` 里多了 `project_type` 和 `project_url`。`project_type` 是 Modrinth 给的原值，它没给就不出现；`project_url` 是按类型和 slug 拼的官方项目页，类型或 slug 不合规则时不出现。

接口的详细说明见 [`docs/设计与参考/API.md`](https://github.com/Trasperioooooon/MineDeck/blob/v3.2.4/docs/设计与参考/API.md)。

## 下载哪个文件

| 文件 | 给谁 |
|---|---|
| `MineDeck.exe` | 开服的人。放进一个单独的空文件夹，双击运行；已经在用旧版本的，换掉原来的那个。 |
| `minedeck-companion-neoforge-1.21.1-0.2.1.jar` | 用了 AI 伙伴的 NeoForge 1.21.1 服上的好友：放进客户端的 `mods` 文件夹 |
| `minedeck-companion-forge-1.20.1-0.2.1.jar` | 同上，Forge 1.20.1 的服 |
| `SHA256SUMS` | 校验和，自动更新会用到，一般不用管 |

伙伴模组还是 0.2.1，和 v3.2.3 的是同一份，已经装过的好友不用换。

## 这一版实际试过的

- **自动测试**：在最终代码上，Go 测试 44 个包全部通过，代码检查（go vet）没有提醒；界面交互测试 268 条、界面原型自检 162 个场景全部走通。会删文件、做路径检查、核对校验值和给报错去掉账号的那几处，逐条反着试过：把对应的代码改回去，相关的用例都会失败。
- **便携 Java 真下载**：用这一版的代码，在一个空文件夹里把 Java 8、11、17、21、25 各下了一遍（在日本的网络上）。五个都是从清华镜像下的、对上了 Adoptium 官方的校验值，装好以后能运行。
- **卸载 Java、没建完的文件夹**：用发版的那条命令编出这一版的程序，在空文件夹里起来，摆好两套真下载的便携 Java、一套没装完的、一台配着 Java 17 的服务器和几种文件夹，逐个调接口：配着的 Java 17 被拦下、说出了是哪台服务器；没确认的被拦下；没人用的 Java 21 删掉了；没装完的列成残留、清理掉了。带记号、有世界文件的文件夹列了出来，删掉了；登记过的服务器只去掉了记号；没记号的文件夹没列、没动。
- **复审**：八条反馈的初版是 Grok 4.7 写的，Gemini 4 Carbon 审改过一轮，Claude 又复审了一遍、补改了几处（Java 校验值要不到时不再白等、接管识别的两处回退、「全选」的范围），补改经 Gemini 4 Argon 复审过两轮。这份发布说明请 Gemini 4 Argon（只读）对着代码核对了两轮，没有说反的地方；它指出的一处漏写、一处不够准的都改了。

## 还没实测过的

- **真窗口**：这一版新加的按钮（全选、确认风险、卸载、清理、删除文件夹、项目页）都是在测试用的浏览器里点的，没在 MineDeck 的窗口里逐个点过。
- **连不上 Adoptium 接口时改走 Mojang 运行时**这一步，只有自动测试。
- **国内的网络。** 国内家庭网络连 Adoptium 官方接口、清华镜像、`neoforged.forgecdn.net` 的情况没人实测过。forgecdn 排在原来的地址后面、向官方要校验值最多等 10 秒，都是按「连不上时别让人白等」定的。
- **Velocity**：没有那位用户的服务器文件夹。
- **Taiyitist**：没下载、没运行过 Taiyitist 的 jar。
- **NeoForge 安装器**：只核对过一份官方 SHA-1 和 forgecdn 上的一致，没从 forgecdn 真的下载、运行过安装器。
- **卸载 Java、删没建完的文件夹**：符号链接那两处检查，在我们的电脑上建不了符号链接，测试跳过了；目录联接的试过。
- v3.2.3、v3.2.2、v3.2.1、v3.2.0 发布说明里写的那些照旧没实测，见 [v3.2.3 的发布说明](https://github.com/Trasperioooooon/MineDeck/blob/v3.2.3/docs/releases/v3.2.3.md)。

## 已知情况

- **连不上 Adoptium 官方接口时**，清华镜像和 Adoptium 官方源都不用，只剩 Mojang 官方运行时一条路；它的文件校验值来自 BMCLAPI 给的清单，和以前一样。下载源选了「官方」，或者清华镜像和 Adoptium 官方接口都连不上时，Adoptium 官方源那一步仍按默认时限等，等完才改用 Mojang 运行时。
- **下载源选「仅镜像」时**，下载 NeoForge 安装器前照旧会向 NeoForge 官方 maven 要一次很小的校验文件。
- **3.2.4 以前的版本建到一半留下的文件夹**没有记号，这一版认不出来，要自己去服务器文件夹里删。
- **卸载一套便携 Java 的同时，又在另一个页面把某台服务器换成这套 Java**，那台服务器下次开服会找不到 Java，换一下就好，不丢数据。
- **一次处理几百个没装上的文件时**，整批做完才返回，期间界面上只有一个变灰的按钮；离开页面以后，还没提交的批次不再提交，回来再点一次就行。
- v3.2.3 已知情况里的几条照旧，见 [v3.2.3 的发布说明](https://github.com/Trasperioooooon/MineDeck/blob/v3.2.3/docs/releases/v3.2.3.md)。
