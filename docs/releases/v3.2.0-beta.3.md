> **这是测试版**，给自己和好友试用、找问题的，可能还有毛病。
> - **从 v3.2.0-beta.2 或更早的版本换过来，要手动换一次程序。** 那些版本检查更新时只看正式版，看不到这个测试版。请先关掉 MineDeck，下载下面的 `MineDeck.exe`，换掉原来文件夹里的那一个。服务器、设置和隧道都存在那个文件夹里，不用动。
> - 从这一版起，「设置 → 更新与关于」里可以选更新渠道：「稳定版」只提示正式版，「最新版」连测试版一起提示。没选过的话，用着测试版就按最新版查，以后的测试版可以直接在程序里更新。
> - 正式版会是 v3.2.0。

和 v3.2.0-beta.2 比，这一版按一次可用性走查的结果把界面整理了一遍：服务器详情页的标签从十几个收成七个，连接地址、启动失败的原因、端口被占这些「出了事要马上看到」的信息放到了页头上；新建、导入的流程补上了取消、返回修改和没装上的文件的后续处理；各处的叫法统一了一次。另外新加了两样东西：左侧栏的「工具箱」，和检查更新时选「稳定版」还是「最新版」。

## 新功能

### 工具箱

左侧栏「内网穿透」下面多了一项「工具箱」，放和朋友一起玩时用得上的小工具。这一版有两个：

- **离线皮肤包**。离线模式的服务器上，大家都顶着默认皮肤。把朋友们的皮肤 PNG 放进来，MineDeck 按每个人的玩家名算出游戏会给他用哪一个默认皮肤，把皮肤图换进去，打成一个资源包。每个朋友把这个资源包放进自己客户端的 `resourcepacks` 文件夹并启用，就能看到彼此的皮肤。也可以不按玩家名、按顺序替换默认角色的外观。老的 64×32 皮肤会自动扩成现在的格式。
  - 默认皮肤的位置是游戏按玩家名定死的：1.19.3 起有 18 个，更早的版本只有 Steve 和 Alex 两个。人一多，两个人撞进同一个位置的机会不小（5 个人大约四成），撞上了只能二选一，页面上会标出来让你选。
  - 游戏还按玩家名定了手臂是粗的还是细的，资源包改不了这一点：手臂粗细和皮肤对不上的，看起来会有点别扭。
  - 支持 1.8 及以后的版本。老的 64×32 皮肤按游戏客户端处理下载皮肤的规则扩成新格式，帽子那一层如果整块涂满了，会清成透明。
  - 生成的资源包附带 SHA-1。想让服务器自动把资源包推给进服的人，要自己把它放到网上能直接下载的地方，再在服务器的「设置 → 全部配置」里填 `resource-pack` 和 `resource-pack-sha1`；工具箱不会改服务器的配置。
- **导出整合包（Modrinth 的 .mrpack 格式）**。两种用法：从已有的模组服务器直接导出它的模组，可以选带上 `config` 文件夹；或者自己挑模组，MineDeck 找齐必装的前置。导出的文件用 Modrinth App、Prism、HMCL、PCL2 这些启动器都能一键安装。
  - Modrinth 上能找到的模组只写下载地址，朋友安装时从官方下载；找不到的（自己改过的、只在别处发布的）整个打进包里，分享前请留意原作者是否允许转发。
  - 自己挑模组时，只在客户端用的模组（小地图、光影加载器之类）也能挑，包里会标明服务器不用装。这份清单是工具箱自己的，和新建服务器时挑的模组分开，不会被装进任何服务器。
  - `config` 文件夹默认不带。勾上的话，看起来放着密码、令牌、密钥、数据库的配置文件（比如聊天机器人的令牌、权限插件的数据库设置）会尽量挑出来不打进包，预览里列出跳过了哪些；认不出的写法难免有，打进去的配置文件也都列在预览里，发之前请看一眼。
  - MineDeck 自己装进服务器的语音桥模组（音乐共享用）只在服务端用，不会打进包；AI 伙伴模组朋友的客户端要装，照常带上。

两个工具都不改任何服务器里的文件。生成的文件可以直接下载；在运行 MineDeck 的这台电脑上，也可以顺手存到一个文件夹里。

### 更新渠道

「设置 → 更新与关于」里可以选「稳定版」或「最新版（包括测试版）」。稳定版只提示正式版；最新版连测试版一起提示，按版本号挑最新的。不会提示比你现在用的更旧的版本：用着测试版又选了稳定版，在下一个正式版出来之前不会有更新提示。不管哪个渠道，下载的程序都要和官方发布的 `SHA256SUMS` 对得上才会换上。

## 服务器详情页

- **标签收成七个**：控制台、玩家、世界与备份、插件 / 模组、定时任务、设置、扩展。原来的「地图」并进了「世界与备份」，叫「换地图」；「资源」和「待装清单」合成一页，上面是已安装的，下面是热门、搜索和从电脑添加；「常用设置」「内存 / 启动」「全部配置」收进「设置」，分别叫「常用」「启动与内存」「全部配置」；游戏内 AI、AI 伙伴、音乐共享收进「扩展」。旧的书签和链接会自动跳到新位置。
- **连接地址在页头和服务器卡片上**：同一个局域网里的朋友要填的 `IP:端口`，点一下就能复制。不在同一个网络的朋友，还是用内网穿透的隧道。
- **页头有一块提示区**：上次启动失败的原因、整合包里没装上的文件、Java 找不到了、模组要求更高版本的 Java，有就一直显示在这里，事情解决了才消失，不再是右上角几秒钟就不见的提示。
- **启动失败的原因留着**：服务器起不来时，原因写在页头和卡片上，切到别的页再回来也还在。
- **端口被占了会说清是谁**：被 MineDeck 里另一台服务器占着时，直接说是哪一台，并给「改成 N 并启动」；被别的程序占着时给「改端口」，带你去设置里的端口那一项。新建服务器、导入、接管时默认的端口会避开已经在用的。
- **加了「重启」按钮**；改了需要重启才生效的设置，保存后的提示和设置项旁边的标注说法一致。
- **设置类的页面都用底部的保存条**，Java 的选择也在保存条里一起保存；定时任务点「添加」先进草稿，保存了才算数。
- **服务器信息集中在「设置 → 启动与内存」页顶**：核心、版本、端口、Java、服务器文件夹，能复制、能打开。「打开文件夹」菜单里多了「备份」，备份页写明备份存在哪。
- **Java 路径失效时会提醒**（比如把服务器从别的电脑拷过来），卡片和页头都会说，Java 下拉里那一项标「找不到」。
- **还原备份**：还原前要做什么、会不会影响正在运行的服务器，确认框里一次说清。
- **有人在线时停服、重启会先问一句**。

## 新建、导入和接管

- **新建服务器时白名单默认关闭，并且写明了**。26.3 起的服务端默认会开白名单，以前不说一声就会把朋友挡在外面。
- **新建页有五种方式**，「用已有地图开服」单独成了一张卡片。
- **导入整合包时没装上的文件会留在服务器上**：以前要在那一次运行里处理完，关了程序就找不回来。现在服务器详情页头会一直提示「有 N 个整合包文件没装上」，点开能逐个处理，跳过的以后也能在插件 / 模组页再处理。
- **任务页**：正在进行的、出了问题的任务排在前面，做完的折起来。新建、导入整合包、导入现成服务端可以取消，取消后显示中性的「已取消」，不再当成失败；点「返回修改」回到原来的表单，填过的都还在。
- **换地图取消了也显示「已取消」**，并写明没有替换任何文件。
- 选构建版本默认收进「高级」；选插件这一步能跳过；同意 EULA 的开关不会被底部的按钮挡住。

## 删除、弹窗

- **删除服务器默认只「移出列表」**，文件夹留着，提示里写出文件夹的位置并能直接打开；要连文件一起删得另外选。移出接管来的服务器时，会说清楚 MineDeck 在那个文件夹里留下了哪些文件。
- **弹窗里报错时，填好的内容不会丢**；弹窗叠着开时，Esc 只关最上面那一层。
- 报错提示至少停留 20 秒，鼠标停在上面或打开了详情时不会消失。

## 内网穿透和设置

- **隧道可以编辑**：名称、绑定的服务器、跟随服务器启动都能改；凭据留空就沿用原来的，换了服务商或服务器地址才要重新填。隧道卡片上信息更全。
- 内网穿透页顶写明：同一个局域网的朋友不用隧道，直接用服务器页上的连接地址。「添加隧道」和「平台账户」是什么关系也写清楚了。
- 设置里原来的「远程访问」改叫「手机远程管理」，说的是用手机或别的电脑的浏览器打开 MineDeck 的管理页，和朋友进游戏的地址无关。
- 「设置 → AI」页顶说明三样 AI 各是什么：标题栏上的「AI 助手」、服务器里的「游戏内 AI」、陪玩的「AI 伙伴」。
- 「点关闭按钮时缩到托盘」开关的说法改清楚了，第一次缩到托盘时会提示一次；侧栏底部加了「退出 MineDeck」。
- 导出交接包时，选的文件夹不存在可以「新建并导出」。存放位置改了以后可以撤销。

## 修复

- **AI 回复的大小上限改成按实际内容算**。beta.1 起是按收到的原始数据算 8 MiB，带很长思考过程的模型可能误碰上限；现在按解码以后的正文和思考内容算，原始数据另设一个宽得多的兜底上限。
- **处理没装上的文件时不再长时间占着锁**：从网上下载放到锁外面，只在真正写进服务器的那一下加锁，下载慢时不会挡住这台服务器别的操作。
- **隧道凭据很短时会提醒**：短于 6 个字符的凭据，日志里含它的行会整行隐藏，填写和编辑隧道时会先说一声。
- **公网地址后面紧跟着别的字符时**，端口不会被截错。
- **隧道配置读不出来时**，音乐共享页的说法改对了，不再显示成「没有语音隧道」。
- 保存文件时取锁的方式改了一处细节，路径写法不同但指向同一个文件时不会拿到两把锁。

## 已知情况

- **存放位置的「撤销」不是完全撤销**：选错了文件夹再撤销，那个文件夹仍会留在扫描列表里。
- **原版服务器上**，导入整合包时跳过的文件在界面上找不回来（原版没有插件 / 模组页）。
- **接管已有服务器时，如果它的端口和别的服务器撞了**，MineDeck 会改它 `server.properties` 里的 `server-port`（只改这一项，界面上会说明）。
- 启动时后台检查更新，日志里不写用的是哪个渠道。
- beta.1 里「AI 的一次回复有大小上限（8 MiB，按原始数据算）」这一条已经改掉（见上面「修复」）；「待决文件要在这次运行里处理完」也不再适用，没装上的文件会一直留到你处理。beta.1、beta.2 发布说明里「已知情况」的其余各条仍然适用。
