这是 MineDeck 的第一个正式版。

测试版的时候说过正式版会叫 v2.9.0。可是和上一个正式版 v2.6.1 比，这一版换了名字（原来叫 AutoMCHUB）、换了一整套界面，又加了 AI 接入、游戏内 AI、音乐共享、AI 伙伴和 MCP 接口，改动大到该算一个新的大版本，所以直接叫 3.0.0。这些功能各自怎么用，见 [v2.9.0-beta.1](https://github.com/Trasperioooooon/MineDeck/releases/tag/v2.9.0-beta.1) 和 [v2.9.0-beta.2](https://github.com/Trasperioooooon/MineDeck/releases/tag/v2.9.0-beta.2) 的发布说明。

beta.2 发出去以后，好友在真机上按测试计划过了 85 项，下面的改动大多来自这份报告。

## 怎么升级

用着 beta.1 或 beta.2 的，打开「设置 → 更新与关于」，点「检查更新」就能直接升到 3.0.0。测试版之间不能自动更新，正式版可以。服务器、Java、设置和 AI Key 都会接着用。

还在用 v2.6.1（AutoMCHUB）的，要手动下载一次：改了名字以后，老版本的自动更新找不到新文件。把 `MineDeck.exe` 放进原来 `AutoMCHUB.exe` 所在的文件夹运行，服务器和设置都会接着用，确认没问题后可以删掉 `AutoMCHUB.exe`。旧的开机自启项用的是老名字，新版会把它删掉，需要的话到「设置 → 启动与托盘」重新打开。

## 窗口和启动

打开程序时不再先闪一下白窗口和系统标题栏，不到一秒就直接出现深色的启动画面。开机自启、静默进托盘时全程不露面，之后从托盘打开立刻就是画好的界面。

双击标题栏现在能最大化和还原。有服务器在跑、又没开「最小化到托盘」的时候，不管是点 ×、按 Alt+F4 还是在任务栏上关，都会先问一句：最小化到托盘（可以记住这个选择）、停止服务器并退出，或者取消。

## 服务器

- 在控制台或者游戏里输入 `stop` 关服，不再被当成崩溃，也不会被自动重启。
- `instance.json` 被别的编辑器存成带 BOM 的格式时，服务器不再从列表里消失。
- 端口检查以前会把只被 0.0.0.0 占着的端口报成「空闲」，现在查得出来。
- 部署时下载慢或者在重试，进度下面会说明是哪个地址、第几次，不再一声不响地卡着。
- 定时任务的时间改成「时:分」文本框，4:5、0400、21：30 这类写法都会补成标准格式，旁边有「5 / 10 / 30 分钟后」的快捷项。以前经接口存进来的「9:05」这种没补零的时间永远不会触发，现在也能触发了。
- 报错横幅认得出更多「缺少前置模组」的写法，「好友进不来」时显示的玩家名也干净了。
- 控制台的快捷键说明一直显示在命令框下面；「全部配置」可以按键名或中文名搜索。

## 内网穿透

跟随服务器启动的隧道更稳了：服务器崩溃后自动重启，隧道也会跟着起来；服务器停下 5 秒还没再开，才把隧道停掉，重启时不会来回开关。隧道卡片的状态刷新得更及时，启动失败的原因直接写在卡片上，公网地址有域名时优先显示域名。跟随启动和停止都会记进操作记录。

## AI

在设置里只改同一个网站下的接口路径，不再清掉已经填好的 Key；真的要清（换了服务商或者换到别的网站）时会先问你。

游戏内 AI 按实测放宽了限制：每人提问的冷却从 15 秒改成 8 秒，每人每天从 30 次改成 60 次，刷屏后的静默从 10 分钟改成 3 分钟，被挡回的提问不再算进刷屏。房主在设置页能看到今天全服用了多少 token、大约合多少钱，以及谁问了几次。AI 执行命令后会等服务器真正返回结果再回答，「/tp 怎么用」这类问法会当成提问，回复在游戏聊天框里按宽度断行。

## 音乐共享

检查清单里 Simple Voice Chat 没装时，直接给一个「安装」按钮，按服务器的加载器和版本从 Modrinth 装上合适的版本。没有开着的语音隧道时，页面会说清楚，不再说「远程好友连服后就能听到」。

## 手机和平板上的远程访问

用手机浏览器打开局域网界面时，底部标签栏不再被浏览器的工具栏压住，内容能滚到最底，横着拿也是手机布局，刘海和底部横条的位置会让开。

「允许局域网访问」的开关拨了就生效；没设访问密码时会就地提示并拨回去。关掉局域网访问或者换了访问密码以后，之前在别的设备上登录的会话都会失效，要重新输入密码。

## 界面

界面上的文字改成了平实的中文。读屏软件能读出每个按钮是对哪台服务器、哪个玩家的；玩家页的 OP、踢出、移除能用 Tab 键选到；新建服务器时可以用方向键挑服务端核心、回车进入下一步。

## 下载哪个文件

- `MineDeck.exe`：开服的人（房主）下载这个就够了。放进一个单独的文件夹，双击运行。
- `minedeck-companion-neoforge-1.21.1-0.2.1.jar` 和 `minedeck-companion-forge-1.20.1-0.2.1.jar`：用了 AI 伙伴的服上，好友的客户端要装的伙伴模组，按服务器的版本二选一放进 `mods` 目录。和 beta.2 一样是 0.2.1，已经装过的不用换。
- `SHA256SUMS`：校验和，自动更新会用到，一般不用管。

## 已知情况

- **没有数字签名**：第一次运行时，Windows 可能提示「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。
- **国内网络**：NeoForge、Forge 的官方下载站和 Modrinth 在国内可能很慢，甚至下不来。部署页会提示正在重试；一直下不来的话，可以开代理再试。
- **Windows 10 上的音乐共享**只能录整机的声音，会把游戏声音也录进去，开始前会提醒。
- **还没测到的**：游戏内 AI 的私下提问和 AI 伙伴的「没权限时不动」需要两个账号同时在线，Minecraft 1.21.5 以后的版本上的游戏内 AI 也还没在真服上试过。MCP 接口实测用的客户端是 Codex，Claude Desktop、Cherry Studio、Cursor、VS Code 按各自的文档写了配置，但没有逐个试过。手机布局在安卓模拟器里检查过，iPhone 还没在真机上看过。

遇到问题，欢迎在 GitHub 上提 Issue，写清楚做了什么、看到了什么。**不要贴出 API Key 和 MCP 的访问令牌。**
