### 还原备份以后设置被重置

- 去问反馈的用户：用的哪个核心、哪个 MineDeck 版本；点的是「世界与备份 → 还原」还是「换地图 → 换回」；那份备份是 MineDeck 做的，还是自己放进备份文件夹的。不问清楚，真正的原因可能还在别处。

### 定时任务：每隔多久、文件夹、一键预设

子代理（Opus 5.5）做完了，现在的程序界面（不是重构的草图）里就能用：添加任务多了「每天 / 每隔」两种，任务可以放进文件夹、挪来挪去，上面一排「一键添加 [每小时存档] [每小时扫地]」。配置里多两个字段：`every`（每隔多少分钟，和 `at` 二选一）、`group`（文件夹名），老配置原样能读能跑。AI 助手、MCP 改定时任务的工具也认这两个字段。

要你敲定的：
- 「存档」主会话理解成 MineDeck 的备份（每小时备份一份），不是游戏里的 save-all：Minecraft 自己每几分钟就存一次盘，用户要的应该是能回退的存档。对不对？
- 每小时一份备份，按现在的保留份数（默认 10，所有服务器共用，手动备份也算）只能留十个小时，手动备份也会被挤掉。要不要给定时备份单独的份数？现在只在悬停里说清楚。

我替你定的（子代理提、主会话同意）：
- 「扫地」= 每小时执行 `kill @e[type=item]`，清掉地上的掉落物；不先发提醒。
- 每隔多久按钟点对齐：从每天 0 点起数，每隔 60 分钟就是每个整点。不从开服或保存那一刻起算，那样重开程序、崩溃重启都会把节奏打乱。
- 最短间隔：命令 5 分钟、备份 30 分钟、重启 60 分钟；最长 12 小时，再长用每天定时。
- 服务器停着时，每隔多久的备份不备（世界没变，备出来都一样，还会把旧备份挤掉）；停下以后补一份。每天定时的备份照旧停着也备。
- 一键预设先加进列表、标「未保存」，点「保存策略」才生效，和这一页别的添加一样；已经有同样的就不重复加。
- 同一条任务上一次还没做完（比如备份在等服务器稳定），这一次跳过，控制台说一声。
- 小标题「每日定时任务」改成「定时任务」。

- 同一台服务器同一分钟只做一个备份、一个重启（每天 04:00 的备份和「每小时存档」都在 04:00 到点时，只做一份）；上一个备份还没做完，到点的下一个（每天定时的也算）跳过，控制台说一声。这是 Gemini 复审挑出来以后改的。
- 服务器停着时要不要补一份备份，按服务器记、不按任务记：改间隔、删了再加都不会把要补的那一份弄丢；每天定时的备份做了也算备过。

已知的小毛病：两个窗口同时点同一个预设会加出两条一样的；老版本 MineDeck 读到新配置会忽略每隔多久的任务；备份交出去那一刻就算「备过了」，之后那次备份失败的话，要补的那一份就没了。

### 把 MineDeck 文件夹加进 Windows 白名单

主会话把「Windows 白名单」理解成 **Windows 安全中心（Defender）的排除项**：实时防护扫服务器文件夹会拖慢开服和存档，frpc 还常被误报隔离；加了排除项这个文件夹就不扫了。不是防火墙（防火墙按程序、按端口放行，不按文件夹）。子代理（Opus 5.5）做完了：「设置 → 存储位置」里多一行「Windows 安全中心排除项」，点「加入…」弹 Windows 的管理员确认（UAC），确认以后用 PowerShell 跑 `Add-MpPreference -ExclusionPath '<程序数据文件夹>'`；能撤销。只有窗口版有这一行，手机远程、浏览器打开、Mac 版都没有；AI 助手和 MCP 调不到它。

要你敲定的：
- 「白名单」指的是 Defender 排除项，对不对？如果你说的是防火墙，要另做。
- **真机还没试过**：为了不改这台电脑的安全设置，子代理和主会话都没有真的点过「加入」、没弹过 UAC。要你找一台能随便改的电脑（或者你自己这台、你同意的话）点一次加入、一次撤销，看 UAC 弹不弹、提示对不对、Windows 安全中心里排除项有没有出现。
- 在 UAC 里点「否」、PowerShell 被组策略禁用、装了别的杀毒软件（Defender 没在工作）这几种情况的提示都写了，也都只在测试里用假的执行器验证过。

我替你定的（子代理提、主会话同意）：
- 程序数据文件夹就是 MineDeck.exe 所在的文件夹（servers 等都在它下面）。
- 程序数据文件夹是磁盘根目录、或者就是桌面、下载、文档、用户目录、Windows、Program Files 这类大文件夹（或它们的上一层）时不替你加：整个排除比不加还糟。
- 系统里到底加没加，没有管理员权限读不到，所以只记 MineDeck 自己加过没有（「已加入 · 时间」）；文件夹搬过以后只给「撤销」旧位置。
- 有服务器或备份放在程序数据文件夹外面时，状态后面写「放在别处的服务器不在里面」，不自动加别的路径。
- 用明文的 `-Command` 跑 PowerShell，不用编码过的命令：UAC 的「显示更多详细信息」里看得懂要做什么，编码过的写法也正是杀毒软件盯着的。

Gemini 4 Argon 分两半审过一轮，子代理照改了（aadf7e9），主会话编过 Windows 和 Mac 两边，跑过 `cmd/minedeck`、`internal/app`、`internal/web` 整个包和存储位置的界面测试，都过。改掉的要紧几处：
- 装了别的杀毒软件（Defender 是被动模式）或者实时防护被关掉时，以前也会说「已加入」，其实不起作用。现在加入前先查，不在工作就说清楚、不加。
- 「太大的文件夹不加」以前只比字符串，8.3 短名、目录联接、subst 盘符能绕过去；系统文件夹名单也漏了 AppData、公用文件夹。都补上了。
- 加完、撤完回读一遍系统的排除项核对；写不进 MineDeck 的配置时照实说「系统里已经改了，但 MineDeck 没能记下来」，不再说成功。
- 等管理员确认期间，传结果的临时文件一直被 MineDeck 占着，别的程序换不掉它（以前能被换成链接，让管理员权限的 PowerShell 写到别处）。
- UAC 里点了「否」以外的几种取消、组策略只禁了 PowerShell 本身，提示都改得更准。

要你知道的：
- 有一个测试会不提权地跑拼出来的 PowerShell 脚本，里面 Defender 的命令全换成了同名假函数，`Set-MpPreference` 一调就退出。不提权的话真命令本来也改不了设置，主会话决定留着；`go test ./cmd/minedeck -short` 会跳过它。
- 加进排除项的是程序文件夹原样的写法，不是解开联接以后的真实路径：程序放在联接、subst 盘符、映射盘上时，Defender 那边可能不生效。

**真机仍然一次都没跑过**：UAC 弹不弹、长命令行能不能完整传过去、加完马上回读读不读得到、装了别的杀毒软件时系统报的是什么，都要你在能改的电脑上点一次加入、一次撤销。
