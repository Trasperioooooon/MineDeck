# 弹窗、提示与报错

## 一、这一份管什么

三类东西：一是确认框（全程序 26 处，`app.js` 里 11 处，其余分散在待装清单、音乐共享、游戏内 AI、伙伴、助手、MCP 六个模块里）；二是右上角的提示条（toast，普通 3.5 秒、出错 6.5 秒，可点击关闭）；三是首启引导卡（用户协议与免责声明 + 选下载源 + 存放位置说明，同意后不再弹）。

报错到底怎么呈现，另有 `00-报错信息.md` 一份，那里已经有结论：正文一句中文，原始报错进「复制报错信息」；错误 toast 延长到 8 秒，并加「详情」按钮打开一个只读对话框。这一份不重复那套规矩，只处理具体的字。

跨模块的确认框（待装清单、音乐共享、游戏内 AI、伙伴、助手、MCP）跟各自那一页一起改，本份只列 `app.js` 的和全局壳。

## 三、不改的条目及原因

- 首启引导卡的标题「欢迎使用 MineDeck」、副标题「Minecraft 开服工具」、三段小标题（用户协议与免责声明 / 下载源 / 你的服务器将存放在）、按钮「同意并开始使用」：都短，且这是用户第一次见到的界面，不需要更好的说法。
- **用户协议与免责声明正文一个字不动**。它包含非官方声明、EULA 义务、正版建议、对外服务责任、MIT 免责五条，其中「NOT AN OFFICIAL MINECRAFT PRODUCT…」整句是商标声明，属于必须原样保留的文字。要压缩得作者和律师说了算，我不动。
- 引导卡里「每台服务器一个子文件夹。想放到 D 盘等大容量分区，可到「设置 → 存储位置」更改。」：一句事实加一条出路。
- 删除服务器确认框：标题点名（「删除服务器「生存服」？」）、默认勾选「同时删除服务器文件夹（含世界存档，无法恢复）」、按钮写字跟着勾选在「删除服务器」和「移出列表」之间变、默认聚焦「保留」——这几处是这一份里最要紧的写法，`tests.js:2576`–`2599` 也断言了其中大半，全部保留。
- 未保存守卫（「放弃未保存的修改？」+「当前页面还有 N 项修改没有保存，离开后这些修改会丢失。」+「放弃 N 项修改」「继续编辑」）：一句后果，两个都写得出的按钮。
- 其余确认框的标题与正文（还原备份、删除备份、删除隧道、清除 CurseForge API Key、保存后要重新填 Key、清除 AI 的 Key、停用 AI、退出 MineDeck）：都做到了「标题点名 + 一句后果」，「保存后要重新填 Key」那种还写清了为什么，`okText` 也都能单独读（「清掉 Key 并保存」「停用」「退出」）。
- toast 的 `title="点击关闭"`：这是给图标区补的可读名称，短。
- 局域网登录遮罩（「MineDeck 远程访问」「请输入访问密码（在主机的「设置 → 远程访问」中配置）」「访问密码」「登录」）：把去哪设密码直接写在正文里，这是用户唯一会卡住的地方。

## 四、没弄清、需要作者定的

1. 引导卡的下载源统一到设置页写法之后，三项里「Paper 和 Purpur 没有国内镜像」这句会出现在第一次打开的界面上。它有用但偏长，作者可能更想在引导卡里只留一句短说明。要不要为引导卡单写一套短版，请作者定。
2. toast 加「详情」按钮之后，出错时右上角会出现一个可点的气泡。点击气泡本身现在是「关闭」，加了按钮以后要点中按钮才展开，两个手势挨很近，需不需要改成交互（例如点气泡就展开详情，右上角另给一个小叉），属交互决定。
3. 「无法连接 MineDeck 后端」这句里「后端」是行话。若作者希望整句都用用户语言，可以改成「无法连接 MineDeck。请通过程序窗口打开本页面。」，`00-报错信息.md` 里也记过这一条。
4. 六个模块里的 15 处确认框，我只在各自页面那一份里写，没有汇总到这里；如果作者想一次看全，我可以补一张总表。
