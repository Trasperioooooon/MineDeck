# 服务器详情：音乐共享

## 一、这一屏是做什么的

把主机上的声音（整个系统，或某个程序）录下来，经 Simple Voice Chat 的语音通道推给已经连上语音的玩家。只支持 NeoForge 1.20.5 以上和 Forge 1.20.1 以上：SVC 和 MineDeck 的桥接模组都要在 `mods` 里，装完要重启服务器。

面板上半是「检查清单」，一条一条打勾：核心支不支持、SVC 装没装（可以点「安装」从 Modrinth 下）、桥接模组装没装、和游戏同端口的语音端口、远程好友的语音隧道（没隧道就给一条去「内网穿透」建 UDP 隧道的话）。下半是广播控制：开始 / 停止、正在听的人数、整机录音的警告、按程序录音时的音源列表、排除自己、音量。局域网打开时只能看状态和停止，开始必须在主机上。

这一屏还往内网穿透的表单里加两个字段：「用途」（游戏 / 语音）和自定义 frps 的「协议」（TCP / UDP）。

## 三、不改的条目及原因

- 检查清单每一条的标题与「都打勾了才能广播。装了 SVC 的玩家都能听到。每个人可以在 SVC 里单独静音。」：清单的语义就是逐项确认，副标题把「装了什么才能听」说全了。
- 五条「先…」的原因（先装 Simple Voice Chat、装好后要重启服务器、先装桥接模组、先开服）：每条四到九个字，是按钮按不下去时的唯一解释。
- 隧道那一条的说明（「远程好友要听到声音：在「内网穿透」添加一条 UDP 隧道，用途选「语音」、绑定这台服务器。只有局域网好友就不用管。」）：三步操作加一个可以不管的分支。
- 语音隧道的建法（樱花后台选 UDP、本地 IP 填 127.0.0.1、本地端口填 SVC 的端口、节点可以和游戏隧道同一个）：照做就能成的三步。
- 「同一时间只能有一个广播：先在那边停掉，再回来开始。」+「去看看」：条件、动作、入口都有。
- 听众行的三种状态（「2 人在听」「还没有人在听」「听众数：连上桥接模组后显示」）：数字由后端给，句式短。
- 「改用整机录音？」确认框（「仍然录整机」「先不录」+ 正文里「这台电脑确认一次就记住，以后不再问。」）：两个按钮都能单独读，且交代了不会再问。
- 桥接模组的加载方式（默认 / 备用、互换按钮）：两个词的状态，不需要解释。
