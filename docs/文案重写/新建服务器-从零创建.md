# 新建服务器：从零创建（向导各步）

## 一、这一页是做什么的

入口页点「从零创建」进的是这个向导。步骤条固定在页头下方，按核心不同是 4 步或 5 步：选核心、选版本、选构建、选模组或选插件（只有非原版有，可留空跳过）、基本设置。原版没有构建这一步，步骤条里那格是灰的，鼠标停上去写「原版无需选择构建」。

每一步都能点已完成的步骤回去改；单击选中、双击选中并进入下一步；版本默认预选最新正式版；底栏左边「上一步」、中间回显已选（如「已选：Paper · 1.21.4」）、右边「下一步」或最后的「开始部署」。基本设置的字段在离开时校验、出错后就地显示在字段下方，提交时全部检查并聚焦第一个出错的字段。

点「开始部署」后跳到部署任务页；如果「选模组」那一步往草稿清单里加过东西，会先等建服任务跑完再自动接着装（这是行为，不是文案）。

核心的名字、徽标和一句说明来自后端 `/api/cores`，源头在 `internal/mcsrc/registry.go`，不在前端。

## 三、不改的条目及原因

- 「新手推荐」标签与卡片 `aria-label` 里的「（新手推荐）」：两处一致，读屏也说得出来。
- 版本列表的「最新」「正式版 / 快照」标签、构建列表的「推荐」标签：一两个词，位置够。
- 搜索框占位「搜索版本号，如 1.20.1 / 26.2」、「显示快照版」开关：清楚，且「26.2」正好说明按年份编号的版本长什么样。
- 列表内空结果「没有匹配的版本」：输入框就在上方，不必再给操作。
- 「1.21.4 暂无 Paper 构建，请换个版本或核心」：发生了什么、下一步都写了。
- 三句字段校验（「请给服务器起个名字」「端口需为 1 ~ 65535 的整数，不确定就用 25565」「开服前需要同意 Minecraft EULA」）：都是就地显示、说清怎么改。
- 「上一步 / 下一步 / 开始部署」、底栏「已选：…」：动词短语，且「开始部署」与部署任务页的标题对得上。
- 「选模组」那一步的兜底错误「这一步的界面没有加载出来。可以先跳过，以后在这台服务器的「待装清单」标签里再加。」：已经写成一句说明加一条出路。
- 内存控件的「最大内存 -Xmx」「1 格 = 512 MB」「其他程序已用 … / 本服分配 … / 共 …」：技术名在这里有辨识作用（用户会拿它跟启动脚本对照），分段条也要靠图例才能读懂。
- 四处核心说明（Purpur、Fabric、Forge、以及上面没列的）我判断没问题，没动。

## 四、没弄清、需要作者定的

1. 步骤名走哪个方向：改「选核心」（保留「选插件」，不碰测试）还是全部「选择 X」（更正式，但要同步改 `tests.js:2847` 的断言）。
2. 「服务器介绍（MOTD）」下面要不要加一行说明写「支持中文与 § 色码」。加了是多一行文字，不加就是会的人自然会。
3. 核心卡的徽标（纯净 / 插件 / 插件+ / 插件·仿原版 / 插件·多线程 / 模组·轻量 / 模组·主流 / 模组·经典 / 混合·Forge+插件 / 混合·Fabric+插件 / 代理·主流 / 代理·经典）我没动：都在两到六个字，改了会顶宽。作者若觉得「插件+」「插件·仿原版」看不懂，我再给一套短说法。
4. 「新手推荐」现在只挂在 Paper 上。「从零创建」对一个完全不知道选什么的人仍然要自己判断，要不要给 Vanilla 也挂一个「最简单」，属于产品判断，没动。
5. 内存控件的分组条把三种状态压在一行（其他程序已用 / 本服分配 / 共），窄窗口下会换行。这是版式问题不是文案，没在预览里试过最小宽度。
