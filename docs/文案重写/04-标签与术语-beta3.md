# 标签与术语（v3.2.0-beta.3，2026-11-15）

这一份是 beta.3 这一轮的口径，取代 `详情-页头与控制台.md` 等文件里把旧标签名当既有术语的说法。依据是 `docs/可用性走查-2026-11-14.md` 第六节和 R23，加上作者 2026-11-15 的三句话：标签要改名；「内网穿透」不改名；术语表按 Claude 的推荐走。下面凡是标了「Claude 定」的，作者可以否决，改这里就行。

参与这一轮的人（不管是主会话还是子代理）改界面文字时都照这里写。新写的句子直接用新词；旧词由最后一轮统一清扫，清扫的验收是下面「清扫」一节列的词在界面文字里找不到。给 AI 助手和 MCP 看的说明照 `00-实例与服务器.md` 的旧口径，继续用「实例」。

## 一、服务器详情页的标签

从十几个平铺的标签收成七个。标签编号（地址里 `#/inst/<名字>/<编号>` 的那一段）和显示的名字如下，编号是各处代码互相引用的接口，定下来以后不要再改：

1. `console`「控制台」。
2. `players`「玩家」：在线、白名单（带总开关）、管理员、封禁。代理端没有这一项。
3. `world`「世界与备份」：备份列表、立即备份、还原；能换地图的核心上还有「换地图」和恢复点。代理端没有这一项。子页编号 `backups`（默认）、`map`。
4. `addons`：插件服叫「插件」，模组服叫「模组」，两样都能装的（Mohist、Banner）叫「插件和模组」。合并原来的「资源」和「待装清单」：上面是已安装，下面是热门、搜索、从电脑添加。原版（vanilla）没有这一项。
5. `tasks`「定时任务」。
6. `settings`「设置」，子页：`common`「常用」、`jvm`「启动与内存」、`raw`「全部配置」。代理端只有「启动与内存」。不带子页时进「常用」，代理端进「启动与内存」。
7. `ext`「扩展」：游戏内 AI（`gameai`）、AI 伙伴（`companion`）、音乐共享（`music`），这台服务器有哪个列哪个，一个都没有时这个标签不出现。

旧地址要跳到新地方，AI 助手、提示和书签里都还用着旧的：`backups` → `world/backups`，地图导入原来就叫 `world`，现在落到 `world` 页上能看到换地图那一块；`res`、`cart` → `addons`；`common`、`raw`、`jvm` → `settings/common`、`settings/raw`、`settings/jvm`；`gameai`、`companion`、`music` → `ext/` 后面接同名的子页。

文字里提到这些地方时用「标签 → 子页」的写法：「到『设置 → 启动与内存』里换 Java」「在『世界与备份』里还原」。

## 二、页头的提示区

详情页头下面有一块常驻的提示区（`#d-notices`），这几类提示都放在这里，有就显示，事情解决了就消失，不靠右上角会自己消失的提示：上次启动失败的原因（R03）、整合包里没装上的文件（R09）、Java 路径失效（R21）、模组要求更高的 Java（原来就有的那条）。谁先做到页头谁建这块，后面的人往里加。

## 三、术语（Claude 定）

**世界。** 服务器里的游戏世界一律叫「世界」，不叫「存档」，也不和「地图」混着叫。「地图」只出现在从外面带进来的那件事上：新建页的「用已有地图开服」、世界与备份里的「换地图」。

**还原、恢复点、换回。** 把备份放回去叫「还原」，不叫「回滚」。「恢复点」只指换地图之前自动留的那一份，把它放回去叫「换回」。

**内网穿透、隧道、连接地址。** 左侧栏和页面名仍叫「内网穿透」，作者定了不改。里面的每一条叫「隧道」。「联机」不当页面名、功能名用，只在句子里当动词（「和朋友联机」）。朋友在游戏里填的那串 `地址:端口` 叫「连接地址」：同一局域网的朋友用详情页头和卡片上的连接地址；不在同一网络的朋友用隧道给出的「公网地址」。内网穿透页顶要有一句指路，告诉人同一局域网不用隧道。

**手机远程管理。** 设置里原来的「远程访问」「允许局域网访问」改叫「手机远程管理」，说的是用手机或别的电脑的浏览器打开 MineDeck 的管理页。页顶写一句：让朋友进游戏的地址在服务器页上，不在这里。

**AI。** 三样东西三个名字：标题栏上那个叫「AI 助手」（不叫「应用内助手」）；每台服务器里在游戏聊天里回话的叫「游戏内 AI」；陪玩的那个叫「AI 伙伴」（标签上也写全）。

**导出交接包、导入交接包。** 菜单、弹窗标题、按钮都叫「导出交接包」；不用「交接给其他电脑」「开始打包」。反过来是新建页的「导入交接包」。

**待装清单、没装上的文件。** 「待装清单」仍是插件 / 模组页里那份「挑好了、还没装」的清单。导入整合包时没能自动装上、要人来处理的那些文件，界面上叫「没装上的文件」，不再叫「待决文件」「待决清单」（只差一个字，太容易和「待装清单」弄混）。代码和接口里的 pending 名字不用改。

**插件、模组。** 插件服（Paper、Purpur、Leaves、Folia，以及代理端）上说「插件」，模组服（Fabric、Forge、NeoForge）上说「模组」，Mohist、Banner 两样都说。不要在插件服上把插件叫成「模组」。

**创建，不说部署。** 「正在创建服务器」「服务器已建好」，不用「部署」。

**状态。** 服务器：启动中、运行中、停止中、已停止。隧道：运行中、已停止；还没拿到过地址时写「还没拿到地址」，不写「尚未启动」。

**取消。** 弹窗里「什么都不做、关掉」的键一律叫「取消」。不要用「保留」当取消键，它会被读成「保留文件夹」。

**启动与内存。** 原来的「内存 / 启动」。

**移出列表、删除。** 只把服务器从 MineDeck 里拿掉、文件夹留着，叫「移出列表」；连文件夹一起删才叫「删除」。

## 四、清扫

最后一轮在界面文字（`internal/web/ui/` 下的页面、脚本、`props-catalog.js`，以及后端会显示到界面上的提示和报错）里找下面这些词，除了注明的例外，找到的都改掉：「存档」、「回滚」、「部署」、「应用内助手」、「待决」、「资源」作标签名、「内存 / 启动」、「常用设置」「全部配置」作标签名、「交接给其他电脑」、「尚未启动」、作取消键的「保留」、「远程访问」「允许局域网访问」作分区名。例外：给 AI 和 MCP 看的说明；`docs/` 里的历史记录；代码里的变量名和接口名。
