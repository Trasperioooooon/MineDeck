# 服务器详情：伙伴

## 一、这一屏是做什么的

管理服务器里的 AI 角色（伙伴）。四块：装模组（伙伴模组、PlayerEngine、Architectury API 三个，缺哪个装哪个，旧版本要整理 mods 目录）、告诉好友客户端要装什么（可以复制一段说明直接发群里）、设置（总开关、伙伴上限、攻击时不许打的生物、禁挖区域）、伙伴与事件列表（刷出、停下、移除，最近发生过什么）。

没配置 AI、核心不支持、加载器版本不对时，上面会出现对应的警告卡。刷出伙伴是弹窗：填名字、选主人、选出生位置。移除伙伴默认连背包一起清掉，可以勾选让背包留在地上。禁挖区域按坐标圈，添加和编辑都在弹窗里。

## 三、不改的条目及原因

- 四个警告卡的标题（「这台服务器用不了 AI 伙伴」「加载器的版本不对」「AI 还没配置」）：一句一个原因，正文由后端补原因，分工清楚。
- 「攻击时不许打的生物」与说明（「填生物 ID，用逗号隔开。清空表示没有额外限制。玩家、伙伴、驯服的、起了名字的、拴着的，不管这里怎么写都不打。」）：把「填什么」和「哪些永远不打」分开说，正是这一项最容易出错的地方。
- 禁挖区域的空态与弹窗说明（「把家、农场这类不想让伙伴动的地方圈起来。按 F3 能看到自己脚下的坐标。」「两个角的坐标」）：给了判断依据，也给了取坐标的方法。
- 移除伙伴的确认框（「伙伴会从世界里消失。默认背包里的东西一起消失；想留下来，勾上下面这项。」+「背包里的东西掉在原地」）：默认值与例外都写明，勾选项本身就是答案。
- 刷出伙伴弹窗（标题「刷出伙伴」、字段「名字」「主人」「出生在」、正文说明主人不在线时落在世界出生点）：三个字段两个词，正文只讲例外。
- 「三个都装好了」「装好了，重启服务器后生效」「都装好了，没什么要改的」三句状态：短，区分「已装」和「装了但没生效」。
- 空态两句（「还没有伙伴」+「连上伙伴模组以后，伙伴会列在这里」、「还没有事件」+「连上伙伴模组、刷出伙伴、伙伴开始和做完任务时，这里会记一笔。」）：说明来历，不是空转。
- 「要装 / 不用装」两种好友客户端标签：两个字，一列并排。

## 四、没弄清、需要作者定的

1. 「伙伴」和「AI 伙伴」两种叫法并存：标签叫「伙伴」，设置里的总开关叫「打开 AI 伙伴」，警告卡叫「AI 伙伴」。要不要统一（全用「伙伴」或全用「AI 伙伴」），牵动标签名和设置页，等作者定。
2. 「攻击时不许打的生物」这个说法偏长，也可以叫「不攻击的生物」，但会与下面那句「不管这里怎么写都不打」重复。作者挑。
3. 好友客户端那段的完整说明与「复制给好友的说明」里的文本（`PACK_GUIDE`）是两套字，我只改了页面上那句；复制的文本没有逐字核过一致性。
