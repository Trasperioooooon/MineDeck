# 设置：九个分区

## 一、这一页是做什么的

左侧九个分区，右侧是对应表单：外观、下载与网络、存储位置、Java 运行时、远程访问、通知与集成、AI（可选）、启动与托盘、更新与关于。切分区只换右侧内容。绝大多数项是**改了就生效**（开关、单选卡、外观选项）；带「保存」键的单字段是 CurseForge Key、Webhook、更新仓库、访问密码、每日额度；AI 服务商和自填单价是吸底保存条。

只在运行 MineDeck 的那台电脑上能改的：存储位置的三个目录、AI 的服务商与 Key（局域网打开时只读）。改存储位置只影响以后新建的服务器和备份，已有的不搬。

## 三、不改的条目及原因

- 九个分区的名字（外观、下载与网络、存储位置、Java 运行时、远程访问、通知与集成、AI（可选）、启动与托盘、更新与关于）：名词短语，长度接近，导航竖排也不折行。
- 下载源三张卡的文字（「自动（推荐）」「仅国内镜像」「仅官方源」+ 各自一句说明）：说明里写清了「Paper 和 Purpur 没有国内镜像，这两项仍从官方下载」这种容易被误解的地方。
- CurseForge Key 的状态说明三句（「加密保存在这台电脑上。换电脑或换 Windows 用户后需要重填」「密钥无法解开…」「清除后，导入 CurseForge 格式的整合包时无法自动下载模组」）：分别是保存方式、异常、后果，各说一件事。
- 三个目录行（服务器存放目录 / 备份存放目录 / 程序数据目录）的说明与「打开」「更改…」「恢复默认」三个键及其 `aria-label`：名字里带上了是哪个目录，测试也按这套名字找控件。
- AI 那几行的标题与说明（服务商、协议、接口地址、模型、思考深度）：`sub` 里是随状态变的内容（预设地址、Key 状态、价格来源、模型单价），这些由代码按状态拼，句式已经稳定。
- 「停用 AI」与「退出程序」两处危险区、以及它们的确认框：后果都写在正文里。
- 关于那一段（字体许可、开源协议、商标声明）：这类文字按原文保留，不改写。
- 更新那一组（当前版本、更新仓库、启动时静默检查更新、检查更新、立即更新并重启）：动词短语，行为明确。

## 四、没弄清、需要作者定的

1. 「开机自动启动」里那句「程序换了文件夹以后，把这个开关关一次再开，路径就会改过来」我按「实现细节」删掉了。但这是用户会撞上的真问题（移动程序目录后自启失效）。要不要保留成一句独立的提示（例如放在开关下方），请作者定；保留的话建议写成「程序换过文件夹后，需重新开关一次」。
2. 首启引导卡里的下载源三项写法（「自动（推荐）— 国内镜像优先，失败自动回退官方源」）与设置页的（「自动（推荐）」「国内镜像（BMCLAPI / 清华）优先，失败自动切换官方源」）不一致：一个用破折号连写，一个分行。建议两处统一成设置页的写法，但那要动引导卡，归到「弹窗与提示」那一份。
3. 「远程访问」一节里的防火墙命令（`netsh advfirewall firewall add rule …`）是原文，需要管理员权限，属于必须给的东西，没改。
4. AI 的「隐私」那一段（提问和结果会发给服务商；Key 加密保存、不发到界面、不写日志；价格只是取公开表）是这一屏唯一的合规说明，我一个字没动。要压缩的话得作者确认哪些可以省。
