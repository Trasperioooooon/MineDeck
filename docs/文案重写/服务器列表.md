# 服务器列表

> 术语方案已定（作者选定方案 A：界面一律叫「服务器」）。第 6、8 条改成渲染预览判断：把这一页的 12 条修订应用到 `internal/web/ui` 的一份拷贝上，用仓库里的仿真后端跑起来，看截图与原型。源码没有改动。

## 一、这一页是做什么的

侧栏第一项「服务器」（快捷键 1）进来的页面，列出这台电脑上 MineDeck 管着的全部服务器，一台一张卡片。卡片上写名称、核心、Minecraft 版本（代理端写代理端自己的版本号）、端口、内存、Java 大版本和运行状态；运行中再显示在线人数与已运行时长，启动中显示分段进度和已用时间，正在停止时写「保存世界」。卡片上的「启动 / 停止」直接调后端接口启停，点卡片空白处或名称进详情页。

页头一行小字汇总台数、运行中台数和在线总人数。下面是工具条：按名称搜索（只匹配名称，不匹配端口、版本），以及三种排序——最近创建（后端按创建时间倒序返回，`internal/inst/inst.go:183`）、运行中优先、名称。列表每 3 秒轮询一次，数据没变化不重绘。

一台都没有时，标题、工具条和排序都隐藏，只剩空状态：图、一句说明、一个「新建服务器」主按钮和一个次要链接。页头右上角的「新建服务器」和空状态里的「新建服务器」落点不同：前者去四选一的入口页，后者直接进从零创建的向导。

本次运行里有后台任务时，卡片上方多一条「部署与下载任务」，列出正在部署、已完成和失败的任务，每行一个入口（查看进度 / 查看结果 / 去处理）。这条也出现在新建服务器页和它的各个子页，文案统一在「部署与任务页」那一份里写，本页只列了一个显示问题。

卡片的「···」菜单里有三段：打开文件夹（服务器本身及模组、插件、世界存档、日志、崩溃报告等子文件夹）、导出交接包（服务器必须停着）、删除服务器（停着才可点）。删除确认框属于「弹窗、提示」那一页，本页不写。

## 三、不改的条目及原因

- 页头标题「服务器」、侧栏同名项、右上角「新建服务器」：已经是最终说法；无障碍测试里登记了例外——侧栏的「新建服务器」和列表页头的「新建服务器」指向同一处，名字一样才对（`tests.js:2317` 的注释）。
- 搜索框占位与 `aria-label`「搜索服务器名称」：动宾清楚，两处一致。
- 排序三项「排序：最近创建 / 运行中优先 / 名称」：下拉框没有可见标签，前缀「排序：」是唯一说明，去掉之后光看「最近创建」不知道是在排什么。
- 状态胶囊「运行中 / 启动中… / 正在停止… / 已停止」：进行中带省略号是这个程序的统一写法（浏览…、上传中…、识别中…），保持一致。
- 状态行「3/20」「已运行 2h13m」「启动中 12s」「保存世界」：各带一项独立信息（人数、时长、正在做什么），并且要能离开胶囊单独读懂（截图、读屏）。
- 「启动 / 停止 / 管理 / 更多操作」以及「启动 生存服」这套 aria-label：符合「可见文字 + 对象」，`tests.js:2359` 断言了这套名字。
- 提示「「X」正在启动」「「X」正在停止并保存世界」：一句话说清点了以后会发生什么，其中「保存世界」解释了为什么不会立刻停。
- 菜单里的注记「需先停止服务器」、整卡可点、图标按钮的 title「更多操作」：陈述条件，没有劝告语气，也不缺名字。
- 卡片副标题「游戏服务器 / 群组代理」：说明这台是不是代理端——代理端不显示端口和在线人数，只看核心徽标看不出来。
- 任务条标题「部署与下载任务」与三枚入口「查看进度 / 查看结果 / 去处理」：三者区分明确，「去处理」被 `tests.js:2623` 断言。

1. **术语**：`00-实例与服务器.md` 里的方案 A 已定（界面一律叫「服务器」）。剩下「目录 / 文件夹」这一对没定：本页第 7 条按「文件夹」写成「服务器文件夹」，若作者选「目录」，改成「服务器目录」，其余不动。
2. **第 6、8 条**：不再靠表格判断。改后的样子在 `%TEMP%\minedeck-copy-preview\shots\` 下的截图里，也可以在 `http://127.0.0.1:27411/__proto/` 上点（那份预览只应用了本页的 12 条，其他页面仍是原样）。
3. **同一个名字两个落点**：页头「新建服务器」去四选一入口页，空状态「新建服务器」直接进从零创建（`app.js:977` 与 `1087`）。一个名字两种行为，要不要给空状态那个改成「从零创建」？我没动，等作者定。
4. **任务条的「已完成，有提示」**：`warningCount` 里混着哪几类提示（没校验的文件、同名没覆盖、Java 版本偏低等）我没逐条核。要写清就得带上条数或类别，模板会多一个占位，按硬性限制我不能自己加。
5. **搜索无结果只留一句话，没有「清除搜索」这个动作**：输入框就在正上方，我倾向不加控件；如果按「空状态一句说明加一个主操作」从严，这里缺一个操作。
6. **代理端卡片的「v3.4.0」**：这是代理端自己的版本号（Velocity、Waterfall），和「MC 1.21.4」并排时那个「v」不表意。写成「代理端 3.4.0」会和副标题重复，只留核心徽标又丢了版本号。三种取舍请作者定，本轮不动。
7. **首启引导卡**（场景 l-onboard）盖在这一页上：它是弹窗，归到「弹窗、提示」那一页一起写，本页不重复。
