# 服务器详情：页头与控制台

## 一、这一页是做什么的

点服务器卡片进的是这个页面，默认停在「控制台」。页头一层是面包屑（服务器 → 这台的名字），下面是像素头像、名字、状态胶囊（运行中带时长和在线人数）、核心徽标、版本徽标、Java 徽标，靠右是「启动」「停止」「打开目录」三个按钮，状态轮询 2.5 秒一次。

页头下面一排标签按核心和功能开关显示：控制台、玩家、备份、定时任务（代理端没有玩家和备份）、资源（原版没有）、待装清单、音乐共享、游戏内 AI、伙伴、常用设置、全部配置、内存 / 启动。标签的取舍规则在 `docs/功能清单.md` 里也写了一份。

控制台这一屏：工具条有日志过滤、自动滚动开关、编码选择（auto / utf-8 / gbk）、字号加减、复制全部、导出 txt；下面是日志区（3000 行上限，按 ERROR/WARN 着色），再下面是命令输入框、发送键和一排键盘提示。命令有历史（↑↓）、补全（常用命令、白名单子命令、在线玩家名）。日志走 SSE，断线会在日志里补一行提示。

页头还会在一种情况下多出一行提示：装的模组要求比当前 Java 更高的版本时，给一条去「内存 / 启动」换 Java 的链接（只提示，不阻断启动）。

## 三、不改的条目及原因

- 页头的「启动 / 停止 / 打开目录」与它们的 `aria-label`（「启动 生存服」「停止 生存服」）：符合「可见文字 + 对象」。「打开目录」这一个词等「目录 / 文件夹」定了再统一，本页不单独改。
- 标签名（控制台、玩家、备份、定时任务、资源、待装清单、音乐共享、游戏内 AI、伙伴、常用设置、全部配置、内存 / 启动）：都是既有术语，且「待装清单」已经替换掉了旧名「购物车」。
- 状态胶囊的文字（运行中、启动中…、正在停止…、已停止）与「· 2h13m · 3/20 人」这段：与列表页共用同一套写法。
- 工具条的「过滤日志（如 ERROR / 玩家名）」「自动滚动」「A-」「A+」「复制全部」「导出为 txt」：短、名词或动宾，图标按钮都有名字。
- 键盘提示那一行（回车 发送 / Tab 补全 / ↑↓ 翻历史 / Esc 关掉补全 / 在别处按 T 或 / 跳到这里）：每条一个动作，读起来是清单。
- 命令输入框的占位「如 op 玩家名 / say 大家好」与 `aria-label`「服务器命令」：一个给例子，一个给名字，各司其职。
- 三句 toast（「正在启动，首次生成世界可能需要一两分钟」「正在保存世界并停止」「编码已切换，对之后的新输出生效」）：都在说「这一下会发生什么」，其中第一句提前交代了首次启动要等，属于有用信息。
- 日志里的「[MineDeck] 控制台连接中断，切换页面可重连」：这是程序输出的一行，带方括号前缀便于和服务器输出区分，且给了办法。

## 四、没弄清、需要作者定的

1. 「打开目录」这个按钮名取决于第二组术语（目录 / 文件夹）。若统一成「文件夹」，这里是「打开文件夹」，与卡片菜单的「服务器文件夹」一起改。
2. 控制台编码下拉改用中文显示后，`auto` 这个值本身在别的地方（`server.properties`、日志）没有对应物，用户可能想知道「自动」到底按什么判断。要不要在下面加半句说明，取决于作者要不要在这屏加文字。
3. 我这一轮只写了页头和控制台。玩家、备份、定时任务、资源、待装清单、常用设置、全部配置、内存 / 启动、音乐共享、游戏内 AI、伙伴这十一屏还没写，接下来逐个来。
