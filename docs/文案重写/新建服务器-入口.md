# 新建服务器（入口）

## 一、这一页是做什么的

侧栏第二项「新建服务器」（快捷键 2）进来的页面，把建服务器的四条路分成两组摆成卡片：新开一台——从零创建、导入整合包；把现成的搬进来——导入交接包、接管已有服务器。卡片整块可点，单击进入对应的页面或向导，键盘 Tab 进来、空格选中、回车进入。从零创建进的是向导第一步（选择核心）。

页头只有标题「新建服务器」和一句副标题，没有按钮。眉标写「四种方式 · Java 与服务端自动下载」。本次运行有后台任务时，卡片上方多一条「部署与下载任务」，和服务器列表页是同一条，文案统一在那份里写。

## 三、不改的条目及原因

- 标题「新建服务器」、副标题「选一种方式开始。」：短、中性，回答「现在要做什么」。
- 四张卡的名称：与后续页面的标题、面包屑、别的页面的指路说法一致（「新建服务器 → 接管已有服务器」），测试也按这几个名字指路。
- 卡片的 `aria-label` 只放名称：描述通过 `aria-describedby` 指向卡片里的 `.cd`，读屏会读出来，不必重复进名字。
- 「其它」分组（`app.js:1691`）：只在核心清单里出现未知核心时才有，正常看不到，本轮不动。
- 任务条：与服务器列表页同一个组件，文案在那份里统一。

## 四、没弄清、需要作者定的

1. 分组名改「新建 / 导入与接管」之后，第一组里同时有「从零创建」和「导入整合包」，「导入」在两处出现会不会觉得重复？另一种写法是第一组叫「新建」，第二组叫「接手现成的」。两种都行，等作者定。
2. 页头副标题现在只有「选一种方式开始。」，没有说明这四种方式的区别——卡片自己写了。要不要在副标题里写一句「不知道选哪个就用从零创建」？这属于引导，按中立标准我没加。
