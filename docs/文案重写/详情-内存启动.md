# 服务器详情：内存 / 启动

## 一、这一屏是做什么的

改这台服务器分到的内存、追加的 JVM 参数，以及用哪个 Java。内存那块是和向导、导入页共用的同一个控件（滑条 + 精确输入 + 本机内存条）。JVM 参数是一个文本框，每行一个或用空格分隔；`-Xmx` 和 `-Xms` 不在这里填，由上面的内存自动生成。旁边两个快捷键：「套用 Aikar's Flags」按当前内存大小填一套 G1GC 参数，「清空」把文本框清掉，两个动作都会保留老版本加上去的 log4shell 缓解参数。

Java 是一个下拉加「更换 Java」：列出 MineDeck 下载的、本机装好的，以及本机没有但可以现下的版本（约 50 MB）；当前用的那个标「· 现在用的」。要下载的话点了会跳任务页。

内存和 JVM 参数走吸底保存条（运行中保存要重启生效）；换 Java 不走保存条，点「更换 Java」立即写进实例。

## 三、不改的条目及原因

- 「套用 Aikar's Flags（G1GC 优化）」：专名原文保留，括号里说明它是干什么的。
- 「清空」：两字，行为明确（文本框清空，安全参数保留由提示交代）。
- Java 下拉里三行选项的写法（「Java 21（MineDeck 下载的）」「Java 17（本机装的 17.0.9：路径）」「Java 25（本机没有，下载一份，约 50 MB）」）与「· 现在用的」后缀：把来源、路径、要不要下载都写在同一行，选的时候不用再点开看。
- 「更换 Java」按钮与它的行为不一致之处（不经过保存条）：由按钮上的「更换」二字和提示里的「下次启动生效 / 重启服务器后生效」交代，没另加文字。
- 三条 toast（「已换成 Java 21，下次启动生效」「已保存内存与 JVM 参数（已自动补回 log4shell 漏洞缓解参数）」「已填入 Aikar's Flags（保留 log4shell 漏洞缓解参数），保存后生效」）：都在说清做了什么、什么时候生效、顺带交代了安全参数没被冲掉。
- 保存条上的「运行中：保存后需重启生效」：与常用设置同一句式。

## 四、没弄清、需要作者定的

1. 「服务器文件夹 / 目录」按第二组术语定，这一行会跟着改一个词。
2. log4shell 缓解参数在三条提示里都出现。对不知道这段历史的用户，这四个字没有意义；要不要只在真的补回时才提（现在的实现就是这样），还是统一改成「安全相关参数」，等作者定。
3. Aikar's Flags 的内容按内存大小分两档（≥12 GB 一套，否则另一套），这一点文案里没写，用户也不需要知道。但如果作者想让人明白「套用」会覆盖文本框里的现有内容，可以在按钮旁加半句，属于加文字。
