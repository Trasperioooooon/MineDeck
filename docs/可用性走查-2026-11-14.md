# MineDeck 可用性走查报告（v3.2.0-beta.1，2026-11-14）

这份报告回答作者提出的问题：页面组织不清楚、入口分散、有些功能藏在想不到的地方，用户想做一件事时不知道先去哪。做法是让两位没看过源码的走查员（Claude 子代理）各扮演一类用户，在真的 MineDeck 窗口里完成 23 项任务，把每一步截图；然后由主会话对照源码解释原因，并在真窗口里补测几处没有定论的地方。最后给出导航调整、流程前后对照和可以直接交给开发 Agent 的整改清单。

本报告不改任何产品代码。被测程序是 main 的 c970a67，代码与标签 v3.2.0-beta.1 相同（c970a67 只比标签多了文档提交）。下文所有代码行号都指这个提交。

证据的标法，后文每条结论都带着：

- 【盲测】：第一轮走查员在真窗口里看到的，带截图编号。A 开头是首次使用者（`D:\MineDeck-ux\round1\first\shots\`），B 开头是回访用户（`round1\return\shots\`）。
- 【主控实测】：第二轮主会话在真窗口里复核的，R2 开头（`D:\MineDeck-ux\round2\…\shots\`）。
- 【源码】：只从代码判断，没有在界面上验证。
- 【假设】：可用性推断，还需要验证。

挑出来的 17 张关键截图放在 `docs/可用性走查-2026-11-14/`，文件名和对应的问题见第十节末尾的索引。两份完整的走查记录（共约 14 万字节）和全部 600 多张截图在 `D:\MineDeck-ux\`，没有入库。

## 一、最重要的发现

下面七条最影响使用，按「挡住了多少人做多常见的事」排。每条都是从一个具体任务里撞出来的。

**1. 开好服务器以后，软件里找不到「朋友该连哪个地址」。** 首次使用者开完第一台服务器，想把地址发给同一个局域网的朋友，翻了 8 个地方、用满 20 步都没找到本机 IP，只在卡片上看到端口（A2，#0027–#0053）。全软件唯一显示局域网 IP 的地方是「设置 → 远程访问」，那是给手机打开管理页用的，而且要先打开局域网访问并重启才显示（app.js:4232–4257）。它的名字「允许局域网访问」恰好像「让局域网朋友连进来」，走查员读了小字才明白是手机管理页，并在记录里提醒「只看开关名字的人很可能把它打开」。这是「和朋友一起玩」最要紧的一句话。【盲测 + 源码】

**2. 新建的 26.3 服务器默认开着白名单，而且名单是空的，全程没人提醒。** 首次使用者以为任务 1 已经做到「朋友现在就能连」，直到任务 5 改人数时才在「常用设置 → 玩家与权限」里看到开关是开的，下面一行黄字「注意：此版本起白名单默认开启」（A #0084）。主控核对了配置文件：没人动过的原版 26.3 服务器「创造小镇」的 server.properties 里是 `white-list=true`。更糟的是「玩家」标签里白名单那一块的说明写着「要在『常用设置』里打开白名单才生效」（app.js:2786），读起来像默认关着，和实际相反。新建向导选版本时默认就是最新的 26.3，所以按默认值走的新手都会碰上。【盲测 + 配置文件核实，未用游戏客户端验证】

**3. 启动失败的原因只在右上角闪几秒，端口被占这一类过后不留任何痕迹。** 回访用户新建的服务器第一次启动因端口被占失败，提示消失后状态是「已停止」、控制台全黑，他是事后翻截图才知道为什么（B7，#0133–#0135）。首次使用者第一次去点提示上的「详情」时提示已经没了（A8 #0175），第二次赶在消失前点上，弹出的「报错信息」只是把同一句话再写一遍（#0178）。卡片上从来不显示「上次启动失败」。原因：错误提示 8 秒自动关（app.js:159，秒数来自源码）；端口被占时启动检查直接返回错误，不往控制台写（internal/inst/proc.go:95–97），而找不到 Java 时会在控制台写一行（proc.go:88–91，回访用户任务 5 看到了这一行），两种失败留痕不一致。【盲测 + 源码】

**4. 弹窗里出了错，想看「详情」，弹窗连同填好的内容会一起丢掉。** 有两条路，结果一样：
- 走查员碰到的那条：回访用户导出交接包时文件夹不存在，报错后约 17 秒才去点「详情」，提示早已按 8 秒规则消失，点中的是交接弹窗的遮罩；交接弹窗「点遮罩就关」（app.js:1627），不问一声，路径丢了，详情也没出现（B8 #0156–#0158，时间见 actions.jsonl 第 156、158 条）。【盲测 + 源码】
- 主控补测的那条：提示还在时（3 秒内）点「详情」，「报错信息」窗口直接把交接弹窗替换掉，关掉详情后交接弹窗和填的路径都没了（R2 return #0057–#0066）。原因是「详情」和确认框都对共用的 `#modal-root` 整体写 `innerHTML`（app.js:163–170、288–297），而交接弹窗是追加进同一个容器的（1625）。这是缺陷。【主控实测 + 源码】

**5. 删除服务器时，「同时删除服务器文件夹（含世界存档，无法恢复）」默认是开着的，取消键叫「保留」。** 回访用户只想把一台服务器从列表里拿掉，弹窗里开关默认开（B11，#0197）；他停下来读了小字、关掉开关才点。按代码，如果不读就直接点红色按钮，文件夹和世界会一起删掉（走查员没有真的这样点）。「保留」二字恰好对上「我要保留文件夹」，容易被当成「保留文件夹并删除」。两位走查员看到的默认值相反，是同一条规则：自己建的服务器默认开，接管来的默认关（app.js:1088–1090）。【盲测 + 源码】

**6. 一台服务器的操作散在四处，进了详情页反而找不到导出和删除。** 详情页有 11 个平铺的标签（控制台、玩家、备份、地图、定时任务、资源、待装清单、游戏内 AI、常用设置、全部配置、内存 / 启动），页头只有启动、停止、打开文件夹。「导出交接包」「删除服务器」只在列表页卡片右下角那个只有图标的「···」里（app.js:1237–1244），详情页没有。回访用户能找到，全靠任务 4 找隧道时乱翻碰巧见过（B8、B11 的「预计入口」里都写明了）。端口不在详情页头，文件夹路径在「内存 / 启动」最底下一行灰字，备份放在哪要去全局「设置 → 存储位置」看。【盲测 + 源码】

**7. 还没连上过的隧道什么都不告诉你，而且所有隧道都改不了。** 回访用户找到了上次设的「朋友联机」，但该显示地址的位置写着「尚未启动」，没有复制；「开服时会不会跟着启动」完全不显示；也没有编辑，看起来只能删了重建。这是回访用户 11 项里唯一没做成的（B4，#0050–#0080；全部 23 项里没做成的还有首次使用者的 A2 和 A12a）。原因：地址只取 frpc 跑起来后回写的 `publicAddr`，被测的是一条从没启动过的假隧道，所以没有；按代码，跑过一次、拿到过地址的隧道停下后仍会显示上次的地址（这一点没在界面上验证）。自定义 frps 的「地址:公网端口」事先就知道，也不拿来显示。「跟随」只在打开时以「 · 跟随」出现，关着时什么都不写（app.js:3806–3817）；后端早有 `PUT /api/tunnels/{id}`（internal/web/server.go:101），界面只在「清除凭据」时用了它（app.js:3891）。【盲测 + 源码】

紧随其后的几条：端口冲突的报错不说是「你的另一台服务器」占的、也不带你去改端口（A8、A10）；整合包里没装上的文件只在那一次运行的界面上能处理，重开软件后在软件里无处可寻（A12a + 主控实测；磁盘上留有一份 txt，界面不提）；装插件有「资源」「待装清单」两个做法不同的入口，而且哪里都看不到「已经装了什么」（A7）；没有重启按钮，「改完要不要重启」的提示互相矛盾（A5）。

两位走查员的总体印象各有侧重。首次使用者的话是：「把服务器开起来」这一段很顺，首次引导、新建向导、导入整合包、接管旧服务器几乎一路点默认就成；卡住的地方几乎都在「开起来以后」——朋友怎么连、装了什么、出了错去哪改、上次没弄完的东西去哪找。回访用户的话是：常做的事都在第一反应的地方，让他费劲的不是功能没有，而是出了错没人告诉第二遍、有些东西只在特定状态下看得见、同一类操作的入口分在三四处、有两处默认值偏向危险的一边。两人各自排的前五名几乎不重叠（首次：连接地址、白名单、端口报错、装插件、待决文件；回访：报错不留痕、隧道、删除默认值、入口分散、前提不提前说），上面七条是两边合起来、按影响重排的。

## 二、走查条件和覆盖范围

### 能检查到什么

能打开并操作真正的 Windows EXE。程序按发布参数编译（`-H windowsgui`），在 `D:\MineDeck-ux` 的两份独立副本里运行，LOCALAPPDATA、APPDATA、TEMP 都指进副本，不碰作者本机的 MineDeck。WebView2 多开一个调试端口，脚本经它把鼠标、键盘事件送进窗口，页面里跑的就是发布出去的那份界面代码。

走查员能做的：截图（Read 打开图片看）、按坐标点击和双击、悬停并读出系统悬停提示（title）、打字、按键、滚动、拖动、在下拉框里选、在「打开文件」对话框里选文件、在系统「选择文件夹」对话框里填路径。不给他们页面地址，不让调接口、读 DOM 或无障碍树；可以「找屏幕上看得见的字」拿坐标，但用它找到入口要在记录里写明。脚本和规则已入库：`tools/ux-walkthrough/`。

### 两位走查员和盲测的局限

- 首次使用者：全新副本（只放了下载缓存，Java 和服务端从缓存「下载」，所以下载很快），12 项任务，298 张截图，约 45 分钟。
- 回访用户：主控预置了三台服务器（Paper 1.21.11「生存服」带两份备份；原版 26.3「创造小镇」；原版 1.21.11「旧电脑搬来的服」，instance.json 里的 Java 路径改成不存在的 `E:\OldPC\…`，模拟从旧电脑拷来）和一条不会启动的自定义 frps 假隧道「朋友联机」。11 项任务，219 张截图，约 36 分钟。
- 主会话（写这份报告的这一个）通过记忆熟悉源码，所以第一轮交给两个没接触源码的 Fable 5.2 子代理，规则写明不读源码、文档、程序数据文件和驱动源码。两人都报告照做了；它们的会话启动时系统自动带入了全局规则和记忆索引的几行摘要（提到 MineDeck 的版本和 PR，不涉及界面结构），这一点照实记下。
- 回访用户其实没真用过这个软件，只是有预置数据、被告知「记不清菜单在哪」，算是「记忆最差的回访用户」。真正「隔一段时间再回来」的检验是首次使用者的任务 12（关掉程序重开后做三件事）。
- 任务清单是熟悉源码的主会话写的，只写目标、不写路径。回访用户的任务 6、8、11 的入口是在任务 4 里乱翻碰巧见过的，记录里各自标明了，下面统计时不算「凭界面找到」。

### 排除掉的测试工具问题（不是软件缺陷）

- **「从电脑添加…」点在文字上没反应（A7）**：主控在同一位置复现了「没反应」（R2 first #0006，驱动记的是「没有弹出打开文件对话框」，页面截图里也没有）。紧接着用窗口枚举查了整个桌面：有一个可见的系统「打开」对话框，属于 msedgewebview2 进程，不属于 MineDeck——页面截图拍不到它，驱动按 MineDeck 进程找窗口也找不到。主控把它取消掉，把驱动改成先等文件对话框拦截生效再点，同一坐标再点文字就正常选上了文件（#0007）。所以第二轮这一次确定是工具问题。第一轮那五次是不是同一原因，没有直接证据，但现象一致（第一轮还混用了不拦截对话框的普通点击），判断为「很可能是工具问题」；在作者用鼠标亲手点一次按钮文字之前，不把它当缺陷，也不当成已排除。A7 的「部分完成」和步数受它影响，不拿来做前后对比。整合包的「选择文件」第一次失败（A8 #0153）同理。
- **回访用户新建服务器时 25565 被占（B7）**：时间上正好是首次使用者的服务器在 25565 运行（两份副本并行）。不过「向导不查端口、失败后不留痕」这两点不因占用者是谁而改变，仍列为问题。

### 检查过的页面、任务和状态

页面：首次欢迎框、服务器列表（空状态和有数据）、新建服务器的四种方式页、从零创建向导五步、导入整合包、接管已有服务器、用已有地图开服、任务进度页（创建、导入、接管、装模组、导出交接包）、服务器详情在 Paper、原版、Fabric 上出现的 11 个标签（原版少「资源」「待装清单」；音乐共享、伙伴因核心不符没出现）、详情页头的打开文件夹菜单、卡片「···」菜单、删除确认、交接导出弹窗、内网穿透（添加隧道表单、平台账户、隧道行、日志）、AI 助手面板、设置的全部 9 个分区（远程访问、开机自启只看不点）。

状态：首次使用和已有数据；服务器停止、启动中、运行中；启动失败（Java 路径失效、端口被占）；整合包有待决文件（处理与不处理两种）；导入中途取消；有未保存修改时切换标签；关闭窗口缩到托盘再叫回；关掉程序重开；深色外观。

### 没有覆盖到的

- 桌面行为：托盘图标本身和托盘菜单（只用脚本模拟了「点托盘图标叫回窗口」）、右键菜单、从资源管理器真拖文件进窗口、防火墙询问、系统通知、窗口拖动和缩放到最小尺寸。
- 要特定条件才出现的界面：代理端（Velocity、Waterfall）、只在 NeoForge/Forge/Mohist 上出现的「音乐共享」、只在 NeoForge 1.21.1/Forge 1.20.1 上出现的「伙伴」、填了 Key 以后的 AI 助手和游戏内 AI、连上 OpenFrp/樱花账户以后的平台功能。
- 别的流程：手机或局域网浏览器打开的界面、导入交接包、给已有服务器换地图和恢复点、CurseForge 整合包、应用内更新、崩溃自动重启、Webhook、MCP、键盘快捷键。
- 「朋友能连」「白名单挡人」都只到界面和配置文件的证据，没有用游戏客户端真的连。

第一轮全程页面脚本没有出现未捕获的异常；页面控制台里记下的 8 条 HTTP 400 都对应界面上已经报出来的接口错误（端口被占、Java 找不到、导出文件夹不可用、运行中还原等）。

## 三、用户任务清单

按「用户想完成什么」列，只保留软件真有的能力。括号里是任务编号。

1. **第一次把服务器开起来，让朋友进来玩（A1）**：这是下载这个软件的理由，开不起来或开起来朋友进不去，用户就走了。
2. **告诉朋友怎么连（A2：局域网；A3：外地朋友，做到要填密钥为止；B4：找回上次设的隧道地址）**：开服的目的就是给人连。
3. **在服务器里做日常管理（A4 发公告、给 OP；B1 看在线、加白名单）**：最高频的操作。
4. **改服务器设置（A5 人数、难度、介绍；A6 内存）**：开服后第一批要调的。
5. **装插件或模组（A7）**：大多数服迟早要装。
6. **导入整合包、接管旧服务器、用已有存档开服（A8、A9、B7）**：「从零创建」以外的三种来路。
7. **出问题时自己解决（A10 两台撞端口；B5 Java 找不到）**：恢复能力决定用户会不会放弃。
8. **备份、还原、自动化（B2 还原备份；B3 每天重启和备份；A12b 手动备份并找到备份位置）**：防丢档。
9. **搬家和清理（B8 导出交接包；B11、A12c 移出列表但保留文件；B10 改存放位置）**：低频但出错代价大。
10. **改软件本身的设置（A11 深色、关窗缩到托盘）**。
11. **隔一段时间回来接着做（A12a 找回上次没装上的整合包文件；B6 看某台服务器的版本、Java、内存、文件夹）**。
12. **找到可选功能（B9 AI 助手要先填什么、能做什么）**。

## 四、任务走查记录（摘要）

完整记录（每一步的截图编号、当时屏幕上的原文、犹豫和折返）在 `D:\MineDeck-ux\round1\first\走查记录.md` 和 `round1\return\走查记录.md`。这里每个任务压成几行：预计入口、实际路径、卡点、结果。步数照抄各走查员自己的计法：回访用户只算点击、输入、按键、选择、滚动；首次使用者把悬停和 showwindow 也算一步。两边口径略有差别，比较时看量级。

### 首次使用者（全新副本）

- **A1 开第一台服务器**｜预计：有欢迎引导，再找「新建服务器」。实际：欢迎框勾协议 → 空状态「从零创建」→ 五步向导全用默认（Paper 26.3、构建 249）→ 打开 EULA →「开始部署」→ 约 30 秒完成 →「完成，进入控制台」→「启动」，40 秒后 Done。16 步。卡点：「选构建」对新手没意义；「选插件」那步没有「跳过」按钮；EULA 开关被吸底栏挡住一半（A #0014）；开起来以后页面上没有连接地址；白名单默认开（任务 5 才发现）。结果：服务器开起来了，「朋友现在就能连」当时其实不成立。

## 五、问题清单

优先级的定法：**P0** 挡住高频的核心任务，或者可能让人丢数据、本身是缺陷；**P1** 高频任务明显绕路、要撞墙才知道前提，或者失败后很难恢复；**P2** 低频、措辞、一致性问题。每条后面写依据。

### P0

**U01 找不到连接地址**｜类型：缺失信息、入口分类｜证据：【盲测】A1 #0025、A2 #0027–#0053（8 处没找到）、A10；【源码】局域网 IP 只在 app.js:4232–4257（远程访问）出现，详情页头（2522–2531）和卡片（1189–1203）都没有｜影响：核心目标「和朋友一起玩」做不完，要离开软件去查 IP；改端口后也不知道新地址｜依据：每个用户开服后必做，完全没有入口。

**U02 26.3 起新服务器默认开白名单且为空，没有提醒，说明还写反了**｜类型：隐藏条件、措辞矛盾｜证据：【盲测】A5 #0084；【配置文件】「创造小镇」`white-list=true`；【源码】黄字只在常用设置那一项下（app.js:3010），「玩家」标签说明「要在常用设置里打开才生效」（2786），新建流程写配置时不写 white-list（internal/inst/install.go:379–398 只写端口、正版验证、飞行、介绍、难度、模式等）｜影响：按默认值开服的新手，朋友连进来会被白名单挡住（按服务端规则推断，未用客户端验证），而界面显示一切正常｜依据：向导默认就选最新版本，命中面最大。补充：用「用已有地图开服」建的 26.3 服务器是 `white-list=false`，原因没查（位置未确认）。

**U03 启动失败只在几秒的提示里说，端口被占这类不留痕**｜类型：状态反馈、恢复｜证据：【盲测】B7 #0133–#0135（提示消失后控制台全黑）、A8 #0175（第一次点详情时提示已消失）与 #0178（第二次点上，详情只重复原话）、B5 #0083–#0088（找不到 Java 时控制台留了一行，卡片照常）；【源码】app.js:159（错误提示 8 秒自动关）、internal/inst/proc.go:95–97（端口被占不写控制台）、卡片 1189–1203 无失败状态｜影响：用户回来只看到一个没反应的「启动」按钮；提示还正好盖在详情页的启动、停止按钮上（A #0172）｜依据：启动是最高频操作，失败后无从下手。

**U04 弹窗里报错后想看「详情」，弹窗和输入会丢（含一处缺陷）**｜类型：功能缺陷、状态丢失｜证据：【盲测】B8 #0156–#0158（提示已消失，点到遮罩，交接弹窗「点遮罩即关」app.js:1627）；【主控实测】R2 return #0057–#0066（提示还在时点详情，报错信息窗口替换掉交接弹窗）；【源码】showErrDetail 与 confirmModal 对共用的 `#modal-root` 整体写 innerHTML（app.js:163–170、288–297）｜影响：填好的表单丢失；凡是追加在 `#modal-root` 里的弹窗（交接导出等）都会这样，删除确认这类本身用 confirmModal 的没有单独测｜依据：缺陷，修起来小。

**U05 删除服务器默认连文件夹一起删，取消键叫「保留」**｜类型：危险默认值、按钮命名｜证据：【盲测】B11 #0197（自建的服默认开）、A12c #0295（接管来的默认关）；【源码】app.js:1088–1090｜影响：按代码，不读小字直接点红键，世界存档会不可恢复地删掉（走查员读了小字、没有这样点）｜依据：不可逆，代价最高。

### P1

**U06 服务器详情的结构：11 个平铺标签（这次打开的服务器上的数量，NeoForge、Forge 等还会多出音乐共享、伙伴），名字不说明用途，常用操作不在里面**｜类型：分类、命名、入口位置｜证据：【盲测】A1、B1 都说「待装清单、游戏内 AI、全部配置和常用设置的区别光看名字说不清」；B6、B8、B11 的入口不在详情页；【源码】标签表 app.js:2532–2547，页头 2528–2530，导出和删除只在 1237–1244｜影响：同一台服务器的事要在卡片、卡片「···」、11 个标签、「打开文件夹」四处找｜依据：所有对单台服务器的操作都受影响。

**U07 端口冲突：表单不查重，报错不指名，不带路**｜类型：隐藏条件、错误提示｜证据：【盲测】A8、A10（占用者是自己的另一台服务器，提示说「别的程序」）；B7；【源码】internal/inst/portcheck.go:34–39 的话术不区分；新建、导入表单默认都是 25565｜影响：第二台服务器几乎必撞；改端口要知道在「常用设置 → 网络与远程管理」23 项里｜依据：有两台以上服务器的用户都会遇到。

### P2
