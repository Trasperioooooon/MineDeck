> 调研日期：2026-11-09 · 分支 research-frp-feasibility · 本文件是 docs-only 的纯调研产出，不伴随任何产品代码改动。
>

## 0 摘要

MineDeck 现在的 `internal/tunnel/` 只是第三方穿透服务的客户端管理器（providers：OpenFrp、樱花 natfrp、custom 自建 frps）。命题是：**团队自己架 frps 节点、作为产品的一部分给用户提供联机能力（可能免费+捐赠，也可能收费）**，重点评估"会不会被判定为与网易不正当竞争"。

四路并行研究后的分级结论：

- **短期（纯文档化自建 frps 教程）：可行，无新增风险。** 行业惯例，竞品同款（MSL"自定义 Frp"引导模式即此思路）。来源：MSL 官方文档（https://www.mslmc.cn/docs/proxy/frp/，官方，查证 2026-11-09）。
- **中期（社区免费/半公益节点，大陆节点、境内闭环）：有条件可行，但处在"未被监管定性"的灰色地带。** 条件：实名、限速+配额、只开游戏 TCP/语音 UDP 不开 HTTP 建站、日志留存、封禁处置流程、随时可关停的预案；启动前须有一次执业律师咨询。法务上这条路没有人走过——现有 frp 平台要么办了证（神卓互联、网云穿），要么以"免费公益+实名约束"的形态存续（OpenFrp），后者只是"未被追究的成本"，不是"合法的证明"。
- **远期（商业化收费）：技术在先例范围内，但合规是重资产，现阶段不建议直接做。** 前置条件：经营主体（公司）+ 增值电信业务经营许可（B2）+ 国内互联网虚拟专用网业务许可（B1）+ 等保 + 实名 KYC + 内容治理 + 法务专项意见。
- **无论哪种形态都有一组红线**（见 §7），最危险的三条：不为大陆用户提供跨境绕行能力、不分发/加速游戏客户端、不做游戏内经济或内容型服务器。

网易-Mojang 一线的关键发现可以提前说：**截至 2026-11-09，无论中国还是国外，都没有检索到任何针对"联机工具/穿透工具/开服器"（不碰游戏本体）的判例或执法案例**；网易生态十年维权的落点全部是盗版分发、玩法抄袭、内容合规三件事。风险主要来自我们自己怎么营销、怎么收费、碰不碰游戏文件，而不是"网易会不会来打"。

## 1 研究范围与方法

### 1.1 命题与现状

- **命题**：MineDeck 团队自建 frps 节点，作为产品的一部分向用户提供联机能力。两种设想的收费形态：免费+捐赠；订阅收费。
- **现状（读码核实，来源：本仓库 `internal/tunnel/providers.go`、`tunnel.go`）**：
  - `Provider` 接口三项能力：`ID()` / `EnsureFrpc()`（确保 frpc 就绪）/ `Launch(t)`（构造启动参数与环境变量）；`providerOf` 是硬编码 switch，只有 openfrp / natfrp / custom 三个实现。
  - openfrp：从 `api.openfrp.net` 取版本与下载源，下载 OpenFrp 定制版 frpc；启动参数 `-u <用户密钥> -p <隧道ID>`。
  - natfrp（樱花）：无稳定直链，首次引导用户手动放置 frpc；启动参数 `-f <访问密钥>:<隧道ID>`。
  - custom（自建 frps）：自动下载 fatedier/frp 官方 0.61.1（走 `dl.GHMirrors` 镜像，SHA-256 校验），生成 TOML 配置（`loginFailExit=false`、`[[proxies]] type=tcp|udp`），token 经 `MINEDECK_FRP_TOKEN` 环境变量注入、不落盘（frp 用 html/template 渲染配置，故 token 值逐字符转义为 TOML `\uXXXX`）。
  - 隧道凭据 DPAPI 加密存 `tunnels.json`（0600）；隧道可绑定实例、跟随实例启停（启动后 2 秒拉起、停止 5 秒后关闭）；`purpose=game|voice`（voice 用于 Simple Voice Chat 语音模组的 UDP 端口，公网地址自动写入 `voice_host`）。
  - 隧道的创建/删除仍在第三方服务商官网完成——**MineDeck 侧本来就不产生"运营服务"的义务**，这正是命题要改变的点。

### 1.2 方法

四条研究线由四个并发子代理独立执行，每个子代理只读联网查证（web 搜索 + 打开原文核对），产出带来源的报告，由本会话汇总复核查证口径后合成本稿：

1. 技术与成本（frps 能力边界、多租户、节点选址、对照 OpenFrp/樱花、成本模型、风控技术）；
2. 中国大陆运营合规（经营定性、证照、实名、跨境红线、平台责任、同行公示、游戏监管切面）；
3. 网易/Mojang 风险（独家授权范围与时点、判例盘点、Mojang/Microsoft 条款原文、商标、风险因子拆解）；
4. 竞品与商业模式（国内同行的联机服务现状、OpenFrp/樱花模式、三种形态先例、付费意愿）。

## 2 路线一：技术与成本

### 2.1 frp 能力边界（官方文档核证）

- **全流量经 frps 中转，唯一例外是 xtcp 打洞成功**。官方 XTCP 文档原文："如果成功，后续的流量将不会经过 frps，而是直接通信，不再受到 frps 所在服务器的带宽限制。由于打洞成功率取决于所处网络的 NAT 类型，所以 XTCP 的可用性和稳定性无法保证。在需要可靠连接的情况下，建议使用 STCP 替代。"（来源：https://gofrp.org/zh-cn/docs/features/xtcp/，官方，查证 2026-11-09）。即**自建节点 = 花"公网带宽 + 治理"换联机体验**。
- **部署模型**：frps 主监听 `bindPort`（默认 7000），每条 TCP/UDP 代理占用一个独立 `remotePort`；`allowPorts` 白名单端口池原生支持、默认不限制（官方原文 "Only allow frpc to bind ports you list. By default, there won't be any limit."）。来源：https://gofrp.org/en/docs/reference/proxy/、https://raw.githubusercontent.com/fatedier/frp/dev/conf/frps_full_example.toml（官方，查证 2026-11-09）。
- **代理类型全集**："Options are tcp, udp, http, https, tcpmux, stcp, sudp, xtcp."（来源：https://gofrp.org/en/docs/reference/proxy/，官方，查证 2026-11-09）。MineDeck 实际只用到 tcp/udp。
- **认证**：`auth.method` 可 token（默认）或 OIDC，本质是**一把全局 token**，无用户概念；`auth.additionalScopes` 可要求心跳/新建连接也验权。来源：https://gofrp.org/en/docs/reference/server-configures/（官方，查证 2026-11-09）。
- **每代理限速**：`transport.bandwidthLimit`（MB/KB 单位，0 不限）+ `bandwidthLimitMode`（client 默认/server 可选）——**参数由客户端配置携带**，要服务端强制必须走 Server Plugin 在 `NewProxy` 时校验。（来源：https://gofrp.org/en/docs/reference/proxy/，官方，查证 2026-11-09）
- **官方没有的服务**：用户体系、租户、月流量配额、计费、内容审计。唯一的原生额度控件是 `maxPortsPerClient`（单客户端代理数上限）。多租户化的官方挂钩点是 Server Plugin（操作类型 "Login, NewProxy, CloseProxy, Ping, NewWorkConn, and NewUserConn"，可返回 reject 拒绝）。`frpc` 的 `user` 字段只是代理名前缀（`{user}.{proxy}`），不是账户。来源：https://gofrp.org/en/docs/features/common/server-plugin/、https://raw.githubusercontent.com/fatedier/frp/dev/conf/frpc_full_example.toml（官方，查证 2026-11-09）。
- **风控现实**：frps 数据面是字节流转发，官方功能集里没有任何内容解析/DPI 能力记载（ServerConfig 全字段通读）；治理只能停留在"元数据 + 流量特征 + 实名威慑 + 处置流程"层级。（来源：https://gofrp.org/en/docs/reference/server-configures/，官方，查证 2026-11-09；"无内容审计"是基于官方字段语义的推断，子代理已标注）
- **项目状态**：frp v1 处于维护期（官方 README："We are currently working on version 2 … it will not be compatible with version 1 … will only accept bug fixes"），仓库活跃（2026-11-05 仍有提交）。锁定 0.6x 短期稳定，重度定制有 v2 迁移风险。（来源：https://github.com/fatedier/frp，官方，查证 2026-11-09）
- **xtcp/stcp 不是出路**：官方明示打洞成功率无保证；stcp 要求每个访问者（每位朋友）都装 frpc visitor，与"把地址发给朋友就能进服"的产品形态冲突。（来源：https://gofrp.org/zh-cn/docs/features/xtcp/，官方，查证 2026-11-09）
- **语音 UDP 相对次要**：Simple Voice Chat 官方文档"AUDIO packets are always transmitted via the UDP protocol … independently of other networking"（来源：https://modrepo.de/minecraft/voicechat/wiki/server_config，官方，查证 2026-11-09），人均语音流量为几十 kbps 量级，比游戏 TCP 人均 0.4-1.6 Mbps 低一个数量级（佐证：作者 issue 提到降到 10 kbps 后断流消失，https://github.com/henkelmax/simple-voice-chat/issues/43，社区，查证 2026-11-09）；运维重点是独立端口池与 UDP 泛洪防护，不是带宽账单。

### 2.3 节点选址与延迟

- 香港：对大陆一线城市典型 30-60ms、二三线 50-100ms、偏远 80-150ms（来源：https://www.hncloud.com/news/7698.html，行业·社区资料，查证 2026-11-09）。
- 日本：华东 40-80、华南 50-90、华北 60-100、西部 70-120ms（来源：https://www.simcentric.com/japan-dedicated-server/what-is-a-normal-ping-value-for-japan-servers/，行业·社区资料，查证 2026-11-09）。
- 美国：130-300ms，口径因线路（普通 vs CN2）差异大，对实时联机偏慢（来源：https://www.hncloud.com/news/7426.html、https://www.hncloud.com/news/4432.html，行业·社区资料，两说并列，查证 2026-11-09）。
- 行业对实时应用的通用门槛 <100ms（来源同上）。**给大陆玩家做产品，可用区间从优到劣为：大陆 > 香港 ≈ 日本 ≫ 美国**；大陆节点一旦用域名接入（哪怕只是面板/说明页）即触发 ICP 备案研究（来源：腾讯云官方"域名解析到腾讯云中国境内云资源，都必须先完成 ICP 备案"，https://cloud.tencent.com/document/product/243/19630，官方，查证 2026-11-09）。以上 RTT 为行业文章口径，精确值应以目标节点实测为准。

### 2.5 带宽量级与成本模型

- MC 单玩家带宽：原版/轻 Paper 每活跃玩家上行 50-100 KB/s（0.4-0.8 Mbps）；模组服 100-200 KB/s（0.8-1.6 Mbps）。来源：https://space-node.net/blog/minecraft-server-bandwidth-requirements-2026（托管商，行业·社区资料，查证 2026-11-09）。社区提示"10M 带 10 人"与"10M 带 80-100 人"两说并存，取决于视距/插件/模组（来源：https://github.com/ktj82474/mc-server-bandwidth-requirements，社区资料，查证 2026-11-09）——**设额定带宽必须绑定"视距+在线数+模组"假设**。
- 腾讯云《公网网络费用》（来源：https://cloud.tencent.com/document/product/213/113026，官方，页面更新 2026-08-28，查证 2026-11-09）：包月常规 BGP（广州/上海/北京/香港等）≤2Mbps 段 20 元、2-5Mbps 段 25 元、**>5Mbps 段 90 元/Mbps/月**；按流量大陆 0.80 元/GB；计费流量比应用层自行统计多约 10%（TCP 重传 3-10%）；**香港"精品 BGP"380 元/Mbps/月**——大陆优化的低延迟香港带宽比大陆普通 BGP 贵一个数量级。阿里云官方页被反爬，第三方整理口径（1Mbps 23 元/月、≥6Mbps 80 元/Mbps/月、按量 0.8 元/GB）与之量级互证（来源：https://www.aliyunbaike.com/ecs/8329/，行业·社区资料，2024-04 发布，未经官方复核）。
- **30 个并发活跃小服的月成本公式**：需购置带宽 W = 30 × 每服峰值上限 X × 同时峰值系数 s（工程假设 0.2-0.5，需按真实流量校准）；月费 C(W) = 20·min(W,2) + 25·clamp(W−2,0,3) + 90·max(W−5,0) 元 + 服务器实例费；按量口径 C2 = 0.80 元/GB × 月流量。取 X=2-4 Mbps、每日活跃 2-4 小时：**纯公网带宽开销约 500-3000 元/月**（不含实例费、人工、语音 UDP）。>5Mbps 档 90 元/Mbps/月的跳价是成本主项——**"每服限速 + 多服复用"是设计一等公民**，两家先行者免费档都压在 10-12 Mbps/用户不是偶然。

### 2.6 "minedeck" Provider 的技术轮廓（只描述，不实现）

- **客户端侧几乎为零**：custom Provider 已具备"官方 frp 下载+SHA256 校验、TOML 生成、token 环境变量注入不落盘"全部基础设施；新增一个 `case "minedeck"` 只是预设 endpoint 与产品化 token 的组合，无新协议工作。UI 上添加隧道不再要求用户填凭据，改为"登录 MineDeck 账号 → 领取隧道"。
- **服务端才是工程主体**，按依赖排：
  1. frps 节点与 `allowPorts` 端口池（tcp 25565 段 + 语音 UDP 段，不开放 HTTP/HTTPS）；
  2. Server Plugin（Login/NewProxy/Ping 钩子）把全局 token 换成"逐用户令牌 + 配额校验"，月流量配额需自建计数（原生无）；
  3. 账号/实名/配额/计费面板（可参照 VaalaCat/frp-panel 作底盘，原型期数周量级）；
  4. 滥用治理流水线：内容政策、封禁分级、投诉处置、日志留存（≥6 个月，见路线二）。
  以开源面板作底盘是数周到数月的原型工程；**长期成本的大头在运营与合规，不在代码**。

### 2.7 路线一小结

技术不是瓶颈：单台 frps + 插件即可支撑几百条游戏隧道的原型；500-3000 元/月的带宽量级决定免费+捐赠形态必须照先行者的"限速+签到控流量"玩。瓶颈在"对陌生人开放"之后的治理与合规（路线二、三）。

## 3 路线二：中国大陆运营合规

### 3.1 经营定性：内网穿透服务最接近 IP-VPN

- 《电信业务分类目录（2015年版）》（工信部通告，2016-03-01 施行；2019 修订仅增 5G 条目，"其他业务维持不变"）没有"内网穿透/端口映射"专门条目。四个候选类目定义原文（来源：https://zh.wikisource.org/wiki/电信业务分类目录（2015年版），法规转录文本，查证 2026-11-09；官方存档 PDF https://shca.miit.gov.cn/cms_files/filemanager/oldfile/shca/uploads/1/file/public/201803/20180313094125_6847g0.pdf，查证 2026-11-09）：
  - B11 IDC："利用相应的机房设施，以外包出租的方式为用户的服务器等设备提供放置、代理维护……通信线路和出口带宽的代理租用"；
  - B12 CDN："内容的分散存储和高速缓存……将内容分发到快速、稳定的缓存服务器上"；
  - **B13 国内互联网虚拟专用网（IP-VPN）："利用自有或租用的互联网网络资源，采用TCP/IP，为国内用户定制互联网闭合用户群网络的服务。互联网虚拟专用网主要采用 IP 隧道等基于 TCP/IP 的技术组建"**；
  - B14 互联网接入服务："建立业务节点……为各类用户提供接入互联网的服务"。
- **比对判断**：MineDeck 官方节点无机房托管（不匹配 B11）、无内容缓存分发（不匹配 B12）、不提供"接入互联网"（方向相反，不匹配 B14）；端口映射隧道的技术特征**最接近 B13 IP-VPN 的"IP 隧道""闭合用户群"刻画**，但 frp 是 NAT/端口映射而非"定制闭合网络"，并非完全重合。**定性存疑，需监管口径确认，本报告不下定论。**
- 两个旁证：（a）司法实践中已有法院把无证 VPN 服务径行归入增值电信业务并按非法经营罪评价（见 3.4）；（b）同业内网穿透厂商的办证实践直接落在 IP-VPN 上（见 3.6）。

### 3.2 备案与许可

《互联网信息服务管理办法》（2000 年国务院令第 292 号，2024-12-06 第二次修订；来源：https://zh.wikisource.org/wiki/互联网信息服务管理办法，法规转录，查证 2026-11-09）：

- 第3条：经营性="通过互联网向上网用户**有偿**提供信息或者网页制作等服务活动"；非经营性="无偿提供具有公开性、共享性信息的服务活动"。
- 第4条：经营性实行**许可**制度，非经营性实行**备案**制度；第7条：经营性应申请**互联网信息服务增值电信业务经营许可证**；第8条：非经营性应办理备案。
- "纯 IP+端口也要备案"的口径（工信部备案系统 FAQ，第三方转引）："无论您的网站是通过域名方式访问或是通过IP地址的方式访问，只要在中华人民共和国境内提供非经营性互联网信息服务都要办理备案手续。"（来源：https://www.aliyunbaike.com/beian/3775/、https://boke112.com/article/p9494.html，行业·社区资料，仅见转引文本，未及工信部系统 FAQ 原文页，查证 2026-11-09）
- **对 MineDeck 的分解**：frps 端口转发是通道承载、不向"上网用户提供信息"，落入"信息服务"定义的可能性低——它的合规抓手是**电信业务许可**；但 MineDeck 的官网/文档/软件分发构成信息服务：免费 → 非经营性备案；**对穿透服务收费、或以捐赠/会员换取专享权益 → 有被认定"有偿"的现实概率 → 需要经营许可（第7条）**。

### 3.3 实名制

- 《网络安全法》2016 年通过，**2025-10-28 修正、2026-01-01 施行**（来源：新华网 http://www.news.cn/20251028/48d486c46100486ba98cb5156eafdf97/c.html、央视网 https://news.cctv.com/2025/10/28/ARTI6000IxIlgIji0jPlypWT251028.shtml，权威媒体官方通稿，查证 2026-11-09；修正后全文 https://www.cac.gov.cn/2025-12/29/c_1768735112911946.htm，官方，查证 2026-11-09）。**条文重编号：实名 24→26 条、信息管理 47→49 条、等保 21→23 条**，本报告引用一律用新编号。2025 修正同时提高了处罚力度（提高罚款额度、增设停业整顿及吊销执照等处罚；来源：https://www.secrss.com/articles/84453，行业·社区资料，查证 2026-11-09）。
- 修正后第26条原文："网络运营者为用户办理**网络接入**、域名注册服务，办理固定电话、移动电话等入网手续，或者为用户提供信息发布、即时通讯等服务，在与用户签订协议或者确认提供服务时，应当要求用户提供真实身份信息。用户不提供真实身份信息的，网络运营者不得为其提供相关服务。"（来源：网信办官网修正后全文，官方，查证 2026-11-09）
- 工信部信管函〔2017〕32号："未经电信主管部门批准，不得自行建立或租用专线（含虚拟专用网络VPN）等其他信道开展跨境经营活动。"（来源：https://www.miit.gov.cn/zwgk/zcwj/wjfb/tz/art/2017/art_a940645e940946e1a62cd6c90a4e994e.html，官方，已读原文，查证 2026-11-09）
- 行业实践印证"大陆节点实名"是事实标配：OpenFrp"使用大陆节点需要实名认证，海外节点无需实名"（来源：https://www.bilibili.com/video/BV1LQ4y1y7bv/ 视频简介、https://nav.eyosc.com/sites/7227.html，行业·社区资料，查证 2026-11-09）；樱花大陆身份证 KYC（见 2.4）。结论：**MineDeck 若用大陆节点，实名几乎绕不开**；实名又把账号体系拖进《个人信息保护法》《数据安全法》《网络数据安全管理条例》（2025-01-01 施行，且已作执法处罚依据，来源：新华网 https://www.news.cn/20260915/2aee3aaab33a46cb84dfb99a2637695c/c.html，权威媒体引网信办通报，查证 2026-11-09）。

### 3.4 跨境是最大红线

- 《计算机信息网络国际联网管理暂行规定》（1996 年国务院令第 195 号，多次修订；来源：https://zh.wikisource.org/wiki/中华人民共和国计算机信息网络国际联网管理暂行规定，法规转录，查证 2026-11-09）：
  - **第6条**："计算机信息网络直接进行国际联网，必须使用国家公用电信网提供的国际出入口信道。任何单位和个人不得自行建立或者使用其他信道进行国际联网。"
  - 第8条：从事国际联网经营须取得国际联网经营许可证；**第14条罚则**：公安责令停止联网、警告、1.5 万元以下罚款、没收违法所得。
- **"卖 VPN"判例定罪谱系（邻近品类，frp 联机不是同类，但证明锋面真实）**——案号经律师团队对 86 份 VPN 判决的梳理转引（未见判决书原件）：
  - 非法经营罪：泰顺 (2018)浙0329刑初46号（营业额 47 万余元）；合肥包河 (2018)皖0111刑初885号（"赤兔加速器"，涉案 109 万余元）。

  - 拒不履行信息网络安全管理义务罪：荆州 (2018)鄂1003刑初150号（罪名三易后以此定罪）、上海浦东 (2018)沪0115刑初2974号。
  - 对置观点认为出售翻墙软件仅行政违法、不构成犯罪——**两说并存，类案定性不统一**。
  - 来源：https://www.163.com/dy/article/G8LE2KCV05453POT.html（判决梳理转载）；对置观点 https://zhuanlan.zhihu.com/p/636065916（行业·社区资料）。均查证 2026-11-09。
- **限定与结论**：以上判例全部是"帮助用户访问被墙境外网站"的翻墙服务场景。**针对 frp/端口映射型联机穿透服务，未查到任何刑事定罪、行政处罚或监管定性文件——灰色地带，但风险敞口真实**：
  1. 通用任意端口映射技术上可被用于翻墙（经节点出向访问境外），产品不设区分将难以自证"非翻墙工具"；樱花内容策略因此明文禁止跨境正向代理（见 2.4）；
  2. "大陆玩家经海外节点进出"的路由形态可被指控为"自行建立或者使用其他信道进行国际联网"（第6条）；
  3. 判例已出现拒不履行信息网络安全管理义务罪——即使回避业务定性，未落实安全管理义务本身也可入罪。

## 4 路线三：网易/Mojang 风险（重点）

### 4.1 独家授权：范围窄、期限黑箱、仍在运营

- **2016 年授权公告原文**（网易投资者关系新闻稿，2016-05-20，已读全文）："Microsoft, Mojang and NetEase, Inc. today announced a **five-year exclusive agreement** to license Mojang's Minecraft **mobile and PC editions** to a NetEase, Inc. affiliate **in mainland China**. … Mojang will develop a version of Minecraft tailored for the Chinese market…"（来源：https://ir.netease.com/news-releases/news-release-details/minecraft-will-officially-enter-china-mobile-and-pc-netease，官方，查证 2026-11-09）。**授权标的是游戏本体（PC + 移动版）在中国大陆的发行运营；公告通篇没有提及联机工具、开服器、内网穿透、第三方服务器托管。**
- **续约期限三种口径并存、官方沉默**：网易 2022 年度年报口径"授权至 2023 年 8 月"（MCBBS 社区转述，未读年报原文）；中文 Minecraft Wiki 称 2023 年延至 2028（页面拒绝自动访问）；社区传闻 2026-06（自称未经官方背书）。**未查到任何一方对续约的官方公告——合同期限事实上不可考，长周期规划必须把"中国版合同状态不可知"当作已知条件。**（来源：https://www.zhihu.com/question/598539849、https://zh.minecraft.wiki/w/中国版、https://www.minebbs.com/threads/20046/，均为社区资料，仅见搜索摘要，查证 2026-11-09）
- **现势（截至 2026-11）**：网易仍在运营并更新中国版——2026-10-30 官网发布《群骑纷争》版本更新与开发者大会消息（来源：https://mc.163.com/，官方，查证 2026-11-09）；中国版注册账户约 8 亿（来源：https://minecraft.wiki/w/China_Edition，行业·社区资料·英文 Wiki，已读正文，查证 2026-11-09）。
- **2026-01 的"停服风波"真相**：2026-01-22 官方《部分网络游戏服务器停服通知》——中国版联机大厅内 **31 个第三方开发运营的商业化"网络游戏服务器"**（RPG 类付费服）因品控于 2026-02-06 正式下架，向付费玩家发"继承礼包"（来源：官方原文 https://mc.163.com/news/20260122/29175_1283233.html（抓取临时失败）；IT之家逐字转载 https://www.ithome.com/0/915/588.htm，权威媒体，已读全文，查证 2026-11-09）。**含义：不是游戏停运，是网易对"平台上长出来的商业化服务器生态"的批量收缩——不要做"类官方平台"形态的产品。**

### 4.2 判例盘点：执法锋面在哪，不在哪

- **重要修正：任务书里"网易诉多玩我的世界盒子案"的诉讼形态并不存在。** 查证结果：2017 年网易（自称"大陆地区唯一运营商"）向广州华多、广州虎牙、珠海多玩三家多玩系公司发停止侵权函（来源：http://www.gamelook.com.cn/2017/07/298300/，行业媒体，查证 2026-11-09，仅见搜索摘要）；随后在国家版权局"剑网 2017"专项行动中，**广州华多网络科技有限公司因未经许可通过"多玩我的世界盒子"向公众传播《我的世界》等网络游戏被行政处罚，涉案金额 18 万余元，罚款 27 万元**；2017-07 多玩盒下架盗版游戏资源并关闭充值（来源：https://news.17173.com/content/01252018/181008984.shtml，权威媒体转引国家版权局通报，已读全文，查证 2026-11-09）。**处罚针对的是盗版游戏本体分发+充值变现；处罚后该产品的联机、MOD、地图下载功能继续存活。未查到名为"网易诉多玩我的世界盒子"的民事判决、案号或判赔额。**
- **迷你世界案（网易维权代表性判例）**：(2021)粤民终1035号，广东省高级人民法院二审判决（2022-11-30）：认定《迷你世界》**不构成著作权侵权（游戏整体画面）但构成不正当竞争**，判令删除 230 个侵权元素、赔偿 5000 万元（一审 2113 万；查明累计下载 33.6 亿次、注册用户超 4 亿；知产力解读——"游戏玩法规则等非视听画面内容不属于游戏画面著作权的保护范围……最终选择了不正当竞争保护路径"）。判决书 PDF 存档存在但未能读取全文，数字系权威媒体+律所+判决摘录多源交叉，未逐字核对。（来源：https://finance.sina.cn/tech/2022-12-04/detail-imqmmthc6968579.d.html，权威媒体，仅见摘要；https://www.zhichanli.com/p/139770468，行业·专业社区，仅见摘要；判决书存档 https://upload.wikimedia.org/wikipedia/commons/e/e7/广东省高级人民法院（2021）粤民终1035号民事判决书.pdf，查证 2026-11-09）
- **奶块案：网易输了的一件**。诉广州华多、虎牙的《奶块》案一审判赔 2000 万，**广州知识产权法院 2023 年二审撤销一审判决，认定"既不构成著作权侵权，也不构成不正当竞争"**；报道引律师观点：其审判逻辑延续迷你世界案的克制路径（来源：https://m.mp.oeeee.com/a/BAAFRD000020230804827402.html，权威媒体·南方都市报系，查证 2026-11-09，仅见搜索摘要）。——网易的权利射程在司法上有清晰边界。
- **对 MineDeck 至关重要的事实真空**：**未查到任何判例、行政处罚或执法案例，其处罚对象是"不碰游戏本体、只提供联机/穿透/开服便利"的工具类产品（中外皆无）。** 已查到的执法/诉讼锚点全部是四类：盗版分发游戏本体+变现（多玩盒 27 万罚款）；整体玩法抄袭（迷你世界 5000 万）；相似但不够格产品判不侵权（奶块案）；平台内容合规（2019 年联机大厅被 CCTV 报道低俗内容后网易改房间命名，来源：https://zh.wikipedia.org/zh-hans/我的世界，社区资料，仅见摘要，查证 2026-11-09）。**"联机工具未被打击过"是事实真空，不是法律豁免——只能按"低先验风险"处理，不能按"安全"处理。**

### 4.3 Mojang/Microsoft 条款（读官方原文）

- **EULA**（来源：https://www.minecraft.net/en-us/eula，官方，已读全文，查证 2026-11-09）关键原句：
  - **"You may develop tools, plug-ins and services as long as they do not seem official or approved by us, such as by using our logos."**（可以开发工具、插件和服务，只要不冒充官方。）
  - "For the server version of Minecraft: Java Edition, you can install it on a server and host online play."
  - "Do not distribute or make commercial use of anything we've made without our permission."
  - **可撤回性**："These Minecraft Usage Guidelines often change, and we have the right to withdraw the permissions given in them at any time without notice."——**今天合规的形态，明天可能被条款改字消灭（尾部风险）。**
- **Usage Guidelines**（来源：https://www.minecraft.net/en-us/usage-guidelines，官方，已读全文，查证 2026-11-09）关键原句：
  - 商用宽定义："commercial use means any uses of our name, brand, or assets that you use and share with others (**regardless of whether you receive payment or provide it for free**). … even a server you host."——**宣传物料层面的合规义务与收费与否无关**。
  - **服务器与托管章节（MineDeck 这类服务的白名单）**："You may host a server for Minecraft. You may even charge for access to the server as long as you follow the guidelines in this section. By 'server,' we mean a single connecting address or IP number. Access to your server: Must only be granted to users who have a genuine paid-for version of Minecraft; Can't be limited to or controlled, directly or indirectly, by a player owning or having access to out-of-game content, products, or services."——Minehut、Aternos、BisectHosting 等商业托管赖以存在的条款空间即在此。
  - 收入白名单：统一收费（人人同价）、**donations（"Asking for donations, so long as you don't offer the donor something that only they can use"——不给捐赠者专属权益，可作全员目标奖励）**、游戏内展示/广告、无现实价值虚拟币等。
  - 命名规则：Minecraft 名只能作**次要描述要素**——官方示例 "'Kotoba Miners: A Minecraft server for Redstone builds' (we're cool with this)" 对比 "'Minecraft - the ultimate Kotoba server' (we're not cool with this)"；**强制显著免责声明 "NOT AN OFFICIAL MINECRAFT [PRODUCT/SERVICE]. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT"**。
  - 美术素材："Do not use any other aspect of any of our brand or assets as part of any related branding, including as a logo or part of a logo"。
  - NFT 禁令（2022-07 修订，来源：官方博客 https://www.minecraft.net/en-us/article/minecraft-and-nfts 及 The Verge 转引 https://www.theverge.com/2022/7/20/23272152/minecraft-mojang-blocks-rejects-nfts，官方/权威媒体，查证 2026-11-09）：区块链技术与 NFT 整合不受支持、不允许。
- **Mojang/Microsoft 起诉第三方托管/联机服务的公开案例：未查到**。Mojang 对违规服务器的执法手段是游戏内黑名单（社区口径，未经官方确认，来源：https://piratemc.com/topic/mojang-eula-enforcement/，社区，仅见摘要）；**但 Microsoft 的商标批量执法真实存在**：2024-04 美国伊利诺伊州北区法院 24-cv-3255、24-cv-3262 两案批量 TRO 打击在售商品上使用 Minecraft/《我的世界》标识的卖家，"已有 431 家店铺被告"（来源：https://www.amz123.com/t/IwVsoqZP，跨境电商维权资讯，查证 2026-11-09，仅见搜索摘要）。
- EULA 中文版与英文同文，**未查到针对中国大陆的特别条款**（仅维基百科称大陆 IP 访问 minecraft.net 会弹窗指引中国版，未核实）。

### 4.4 商标与宣传口径

- 中文商标"我的世界"存在**申请人/权利人为微软公司**的商标数据库记录（来源：https://www.tmkoo.com/detail/f6e488e2043a81bc967541e3bb13223，商标数据库条目，查证 2026-11-09，仅见搜索摘要；**逐类权利状态未核实**）；"Minecraft"商标权利主张人为 Microsoft Corporation（2024 年批量 TRO 佐证）；网易在司法/媒体口径中被记为"有权针对任何知识产权侵权行为和不正当竞争行为进行维权"（来源：羊城晚报 via 新浪财经 https://finance.sina.cn/tech/2022-12-04/detail-imqmmthc6968579.d.html，权威媒体转引，查证 2026-11-09）——**源头权利在 Mojang/微软，网易凭独家运营+维权授权在大陆行使事实上的执法者角色。**
- 三种宣传口径的素材对比（不下法律结论）：
  - **"我的世界联机服务"：风险最大**。把微软注册、网易运营的中文商标用作主名称（对照 Usage Guidelines"只能作次要描述"）；与网易官方"联机大厅/租赁服"同构，最大化混淆场景；正落在微软 2024 批量商标 TRO 的打击面类型上。
  - **"MineDeck——Minecraft 开服工具（配穿透联机）"：条款明文许可的形态**。"自有品牌名 + 以 Minecraft 作适用对象描述"就是官方示例的合法句式；前提是遵守命名规则 + 显著非官方声明 + 不用其徽标与美术素材。
  - **完全不提游戏名：暴露面最小，获客描述能力受损**。功能描述性使用（"适用于 Minecraft Java 服务器的联机工具"）与第二种同路径，仍在"次要描述"框架内。
- 美术素材（方块、爬行者、徽标字体）用于宣传，落在 Mojang "brand and assets" 管束范围内；国内司法（迷你世界案删除 230 个游戏元素）对"元素级攫取"同样持否定态度——两条线同向。

### 4.5 营利形态暴露面

- **网易线**：网易全部公开执法都锚定"盗版分发/玩法抄袭/内容合规"，**盈利与否是放大器不是扳机**。免费不等于安全（多玩盒被罚的关键是盗版+充值；免费平台的内容合规问题照样出事）。收费则把 292 号令"有偿→经营性"的第一性问题（路线二）直接拉进场。
- **Mojang 线**：条款对"免费/捐赠/收费"给了明文分级——免费最干净；**捐赠明文允许，红线是"不得给捐赠者专属可用权益"**；订阅收费须做成"人人同价的统一收费接入"，做"免费+付费解锁更多带宽/端口/特权"则触碰"不得以游戏外条件闸控"的红线。
- 叠加结论：**免费 → 捐赠 → 商业化，暴露面单调递增；商业化的增量风险主要来自国内证照问题（路线二），而不是网易/Mojang 条款**。

### 4.6 对照生态：工具生态的运行现状与 2026-10 收缩

- HMCL（约 2016 年至今，开源）、PCL2、MCSL2、MSL 等工具公开运行多年；**未查到网易/微软对它们的执法、起诉或投诉记录**；2022 年"网易封杀第三方国际版启动器"传闻已辟谣。（来源：https://github.com/HMCL-dev/HMCL、https://www.zhihu.com/question/583803376/answer/2891662206，社区资料，查证 2026-11-09，部分仅见摘要）
- **2026-10-20 重大事件**：PCL 推送 2.99.0.0 公告"为遵守相关法律法规，PCL 暂不支持提供 MC 下载"（作者声明与网易/微软/原作团队无关）；几乎同时 HMCL 在中国大陆限制下载页面，PCL CE 禁用大陆安装通道；所依据的具体法规条文至今没有任何一方公布（来源：https://www.163.com/dy/article/L9PF7ILM0519RE6Q.html 等多源，权威媒体/社区，查证 2026-11-09，均仅见搜索摘要；社区"未成年玩家私服氪金被家长举报"归因未获官方证实）。**含义：监管压力落在了"游戏本体分发"环节，启动器们全部保留了启动、管理、联机辅助功能——分发是红线，联机/开服环节未被触及。** MineDeck 现状（不分发游戏文件）与启动器收缩后的合规形态同构。

### 5.3 三种形态的国内先例（每种都有活体）

**a. 纯文档支持自建（现状形态）**

- MSL 官方文档"自定义Frp：高级模式，粘贴配置文件进去就好……引导模式，比较适用于自建 Frp 服务"——与 MineDeck 的 custom provider 同思路。（来源：https://www.mslmc.cn/docs/proxy/frp/，官方，查证 2026-11-09）
- 个人教程实测自建成本：云服务器 ¥15.5/月（可按周购）+ 流量 ¥0.80/GB（5 个玩家生存 6 小时约耗 1GB）。（来源：https://www.zouht.com/2504.html，社区，已读正文，2021-06 数据未复核现价）

### 5.4 付费意愿与可持续性证据

- **付费意愿存在**：网易租赁服长期收费且因需求旺盛降价（官方公告，见上）；frp 穿透市场有明确价格带与推广竞争。
- **付费意愿有天花板且人群敏感**：目标客群与学生/未成年人高度重叠——贴吧记录学生为凑 1 元实名认证费用倒腾支付宝提现、无银行卡过不了实名的未成年人"倒腾了一天也没联机上"（来源：https://tieba.baidu.com/p/7464452082、https://tieba.baidu.com/p/7508959423，社区资料，仅见搜索摘要，查证 2026-11-09）。**定价与实名设计必须为这个人群留出路（签到流量、免费额度）。**
- **纯捐赠不可持续**：LoCyanFrp 数年间现金赞助合计 688.75 元，远不够节点成本，靠 IDC 主业+实物节点捐赠反哺；活下来的公益项目都在四条路里选一条或组合：IDC 主业反哺、会员费、企业级产品线、广告/大厅流量（Aternos 靠站内广告、Minehut 靠大厅流量+升级付费，各 1 来源仅见摘要，查证 2026-11-09）。**MSL 模板（爱发电养软件本体、联营 IDC 出节点）是与 MineDeck 最像的活法。**

## 6 结论分级与决策树

### 6.1 分级结论

| 形态 | 结论 | 判据 |
|---|---|---|
| 1. 纯文档支持自建 frps（现状延伸：官方教程 + custom provider 引导） | **可行** | 无新增法律/运营义务；行业惯例（MSL 引导模式、OpenFrp 教程页）；零成本。 |
| 2. 官方免费公益节点（大陆节点、境内闭环、实名、限速配额） | **有条件可行（灰色地带）** | "无 frp 专属判例/定性"≠安全，是"未被追究的成本"；条件见 6.2 与 §8.2 清单。启动前需执业律师咨询。 |
| 3. 免费+捐赠 | **有条件可行** | 在形态 2 条件之上再叠加：捐赠不给专属可用权益（Mojang 条款原文）；捐赠资金透明。注意国内"以捐赠之名行收费之实"可能被认定经营性（292 号令第3条），捐赠换会员/带宽=实质收费=按商业化评估。 |
| 4. 订阅收费（商业化） | **现在不做；条件齐备后远期可行** | 技术与市场都在先例范围内（樱花/云鸢/网易租赁服都是收费联机/托管），但国内合规是重资产：公司主体+B2+B1 证照+等保+实名 KYC+内容治理+法务专项意见；且要与 OpenFrp 的 OPENAPI 商业授权条款解耦。个人开发者形态无法合规收费。 |
| 5. 任何"出境/绕回"能力（大陆用户经海外节点出入） | **不建议（红线）** | 1996 国际联网规定第6条+多起 VPN 定罪判例（邻近品类）；樱花内容策略同款禁令。 |

### 6.2 决策树（免费 → 捐赠 → 商业化）

```

└─ 做 → 先定三件不变的事（对任何形态都成立）：
    ① 只开游戏 TCP + 语音 UDP 端口池，不开 HTTP/HTTPS 建站隧道
    ② 大陆节点强制实名 + 境内闭环（不为大陆用户提供出境/绕回能力）
    ③ 不碰游戏本体与游戏内经济（不分发、不代购、不自营服务器内容）
    │
    ├─ 免费（公益节点）
    │   ├─ 所有条件满足？（先过下面四个问题）
```

## 7 红线清单（无论哪种形态都不能做）

1. **不为大陆用户提供任何"经海外节点出境/绕回"的转发能力**，不做通用任意端口暴露（1996 规定第6条；樱花内容策略同款禁令；VPN 判例）。产品层面只开游戏 TCP 段与语音 UDP 段的固定端口池。
2. **不分发、加速、代购 Minecraft 客户端/游戏文件**（多玩盒 27 万元行政罚款的执法先例；2026-10-20 PCL/HMCL/PCL CE 已集体切断下载——分发环节是刚被检验的高压线）。MineDeck 保持现状：只管服务端，永不碰客户端分发。
3. **不运营游戏内容或游戏内经济**：不自营官方服务器、不接充值/抽成/道具/抽奖（网易 2026-01 批量下架 31 个商业化"网络游戏服务器"；Mojang 条款同样禁止游戏外条件闸控）。
4. **不把"我的世界 / Minecraft"用作主品牌名或宣传主元素，不使用 Mojang 徽标与美术素材**（方块字体、爬行者形象等）；采用"MineDeck——适用于 Minecraft Java 服务器的联机工具"式次要描述 + 显著"非官方、与 Mojang/Microsoft 无关联"声明（Usage Guidelines 原文要求；微软 2024 批量商标 TRO 证明商标执法不是纸老虎）。
5. **大陆节点不搞无实名开放接入**（网安法第26条宽口径；同行一致实践）；海外节点独立服务海外场景，不与大陆用户闭环混跑。
6. **不开放 HTTP/HTTPS 建站类隧道**（避开备案墙与"信息发布平台"责任；只做 game/voice 两用途，与现有 purpose 字段语义一致）。
7. **不给捐赠者任何专属可用权益**（Mojang 条款原文红线；同理不做"免费+付费解锁特权"的分叉收费）。
8. **不引入 NFT/区块链任何形态的接入或权益验证**（Mojang 2022-07 禁令）。
9. **商业化若保留 OpenFrp 集成，先取得 OpenFrp 项目组书面协议授权**（OPENAPI 文档原文要求），未见授权前商业版本剥离深度集成。
10. **不承诺"永久免费"或任何 SLA**（公益项目教训：社区默认不信任；不承诺即不欠；随时可关停的预案先写好后开业）。

## 8 建议产品路径

### 8.1 短期（现在即可做，零新增风险）：纯文档化自建 frps

- 写一篇面向新手的《自建 frps 联机教程》：云服务器购买 → frps 安装 → allowPorts 与 token 配置 → 在 MineDeck 里添加 custom 隧道（服务端地址/端口/远程端口/本地 25565，语音再加 UDP 隧道 + voice_host）。custom provider 已支持全部流程，纯文档工作。
- 参照素材：MSL"自定义 Frp"引导模式、zouht.com 教程的实际成本（¥15.5/月+流量）、MineDeck 现有表单的字段语义。
- 同步把 OpenFrp/樱花的署名义务与实名流程写清（既有集成不受影响：MineDeck 开源免费，暂不触发 OPENAPI 商用授权问题，但文档要注明"若本工具未来商业化，需另行取得 OpenFrp 书面授权"）。

### 8.2 中期（条件全部满足才启动）：社区免费节点试运行

前置条件清单（全部满足才动手）：

1. **治理**：实名认证（大陆身份证 KYC，参照樱花 Face++/支付宝 1 元流程）；`allowPorts` 白名单（TCP 段+UDP 语音段）；每隧道限速（10-12 Mbps 起步，与先行者档位一致）；月流量配额+超额拒绝（Server Plugin 自建计数）；日志留存≥6 个月（网安法第23条）；内容政策+封禁分级（参照 OpenFrp"封隧道→封户→报案"文本本体化）；投诉处置值班安排。
2. **形态**：境内闭环（大陆节点仅境内互访）；只开游戏/语音用途；实名与免费额度对未成年人友好（签到流量）。
3. **法务**：至少一次执业律师专项咨询（重点问：IP-VPN 定性、免费公益形态的定性风险、未成年人保护义务）；官网走非经营性备案；写好用户协议与隐私政策。
4. **运营**：带宽预算（按 2.5 公式，30 活跃服约 500-3000 元/月起）+ 实测 telemetry 校准；节点买法先大陆（便宜、延迟优、要备案与实名）后按需加香港（注意精品 BGP 380 元/Mbps 的成本跳变）；赞助或 IDC 联营（MSL×兮辰云的模板）；**不做"永久免费"承诺**。
5. **退出**：关停预案先写（公告模板、用户迁移指引、数据导出）——节点生命周期与社区信任直接挂钩。

部署形态建议：frps + Server Plugin（Login/NewProxy/Ping 换逐用户令牌+配额）+ 开源面板（VaalaCat/frp-panel 类）作底盘 + MineDeck 内新增 `minedeck` provider（复用 custom 的配置生成与 token 注入，只是端点与凭据由分配 API 下发）。

### 8.3 远期（商业化）前置条件

1. **经营主体**：公司注册（个人形态无法办证）。
2. **证照**：ICP 经营性许可 + 增值电信业务经营许可证（B2）+ 国内互联网虚拟专用网业务许可（B1）——参照神卓互联、网云穿的证照组合与工信部 tsm.miit.gov.cn 申报；等保二级测评。
3. **实名与内容治理**：实名 KYC 全量、内容政策、协查配合流程升级为企业级。
4. **法务**：专项法律意见书（覆盖电信业务定性、未成年人保护、不正当竞争风险面）；商标审慎评估（不碰"我的世界/Minecraft"主名，非官方声明入 UI）。
5. **网易/Mojang 面审计**：营销口径走"次要描述"框架；不使用任何 Mojang 素材；不引入游戏内经济；持续关注网易独家授权合同状态（黑箱）与 Usage Guidelines 随时撤回的尾部风险。
6. **商业设计**：价格带对标 8-60 元/月（樱花-ChmlFrp-云鸢区间）；免费档（10 Mbps 级）保留获客；成本模型按 2.5 公式重算；OpenFrp OPENAPI 集成要么取得书面授权要么剥离。
