# MineDeck 收包上手指南：拿到服主的 .mdpack 之后

你收到了一个 `.mdpack` 文件——那是服主把整台服务器打成的包：世界存档、每个人的进度（`playerdata` 里的都在）、模组和配置全套都在里面。装好之后你们就接着上次的进度继续玩，一样的人物、一样的家、一样的装备，不用重来。

照下面做，大约 10 分钟就能开起来。遇到问题按最后一节的格式告诉服主就行。

## 一、准备一次 MineDeck

没有 MineDeck 的话先装一份：

1. 到[发布页](https://github.com/Trasperioooooon/MineDeck/releases)下载 `MineDeck.exe`。新建一个空文件夹（比如 `D:\MineDeck`），把它放进去，双击运行。
   - 弹出「Windows 已保护你的电脑」就点「更多信息 → 仍要运行」（没有数字签名的正常提示）。
2. 第一次打开按引导走完。什么都不用改，默认就行。

服主本来就管着服务器的话，包里带的进度就是服主停机那一刻的。想确认谁都在，进服看一眼名单就知道了。

## 二、把包装进来

1. 左侧「新建服务器」，找到「**收包开服**」这张卡片点进去。
2. 选服主发给你的 `.mdpack`（微信、网盘传的都一样，别解压、别改名）。
3. 点「上传并清点」。包大的话这一步要等一会儿。清点完 MineDeck 会列出包里的东西，先核对一下：

   - **名称、核心与版本**：是不是你们玩的那台服。比如 `Forge 1.20.1`，和暑假玩的一致就对了。
   - **世界** 有多大、**模组** 有多少个、**打包方式与时间**：时间和服主打包的日期应该差不多；对不上号的旧包别急着收。
   - 上面会写清剔掉了什么（日志、缓存这类），开着不影响的，不用管。

4. 填几个落地设置：

   - **落地名称**：这台服在你电脑的列表里叫什么，默认跟包里一样，不改也行。
   - **端口**：同电脑上第一台服就用默认的。看一下清点屏提醒的包里端口——MineDeck 会先替你查这个端口目前有没有被谁占着。占了的话（包括你自己列表里的别的服）换一个数字再点一次「检查占用」，显示「空着」就好。
   - **内存**：照包里原来分的填好了。
   - **Java**：默认是包里原来用的那个（整合包有可能声明要更高的，比如 `1.20.1` 服要 Java 25 的魔改模组——一般不用动，不确定就保持默认，装好后还能在「内存 / 启动」里换，不着急）。
   - **Minecraft EULA**：第一次收包要勾一下同意；包里已同意过的这一步就不出现。

5. 点「收包开服」，转到任务页等它解包、落目录、备 Java。进度走完、页脚亮「完成，进入控制台」就收好了，到这里你机器上它就是一台可以启动的服务器了。

## 三、开服让大家进来

1. 列表里点「启动」。控制台出现 `Done` 就是开好了。第一次生成存档区块要等一两分钟。
2. 你自己进：`127.0.0.1`（端口改过的话是 `127.0.0.1:端口`）。
3. **朋友连进来**，分两种情况：

   - 和你**同一个网络**（一个宿舍、一个家里）：他们用你这台电脑的局域网地址进，看「设置 → 远程访问」里写着的那个 IP（端口对上）。Windows 防火墙第一次弹窗时选「允许访问」。
   - **不同网络**（各自在家）：到左侧「内网穿透」加一条隧道（OpenFrp、樱花都行，那里有一步一步的说明）。隧道拿到公网地址后发给大家，他们像原来服主开服时一样连这个地址就好。

中间本来就有的白名单、正版验证这些设置，收包后都跟包里一样照旧生效。

## 四、收完之后

- 每个人进度都在：上线第一件事先看一眼自己背包和家还在不在。都在——包收对了。
- 收包是复制：服主把服务器打开也不影响，收到的是打包那一刻的进度，之后服主那边再怎么玩都不会影响你这份。
- 想再续进度、或者包丢了：找服主要最新的 `.mdpack` 重收一遍即可。收完的实例在你自己电脑上，不会因为收了一遍就丢。
- 你也可以自己打包备份：列表里那台 `···` 菜单 →「打包发给朋友…」，选「打包下发」，得到另一个 .mdpack。发回来的成员按第一节一样收，谁都能临时客串服主。

## 五、容易出现的情况

- **说端口被占用**：换一个端口再点「检查占用」。
- **起不来、控制台报错**：截两张图（报错横幅、控制台几十行日志）发服主。95% 是 Java 版本或某个模组的问题，MineDeck 会自己识别常见错误。
- **模组打完包少一个、进服没有某模组内容**：更可能是服主打的包缺了 mod（打包时是全量的）；找服主确认，有必要重发一份。
- **朋友连不进来**：先让朋友试 `ping` 你的公网/局域网地址，然后把「内网穿透」页隧道的「日志」截图发服主。

## 六、反馈怎么说

一个事一条，照下面的格式写：

```
【做了什么】比如：收完包点了启动
【结果】成功 / 失败 / 一部分成功
【预期】服务器开起来，我能进服
【实际】控制台报错「Failed to load mod」…后面贴截图
【电脑】Windows 11（Win+R 输 winver 能看到）
【截图】报错界面 / 控制台，有的话都附上
```

存档和进度都在你机器上，卸载重装 MineDeck 也不丢（只是收包流程重新走一遍、注意选同一个目录或由 MineDeck 的「接管已有服务器」认回来）。
