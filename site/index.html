MineDeck 我的世界（Minecraft）Windows 一键开服工具

一个文件 MineDeck.exe，大约 13 MB。它会下载 Java 和服务端，用窗口管理服务器。整合包可以直接导入。樱花穿透和 OpenFrp 已经做在里面，不在同一个网络的朋友也能连进来。

可选功能：
  • AI 开服助手
  • 游戏内 AI
  • AI 伙伴
  • 音乐共享
下载 GitHub

在发布页下载 MineDeck.exe，放进一个单独的文件夹，双击运行。

三步开服

选好版本，点创建，后面的步骤会自动做完

  1. 1

    下载

    在发布页下载 MineDeck.exe，放进一个单独的文件夹。服务器、下载的 Java 和缓存都放在这个文件夹里，跟程序在一起。

  2. 2

    新建服务器

    双击运行，点「新建服务器」→ 选核心 → 选版本 → 选构建 → 勾选 EULA → 创建。

  3. 3

    启动，叫上朋友

    点「▶ 启动」。控制台出现 Done (...)!，就是开服成功了。同一个局域网里的朋友，连 你的内网IP:端口。不在同一个网络的朋友，到「内网穿透」页加一条隧道，把公网地址发给他们。

点创建以后，会自动做完这些事：按版本下载 Java、下载服务端、运行安装器、同意 EULA、写出配置和启动脚本。下载 Java 和服务端时优先用国内镜像（BMCLAPI、清华 TUNA），镜像不可用就改用官方源。

功能

开服、排错、联机，再加上可选的 AI

AI 都是可选的。要用的话，填你自己的 API Key，在「设置 → AI（可选）」里配置后才会启用。不配置 AI，MineDeck 就不会连接任何 AI 服务，开服和原来的用法也不受影响。

AI 开服助手

先查日志和配置再回答，改东西先问你

在标题栏右上角打开「AI 助手」。问它「服务器为什么起不来」，它会先看日志、配置和崩溃报告再回答。

要改配置、换 Java 或重启服务器，会先弹出确认卡片，你点了才执行。发给 AI 的内容会先去掉本机路径、局域网地址和密钥，你随时可以看实际发出去的原文。

报错横幅

服务器起不来？横幅直接说原因

这一步不用 AI。开服失败时，控制台顶部的提示条能认出常见原因，比如缺前置模组、把客户端模组放进了服务器、端口被占、Java 版本不对，并告诉你怎么改。

配置了 AI 时，可以点「让 AI 分析」。

游戏内 AI

在聊天里 @AI 提问

玩家在聊天里说「@AI」再加上问题，回复默认所有人都能看见。问题前面可以加几个选项。/私 只回复提问的人。/问 只回答，不执行命令。/额度 看今天还能问几次。/帮助 看怎么用。

你在面板里勾选的玩家，可以让 AI 执行白名单里的命令。每条命令的参数都会按允许的写法核对。op、execute 这类命令不会执行。白名单也可以在面板里打开。

AI 伙伴

会跟随、砍树、打怪的伙伴

可以在 NeoForge 1.21.1 或 Forge 1.20.1 的服务器里放 AI 伙伴。聊天里说「@伙伴名 跟着我」「砍 10 个橡木原木」「打附近的僵尸」，它就会去做。

可以设置不让它挖的区域，也可以指定不许打的生物。好友那边只需要装一个伙伴模组。

音乐共享

把房主的音乐放给全服听

把房主电脑上音乐软件的声音经 Simple Voice Chat 广播给服里的人，每人可在语音设置里单独调小或静音。

在 Windows 11 上，可以只录你选的那个音乐程序，不会录进游戏声音和语音。桥接模组已经带在 MineDeck 里，在音乐共享页安装即可。

接入 AI（可选）

七个预设，填 Key 就能用

支持 OpenAI 兼容和 Claude 两种协议，内置 DeepSeek、通义千问、Kimi、智谱、OpenAI、Claude、Ollama（本机）七个预设，也可以填自定义地址。

MineDeck 会按公开价格估算每次大概花多少钱。每个功能都能设每天的用量上限，按 token 算。Key 加密保存在这台电脑上，除了你选的服务商，不会发给别人。不配置 AI，就不会连接任何 AI 服务。

也可以打开 MCP 接口，让 Claude Desktop、Cherry Studio、Cursor 连上 MineDeck。查状态、看日志可以直接做。要改服务器，仍然要你在 MineDeck 里确认。

功能一览

更多功能

完整的功能表见 README。

  • 十二种服务端核心

    原版。插件服是 Paper、Purpur、Leaves、Folia。模组服是 Fabric、NeoForge、Forge。模组和插件都能用的是 Mohist、Banner。群组代理是 Velocity、Waterfall。

  • Java 不用自己装

    按游戏版本选择对应的 Java，常见的是 8、16、17、21、25。电脑里已经有合适的就直接用，不再下载。没有的话会下载一份，只给 MineDeck 用，不改系统设置，也不影响你已经装好的 Java。

  • 下载与重试

    下载时按这个顺序尝试：先是国内镜像 BMCLAPI 和清华 TUNA，然后是 Adoptium 和官方源，最后是 Mojang 提供的 Java。某个源失败就换下一个，最多重试 3 轮。下完会校验文件是否完整。

  • 整合包导入

    把 Modrinth 整合包（.mrpack）拖进来，就能建好服务器。核心、版本和加载器会自动识别，只给客户端用的文件会跳过。CurseForge 的 zip 也可以导入，需要自己填 API Key。

  • 内网穿透

    可以接 OpenFrp、樱花穿透，也可以填你自己的 frps。穿透客户端 frpc 会自动下载，并跟着服务器启动。公网地址可以在页面上复制。

  • 备份、重启和定时任务

    可以备份和还原世界，服务器开着的时候也能备份。崩溃后会自动再启动，先等 10 秒，再等 30 秒，再等 60 秒，连续 3 次仍起不来就停止。正常运行超过 10 分钟后，这个计数会清零。还可以按天定时重启、执行命令或备份。

  • 玩家管理

    可以看在线玩家，踢出或设为 OP。白名单、管理员和封禁可以在界面里改。服务器关着的时候，改的是名单文件本身。离线模式的 UUID 会自动算好。

  • 资源浏览器

    在实例里直接搜索安装 Modrinth 模组和插件，按核心与版本自动过滤兼容项。

  • 全部服务器配置

    server.properties 里大约 60 项，分成 7 组。可以搜索。每项有中文说明、取值范围，以及要不要重启。当前游戏版本用不到的项会隐藏。

  • 控制台

    可以在 GBK 和 UTF-8 之间切换，老整合包出现乱码时用这个。警告和错误会标上颜色。日志可以过滤，命令有历史记录。常用命令和在线玩家名可以用 Tab 补全。

  • 远程管理

    可以打开局域网访问，用密码登录，手机上也能管服务器。另外有 REST API，也可以用 Webhook 把事件推送给别的程序。

  • 启动时的保护

    较老的版本会自动打开 log4shell 的官方缓解。启动服务器时会清掉 JAVA_HOME 这类环境变量，避免用到别的 Java。下载的文件会做完整性校验。本机接口带一组随机令牌，用来防止别的程序随便调用。

问答

常见问题

还有别的问题，可以在 GitHub 上提 Issue。

要自己装 Java 吗？

不用自己装。电脑里已经有合适的 Java，MineDeck 会直接用。没有的话，它会按游戏版本下载一份对应的 Java，只给 MineDeck 自己用，不改系统设置，也不影响你装的其他软件。

朋友不在同一个网络，怎么连进来？

在「内网穿透」页添加一条隧道，樱花穿透、OpenFrp 或你自己的 frps 都可以。把隧道绑定到这台服务器，并打开「跟随实例启动」。开服后把公网地址发给朋友。同一个局域网的朋友不用隧道，直接连 你的内网IP:端口。

支持哪些版本和核心？

支持 MC 1.12.2 到最新版，包括 26.x 起的年份版本号。核心有 12 种：原版、Paper、Purpur、Leaves、Folia、Fabric、NeoForge、Forge、Mohist、Banner、Velocity、Waterfall。Modrinth（.mrpack）和 CurseForge（zip）的整合包可以直接导入。

服务器起不来、报错看不懂怎么办？

开服失败时，先看控制台顶部的提示条。缺前置模组、把客户端模组放进了服务器、端口被占、Java 版本不对，这些常见原因它都能直接认出来，并告诉你怎么改。接了 AI 的话，还可以点「让 AI 分析」，或者在 AI 助手里直接问。

AI 功能要花钱吗？会不会偷偷联网？

AI 是可选功能。不配置 AI，MineDeck 就不会连接任何 AI 服务。要用的话，填入你自己的 API Key，费用由你选的服务商直接收取。MineDeck 会估算每次大概花多少钱，每个功能都能设每天的用量上限。Key 加密保存在这台电脑上，除了你选的服务商，不会发给别人。

AI 会不会乱改我的服务器？

AI 不会擅自改你的服务器。看日志、读配置这类只读的事，它可以直接做。改配置、换 Java、重启服务器之前，它会先弹出一张确认卡片，你点了确认才会执行。每一步都会记在本机的操作记录里（logs\ops 文件夹）。游戏内 AI 默认只回答问题。只有你勾选的玩家，才能让它执行命令，而且只能执行白名单里的命令。op、execute 这类命令不会执行。

AI 伙伴和音乐共享，好友要装什么？

  • AI 伙伴：好友的客户端只装伙伴模组，发布页有下载。
  • 音乐共享：服务器和好友都装同一版本的 Simple Voice Chat，桥接模组由 MineDeck 装进服务器。

数据存在哪？怎么卸载？

数据都在 exe 所在的文件夹里，只有界面偏好存在 %LocalAppData%\MineDeck。卸载就是删掉这两个文件夹。

Windows 提示「已保护你的电脑」？

exe 没有数字签名，点「更多信息 → 仍要运行」即可。源码公开（MIT），也可以自己构建，步骤见 README 的「从源码构建」。
