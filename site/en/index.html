MineDeck One-click Minecraft server launcher for Windows

One file, MineDeck.exe, about 13 MB. It downloads Java and the server software and manages servers in a window. Modpacks can be imported directly. SakuraFrp and OpenFrp are built in, so friends who are not on the same network can join.

The app's interface is Chinese only for now. Below, Chinese labels from the app are given with a translation.

Optional:
  • AI server assistant
  • In-game AI
  • AI companions
  • Music sharing
Download GitHub

On the releases page, download MineDeck.exe, put it in its own folder and double-click it.

Three steps

Pick a version and click create. The rest of the steps run on their own

  1. 1

    Download

    Get MineDeck.exe from the releases page and put it in its own folder. Servers, the downloaded Java and the cache all stay in that folder, next to the program.

  2. 2

    Create a server

    Double-click it, then 新建服务器 (New server) → pick a server type → a version → a build → accept the EULA → create.

  3. 3

    Start it and invite friends

    Click ▶ 启动 (Start). When the console shows Done (...)!, the server is up. Friends on the same LAN connect to your-LAN-IP:port. Friends who are not on the same network add a tunnel on the 内网穿透 (tunnels) page, and you send them the public address.

After you click create, these steps finish on their own: download Java for that game version, download the server, run the installer, accept the EULA, write the config and start script. Downloads of Java and the server try mirrors in China first (BMCLAPI and Tsinghua TUNA). If a mirror is unavailable, MineDeck uses the official source.

Features

Hosting, troubleshooting and playing with friends, plus optional AI

AI features are optional. To use them, enter your own API key and set them up under 设置 → AI（可选） (Settings → AI). If you don't set up AI, MineDeck does not connect to any AI service, and hosting works as before.

AI server assistant

Checks the logs and configs first, and asks before changing anything

Open the assistant (AI 助手) from the top-right of the title bar. Ask why your server won't start, and it reads the logs, configs and crash reports before it answers.

To change a config, switch Java or restart the server, a confirmation card appears first and runs only after you click it. Paths on this PC, LAN addresses and keys are removed before anything is sent. You can always see the exact text that was sent.

Error banner

Server won't start? The banner tells you why

This step does not need AI. When the server fails to start, a notice at the top of the console recognizes common causes, such as a missing required mod, a client mod placed on the server, a port already in use or the wrong Java version, and tells you what to change.

With AI set up, you can also click 让 AI 分析 (Ask AI to analyze).

In-game AI

Players ask @AI in chat

Players say @AI and then a question. Replies are visible to everyone by default. Options can go in front of the question. /私 replies only to the asker. /问 only answers and does not run commands. /额度 shows how many questions are left today. /帮助 shows how to use it.

Players you tick in the panel can have the AI run allowlisted commands. Each command's arguments are checked against the allowed form. Commands such as op and execute are not run. You can also turn on the server whitelist in the panel.

AI companions

Companions that follow players, gather wood and fight mobs

You can add AI companions on NeoForge 1.21.1 or Forge 1.20.1 servers. In chat, say 「@伙伴名 跟着我」 (follow me), 「砍 10 个橡木原木」 (chop 10 oak logs) or 「打附近的僵尸」 (fight the zombies nearby), and the companion does it.

You can set areas it must not dig, and mobs it must not attack. Friends only need one companion mod on the client.

Music sharing

Play the host's music to everyone on the server

Stream the sound of a music player on the host's PC to everyone on the server through Simple Voice Chat; each player can turn it down or mute it in their voice settings.

On Windows 11 it can record only the music program you pick, without game sound or voice chat. The bridge mod is included in MineDeck. Install it on the music sharing page.

AI setup (optional)

Seven presets: fill in a key and go

OpenAI-compatible and Claude protocols, with presets for DeepSeek, Qwen, Kimi, Zhipu, OpenAI, Claude and Ollama (local), plus a custom address.

MineDeck estimates roughly how much each request costs, using public prices. Each feature can have a daily token limit. The key is stored encrypted on this PC and is sent only to the provider you chose, not to anyone else. If you don't set up AI, MineDeck does not connect to any AI service.

You can also turn on the MCP interface so Claude Desktop, Cherry Studio and Cursor can connect to MineDeck. Reading status and logs can happen directly. Changing the server still waits until you confirm in MineDeck.

At a glance

More features

The full feature table is in the README (Chinese).

  • 12 server types

    Vanilla. Plugin servers: Paper, Purpur, Leaves, Folia. Mod servers: Fabric, NeoForge, Forge. Mods and plugins together: Mohist, Banner. Proxies: Velocity, Waterfall.

  • Java, without installing it yourself

    MineDeck picks a Java build for the game version. Common ones are 8, 16, 17, 21 and 25. If this PC already has a suitable Java, it uses that and does not download another. Otherwise it downloads one for MineDeck only. It does not change your system Java settings, and it does not affect a Java you already installed.

  • Downloads and retries

    Downloads try sources in this order: mirrors in China (BMCLAPI and Tsinghua TUNA), then Adoptium and the official source, then the Java build from Mojang. If one source fails, MineDeck tries the next. It retries up to 3 rounds. After a download it checks that the file is complete.

  • Modpack import

    Drop in a Modrinth modpack (.mrpack) and MineDeck creates the server. It detects the server type, version and loader, and skips files that belong only on the client. A CurseForge zip can be imported too. You need to fill in your own API key.

  • Built-in tunnels

    You can use OpenFrp or SakuraFrp, or fill in your own frps. The frpc client is downloaded for you and can start with the server. The public address can be copied on the page.

  • Backups, restarts and schedules

    You can back up and restore the world, including while the server is running. After a crash it starts again, waiting 10 seconds, then 30, then 60. After 3 crashes in a row it stops trying and tells you. The count resets after the server has run normally for more than 10 minutes. You can also schedule a daily restart, command or backup.

  • Player management

    You can see who is online, kick them or make them OP. The whitelist, operator list and ban list can be edited in the window. While the server is stopped, those edits go into the list files. Offline-mode UUIDs are filled in for you.

  • Resource browser

    Search and install Modrinth mods and plugins from inside an instance, filtered for your server type and version.

  • All server settings

    About 60 entries in server.properties, in 7 groups. You can search. Each one has a description, an allowed range, and whether a restart is required. Entries the current game version does not use are hidden.

  • Console

    You can switch between GBK and UTF-8, which helps when an old modpack shows garbled text. Warnings and errors are colored. The log can be filtered, and commands have a history. Common commands and online player names can be completed with Tab.

  • Remote management

    You can turn on LAN access and sign in with a password, including from a phone. There is also a REST API, and webhooks can send events to other programs.

  • Checks at startup

    Older versions turn on the official Log4Shell mitigation. When the server starts, MineDeck clears JAVA_HOME and similar variables so it does not pick up a different Java. Downloaded files are checked. The local interface uses a random token so other programs cannot call it freely.

FAQ

Frequently asked questions

Anything else? Open an issue on GitHub.

Do I need to install Java myself?

No. If this PC already has a suitable Java, MineDeck uses it. If not, it downloads the Java build for that game version, for MineDeck only. It does not change system settings, and it does not affect other software you installed.

My friends aren't on the same network. How do they join?

On the 内网穿透 (tunnels) page, add a tunnel. SakuraFrp, OpenFrp or your own frps all work. Bind the tunnel to this server and turn on 跟随实例启动 (start with the server). After the server is up, send your friends the public address. Friends on the same LAN do not need a tunnel. They connect to your-LAN-IP:port.

Which versions and server types are supported?

MC 1.12.2 through the latest release, including the year-based version numbers from 26.x on. There are 12 server types: Vanilla, Paper, Purpur, Leaves, Folia, Fabric, NeoForge, Forge, Mohist, Banner, Velocity and Waterfall. Modrinth (.mrpack) and CurseForge (zip) modpacks can be imported directly.

My server won't start and I can't read the error. What now?

When the server fails to start, look at the notice at the top of the console. A missing required mod, a client mod placed on the server, a port already in use or the wrong Java version: it can recognize these common causes and tell you what to change. If AI is set up, you can also click 让 AI 分析 (Ask AI to analyze), or just ask in the AI assistant.

Do the AI features cost money? Will MineDeck go online behind my back?

AI is optional. If you don't set up AI, MineDeck does not connect to any AI service. To use it, enter your own API key. The provider you chose charges you directly. MineDeck estimates roughly how much each request costs, and each feature can have a daily usage limit. The key is stored encrypted on this PC. It is sent only to the provider you chose, not to anyone else.

Will the AI mess with my server?

The AI will not change your server on its own. Reading logs and configs can happen directly. Before it changes a config, switches Java or restarts the server, it shows a confirmation card, and the change runs only after you confirm. Each step is written to an operation log on this PC (the logs\ops folder). The in-game AI only answers questions by default. Only players you tick can have it run commands, and only allowlisted ones. Commands such as op and execute are not run.

What do friends need to install for AI companions and music sharing?

  • AI companions: friends install only the companion mod in their client; it's on the releases page.
  • Music sharing: the server and your friends install the same version of Simple Voice Chat; MineDeck installs the bridge mod into the server.

Where is my data, and how do I uninstall?

Everything is in the folder that holds the exe; only interface preferences are stored in %LocalAppData%\MineDeck. To uninstall, delete those two folders.

Windows says "Windows protected your PC"?

The exe isn't digitally signed. Click "More info → Run anyway". The source is public (MIT), and you can build it yourself; see building from source in the README.
