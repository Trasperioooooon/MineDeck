# 中国大陆下载测试脚本

`MineDeck下载测试.bat` 是给在中国大陆的用户双击运行的。用户反馈下载 Forge、NeoForge 老断、要重试好多次，我们在国外测不出大陆的网络是什么样，就把这个文件发给愿意帮忙的用户，请他们跑一遍，把结果发回来。

它只用 Windows 自带的 curl，像 MineDeck 平时那样去连这些地方：软件更新用的 GitHub、两个加速站和官网，版本列表和各家核心的来源，清华镜像和 Adoptium 的 Java。另外还从 NeoForge 1.21.1 安装器要下的依赖库里挑了 20 个，各从 BMCLAPI 和官方拉一遍。最后下几个大文件，看会不会下到一半断掉，顺带看各个下载站支不支持断点续传。每一次都记下这几样：连没连上，失败了是什么原因，用了多久，速度多少，跳转了几次，最后被分到了哪台下载服务器（只记服务器名，地址后面的参数不要）。一共会下大约 90MB，下下来的数据直接丢掉，不落到硬盘上。

它不记用户的 IP、电脑名、用户名和系统版本，也不读用户电脑上的任何文件。开头有两个可以直接回车跳过的问题：宽带是哪家，开没开加速器或 VPN。这两样都是用户自己选的，脚本不去查。结果存成桌面上的「MineDeck下载测试结果.txt」，同时复制到剪贴板，方便直接贴进聊天窗口，内容和窗口里显示的一样。脚本是明文的，第一行以下全是 PowerShell，用户不放心可以先用记事本打开看。

结果先看「汇总」那几行：依赖库从 BMCLAPI 拉成功了几个、从官方拉成功了几个，失败原因各是什么，BMCLAPI 把请求分到了哪些下载服务器、每台成功了几次。明细里每一行是一次请求。

作者自己试脚本时，先设两个环境变量：`MD_NETTEST_QUICK=1` 是省流量模式，大文件只下 2MB，依赖库只拉 5 个，也不碰剪贴板；`MD_NETTEST_OUT` 指一个文件夹，结果写到那里，不写桌面。用户不用管这两个。

这个文件必须是 CRLF 换行、不带 BOM，`.gitattributes` 已经管着 CRLF。用记事本另存时别选「带 BOM 的 UTF-8」，不然 cmd 读不了第一行。脚本里写死的版本（v3.2.9 的更新文件、NeoForge 21.1.77、原版 1.21.1）都在 2026-11-27 核对过地址。以后有哪个地址失效了，测出来会是 404，换成新的就行。
