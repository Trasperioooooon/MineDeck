# MineDeck 实操视频：分镜与口播稿

作者后来决定先不录口播，改做靠字幕讲解的演示视频，实际内容以同目录的 `scenes.js` 为准。这份稿子留着，以后要出口播版时还能用。

这是五分钟左右那支实操视频的底稿。画面是在 `tools/ui-dev` 的仿真后端上录的真实界面，录制办法见同目录的 `README.md`；声音是作者本人的口播。时间线跟着口播走：每一段有多长，就看这一段录音多长，再加上前后的留白。所以下面标的秒数只是估计，录完以后以录音为准。按平常的语速，十段口播合起来在四分五十秒到五分二十秒之间，加上画面上的停顿和片尾，成片五分半以内。

全片分十段，每段录一个文件。口播是照着「说出来顺口」写的，作者可以改成自己的说法。只要不改画面上要点的东西（按钮名、页面名），画面就不用跟着改；改了这些，告诉做录制的人一声。

## 怎么录

每段存一个文件，用段号命名，01 到 10，手机录音机录出来的 m4a 也可以。放进 `tools/promo/tutorial/voice/`，这个文件夹不进 git。

找一个安静的房间，关掉风扇和空调。手机或耳机麦克风离嘴二三十厘米，别正对着嘴吹气。每个文件开头和结尾各空一秒再说话。读错了不用停下来，空两秒，从那句话开头重读一遍，剪的时候取后一遍；整段不满意，就整段重录、覆盖原来的文件。

语速按平时跟朋友讲东西的速度就行，不用赶。读到「点开始部署」这种说操作的句子，说完稍微停一下，画面上的点击会落在这句话上。稿子里的英文名（Paper、Fabric、Forge、NeoForge、Modrinth、OpenFrp、EULA、GitHub、API Key）怎么顺口怎么读；mrpack 不好念的话，直接说「整合包文件」。全部录完大概要二三十分钟。

## 01 开头（约 20 秒）

**口播**

> 这是 MineDeck，一个在 Windows 上开我的世界 Java 版服务器的工具，免费开源。这期从下载开始，开一台服务器，让朋友连进来，再讲平时怎么管。进度条上分了章节，可以直接跳到你要看的那段。

**画面**

开场先给做好以后的样子：服务器列表里「生存服 · 朋友」正在运行，三个人在线，镜头慢慢推近这张卡片。说到「免费开源」时，右下角浮出 MineDeck 的图标和字标（用宣传片的图标素材）。说到「分了章节」时，切到一张章节目录卡，下面九个章节名依次亮起，和 B 站进度条上的分段一一对应：下载和第一次打开、新建服务器、启动和控制台、让朋友连进来、改设置、玩家和备份、模组和整合包、AI（可选）、其他小功能。这一段垫宣传片的配乐 Warmth by the Window，人声进来时压低。

## 02 下载和第一次打开（约 30 秒）

**口播**

> 在 GitHub 的发布页下载 MineDeck.exe，就这一个文件。给它建一个单独的文件夹，以后服务器、Java 和备份都放在这里面。第一次双击，Windows 可能会提示已保护你的电脑，这是因为程序没有数字签名，点更多信息，再点仍要运行。第一次打开要看一份用户协议，勾上同意就能用了。

**画面**

发布页和 Windows 的提示框都不在仿真界面里，这一段前半用示意画面，不去仿画别人的网页和系统窗口。先是一个文件图标，写着 MineDeck.exe；它落进一个新建的空文件夹，文件夹里随后浮出「服务器」「Java」「备份」三个标签，表示以后的东西都在这里。接着是提示框的示意，只画两个按钮上的字「更多信息」和「仍要运行」，用箭头连起来，不画成 Windows 对话框的样子。

后半是真实界面：首次打开的引导卡（仿真后端设成还没同意过协议）。光标滚过协议，勾上「我已阅读并同意」，点「同意并开始使用」，进入空的服务器列表。

作者愿意的话，可以自己录十秒左右的真机画面换掉前半的示意：下载、双击、提示框。录的时候别露出浏览器书签和桌面上的其他东西。

## 03 新建服务器（约 52 秒）

**口播**

> 左边点新建服务器，选从零创建。第一步选核心。只想和朋友玩原版生存，选 Paper，玩法和原版基本一样，还能装插件，所以标着新手推荐。要玩模组，就选模组对应的加载器，Fabric、Forge 或者 NeoForge。下一步选游戏版本，要和朋友们的一致。构建默认是最新的稳定版，不用改。最后起个名字，没有模组的话，内存给两到四 G 就够，难度和游戏模式也在这里选。勾上同意 EULA，点开始部署。Java 和服务端会自动下载，默认走国内镜像，等它跑完就行。

**画面**

从空的服务器列表开始，光标点侧栏「新建服务器」，出现两张卡片，点「从零创建」。核心页有五个分组。说到 Paper 时镜头推近「插件服」那一组，Paper 卡片上的「新手推荐」加一个高亮框；说到 Fabric、Forge、NeoForge 时，高亮框依次移到「模组服」分组里的这三张卡片上，然后回来选中 Paper，点「下一步」。

版本页在搜索框里打 1.21.4，选中，点「下一步」。构建页停一拍，默认选中的那一行加一个短暂的框，点「下一步」。基本设置页：实例名称打「生存服 · 朋友」；把内存滑条拖到 4 GB，镜头推近经验条样式的内存条和下面「没有模组的小队，2~4GB 足够」那句提示；难度选「普通」，游戏模式保持「生存」；滚到底勾上 EULA，点「开始部署」。

部署页快进，右上角挂一个「快进」角标。四个步骤依次打勾：下载 Java 21、下载 Paper 核心、同意 EULA 并生成配置、生成启动脚本。说到「国内镜像」时，日志里「BMCLAPI 镜像」那一行亮一下。最后部署完成，弹出「服务器创建成功」。

## 04 启动和控制台（约 30 秒）

**口播**

> 部署完进到这台服务器，点启动。控制台里出现 Done，就开好了。下面的框可以直接输命令，比如输 op 加空格，按 Tab 能补全在线玩家的名字。日志多的时候，用上面的过滤框，只看报错或者某个玩家。老整合包的日志要是乱码，把编码换成 GBK 试试。

**画面**

点「完成，进入控制台」，进到详情页，点「启动」。状态胶囊变成「启动中」，开服日志一行行进来，出现「Done」的那一行加高亮，状态变成「运行中」。接着时间跳一下（右上角挂「几分钟后」角标），日志里多了 Steve 和 Alex 进服的两行。命令框里打「op 」，按 Tab，补全列表里出现在线玩家的名字，选 Alex，回车，日志里回显这条命令。

然后在过滤框里打 Alex，日志只剩跟他有关的几行，再清空。最后点开「编码」下拉，镜头推近 GBK 这个选项，不真的切换，因为这台服务器不是老整合包。

## 05 让朋友连进来（约 45 秒）

**口播**

> 同一个局域网的朋友，在游戏里添加服务器，地址填你电脑的内网 IP 加端口，内网 IP 一般是 192.168 开头。不在一起的朋友要用内网穿透。先到 OpenFrp 的网站建一条 TCP 隧道，复制用户密钥和隧道 ID。回到 MineDeck 的内网穿透页，点添加隧道，把这两样填进去，绑定这台服务器，打开跟随实例启动，以后一开服，隧道就跟着连上。连上以后点复制，把公网地址发给朋友。樱花穿透和自己的 frps 填法也差不多。

**画面**

前半是示意画面。先画一台电脑和朋友的电脑连着同一个路由器，下面写「游戏里添加服务器：内网 IP:25565」，内网 IP 用「192.168.x.x」表示，旁边一行小字「在 Windows 设置的网络里能看到」。界面上目前没有直接显示这个地址，所以这里只能用示意，见文末。然后画两台电脑分在两个地方，中间一条线穿过「内网穿透」。再用一张字卡列出在 OpenFrp 网站上要做的三件事：建 TCP 隧道、本地端口填 25565、复制用户密钥和隧道 ID。不录 OpenFrp 的网页。

后半回到真实界面：侧栏点「内网穿透」，点「添加隧道」。服务商保持 OpenFrp；用户密钥填一串编出来的假密钥，隧道 ID 填 123456；绑定实例选「生存服 · 朋友」；打开「跟随实例启动」，点确认。隧道卡片出现，状态从启动中变成运行中，公网地址出来时加高亮，光标点「复制」，弹出「已复制」。

可选：作者录十到十五秒游戏画面接在后面，内容是多人游戏、添加服务器、粘贴地址、进服。

## 06 改设置（约 28 秒）

**口播**

> 要改设置，进常用设置。server.properties 里常用的几十项分好了组，每项都有中文说明，也标了要不要重启。找不到就直接搜，比如搜视距。服务器介绍可以点颜色，旁边能看到效果。改完点保存，标着重启生效的，重启一下服务器。内存在内存和启动里调。

**画面**

详情页切到「常用设置」，镜头沿着分组标题扫过去，推近一项带「重启生效」标记的设置。搜索框里打「视距」，列表筛到这一项，把数值从 10 改到 12，底部弹出保存条。清空搜索，找到服务器介绍（MOTD）那一项，点调色板里的金色，旁边预览里的字跟着变色。点保存，弹出保存成功的提示。说到「内存」时切到「内存 / 启动」标签，停一拍。

## 07 玩家和备份（约 35 秒）

**口播**

> 玩家页能看到谁在线，可以给 OP，也可以踢人。白名单、管理员和封禁名单，输名字回车就加上了。备份页点立即备份世界，开着服也能备，还能写个标签，比如打龙前。要回档就先停服，再点还原，它会先把现在的世界也备份一份。定时任务里可以打开崩溃自动重启，再加一条每天凌晨四点的定时备份。

**画面**

「玩家」标签：在线玩家三个名字，镜头推近名字后面的「OP」和「踢」。在白名单的输入框里打 Mia_23，回车，名单里多出一个。

「备份」标签：标签框里打「打龙前」，点「立即备份世界」，列表顶上多出一条。说到「先停服」时，光标点页头的「停止」，状态变成已停止；再点刚才那条备份的「还原」，弹出确认框，镜头推近「当前世界会先自动备份一份」，点「还原」，弹出「还原完成」。

「定时任务」标签：打开「崩溃自动重启」，镜头推近隔 10 秒、30 秒、60 秒再启动的那句说明。再添加一条「定时备份」，时间 04:00，点保存。

## 08 模组和整合包（约 30 秒）

**口播**

> 装插件或者模组，进资源页搜 Modrinth，只会列出和这台服务器对得上的，点安装，重启以后生效。想玩整合包，在新建服务器里选导入整合包，把 mrpack 文件拖进来，核心、版本和加载器会自动识别，点导入并部署。CurseForge 的整合包也能导，要先填一个 API Key。

**画面**

「资源」标签：搜索框里打 chunky，结果里出现 Chunky，点安装，弹出「已安装 Chunky……重启服务器后生效」。

然后侧栏「新建服务器」，选「导入整合包」。一个「机械动力整合包.mrpack」的文件图标从画面外拖进上传框；拖的动作是画上去的，实际用文件选择接口把文件交给页面。识别结果出来，写着 Forge 1.20.1 和文件数，名字已经填好，点「导入并部署」，部署进度快进几步就切走。

## 09 AI（可选）（约 30 秒）

**口播**

> AI 是可选的，不配置就不会连接任何 AI 服务。要用的话，在设置里选一家服务商，填自己的 API Key，再设一个每天的用量上限。开服失败时，控制台顶上的提示能认出常见原因，这一步不用 AI。接了 AI，还可以点让 AI 分析，它要改什么，会先弹卡片等你确认。

**画面**

设置里点「AI（可选）」，先停在顶部那句「不配置就不连接任何 AI 服务」的说明上。然后在预设里点 DeepSeek，Key 框里填一串编出来的假 Key，点测试连接，显示连接正常；往下滚到每日额度，镜头推近「万 token / 天」。

再切到「机械动力整合包」的控制台，顶上是报错横幅「缺少前置模组」，镜头推近横幅里写的原因和修法。点「让 AI 分析」，右边的 AI 面板打开，AI 读完模组清单，给出一张待确认的卡片，镜头停在卡片的确认按钮上，不点。

游戏内问答、AI 伙伴和音乐共享这次不讲，宣传片里演示过，以后可以各剪一支短片。

## 10 其他小功能和结尾（约 35 秒，含片尾）

**口播**

> 最后几个小功能。在设置里打开远程访问，设好密码，重启一次 MineDeck，同一个 Wi-Fi 下的手机扫码就能管服务器。也可以设成关窗口时缩到托盘，服务器接着跑，或者开机自动启动。外观里有七套配色。MineDeck 免费开源，下载地址在简介里，有问题欢迎到 GitHub 反馈。谢谢观看。

**画面**

设置里点「远程访问」，打开「允许局域网访问」，填访问密码，二维码出来（仿真后端里的地址是编的）。切到手机竖屏画面（390×844 的视口），看服务器列表在手机上的样子和底部的标签栏。接着是托盘的示意图：任务栏角落的图标，右键菜单里「打开面板」和「全部停止并退出」，画成示意，不用 Windows 的真截图；然后「启动与托盘」页一闪而过。「外观」页依次点三四套配色，整个界面跟着换。

最后接片尾，直接用宣传片的片尾：图标、字标、「免费开源 · Windows 10/11 · v3.0.0」、网址 trasperioooooon.github.io/MineDeck 和「GitHub 搜索 MineDeck」。配乐回到 Warmth by the Window，渐弱结束。

## 字幕和配乐

字幕直接用口播原文，按停顿断句，每行不超过 18 个字，只用 GB2312 里的字，和宣传片用同一套字体子集。稿子里没有感叹号，也不用「轻松」「告别」这一类词，和宣传片同一个口径。画面上的关键操作用框和推近来指，不再另配文字。

配乐：开头和片尾用 Warmth by the Window，中间垫一首安静、能循环的底乐，在人声底下压低 18 到 20 dB，底乐的提示词之后再补。成片响度 -14 LUFS，以人声为主。

## 制作备注

这一节是写给做录制器的人看的。

仿真后端要补一个教程用的数据场景。开头服务器列表是空的；第 3 段部署完以后，列表里只有「生存服 · 朋友」；第 8 段导入以后多出「机械动力整合包」，它带着缺前置模组的报错，第 9 段要用。隧道开头一条都没有，第 5 段加完以后是一条。原来仿真数据里的另外两台服务器和两条隧道，这支片子里用不上。在线玩家用 Steve、Alex、Kai_07 三个名字：仿真数据里原来的 Notch_CN 借的是真人（游戏作者）的名字，公开的视频里不要出现。

下面这些现在是固定值，或者按真实时间推，要改成跟着虚拟时间走：部署进度、开服日志、玩家进服、隧道从启动中变成运行中。「启动」「停止」要真的改状态，「立即备份世界」要在列表里加一条。「导入整合包」在仿真后端里还没有接口，要补一个假接口，返回识别结果和一个部署任务。版本号照宣传片的做法改成 3.0.0。

第 2 段的文件图标和提示框、第 5 段的网络示意和 OpenFrp 步骤卡、第 10 段的托盘菜单，都是示意画面，用宣传片 `scene` 那套写法单独画，不仿画别人的网页和系统窗口。

可选的真机片段有两处：第 2 段的下载和提示框，第 5 段的游戏里进服。作者自己录的话，用临时文件夹里的 MineDeck，不要在 `D:\MineDeck` 里录，那里的隧道会自己启动；游戏里的地址填局域网地址；游戏里的玩家名介意的话，用小号。

## 写稿时发现的界面缺口

界面上没有直接显示局域网里的连接地址。同一个局域网的朋友要用「内网 IP 加端口」连进来，但 MineDeck 只在远程访问的设置里列出本机 IP，那是管理界面的地址，端口也不一样，新手只能自己去 Windows 的网络设置里找。所以第 5 段的前半只能用示意画面带过。可以考虑在服务器详情页或者卡片上加一行局域网连接地址（比如 192.168.1.23:25565）和一个复制按钮。加了以后，这一段的前半可以改成真实界面，口播改成「地址在服务器页上，点复制发给朋友」。
