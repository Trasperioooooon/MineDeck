# MineDeck 宣传动画

这个目录生成 MineDeck 的宣传视频：76 秒，16:9，2560×1440 和 1920×1080 两个版本，都是恒定 60 帧，带一条立体声配乐。配乐是作者按 `配乐提示词.md` 用 Gemini 的音乐模型生成的，放在 `music/` 里，由 `music.js` 对上节拍以后合进视频。画面里的界面全部是真实界面的截图，在 `tools/ui-dev` 的仿真后端上拍，数据都是仿真后端里的假数据，没有任何真人信息，也没有用游戏本身的贴图、字体、标志或截图。

## 重新出片

双击 `make-video.bat` 就行，大约十分钟。它按顺序做五件事：检查上屏文字，拍界面截图，逐帧渲染，编码，合配乐。需要 Node 18 以上、PATH 里的 ffmpeg、`tools/ui-dev/node_modules` 里的 Playwright，以及本机装好的 Google Chrome（Playwright 自带的 Chromium 没装，脚本都用 `channel: "chrome"` 启动本机 Chrome）。

想分步跑的话，在任意目录执行下面几条，先把 `NODE_PATH` 指到 `tools/ui-dev/node_modules`：

- `node tools/promo/video/check-text.js` 检查字幕和其他上屏文字：只用 GB2312 里的字（内嵌的思源黑体子集就是按 GB2312 做的），字幕每行不超过 18 个字符，没有「轻松」「告别」这类词，没有感叹号，「一键开服」全片只出现一次。
- `node tools/promo/video/capture.js` 起一份仿真后端（端口 27410），用 Chrome 拍 30 多张界面截图到 `out/shots/`，同时把要标框、要让光标去点的元素位置记进 `out/shots/rects.json`，再从 `assets/icon.ico` 取出 256 像素的图标、从 `internal/web/ui/index.html` 取出启动画面用的 16×16 像素图标。桌面截图是 1280×800、DPR 2，浅色、配色「方块」；镜头推得比较近的几张（控制台、内网穿透、AI 助手）用 DPR 3，放大以后字还是清楚的；手机截图是 390×844、DPR 3。加 `--only=正则` 可以只重拍几张。
- `node tools/promo/video/render.js` 逐帧渲染。先在浏览器里实测一遍：每个字都确实由内嵌字体画出来，每条字幕都在 5% 的标题安全区里。然后开 6 个页面并行，对第 i 帧调用 `renderAt(i / 60)` 再截图，存到 `out/frames/`。4560 帧大约四分钟。加 `--every=30` 只渲染每半秒一帧（存到 `out/preview/`，看片用），`--at=12.5,40` 只渲染这几个时间点（存到 `out/samples/`）。
- `node tools/promo/video/encode.js` 把帧编成两个视频，用 ffprobe 核对分辨率、帧率、帧数、时长、色彩标签，出一张每秒一帧的联系表和几张原尺寸样帧，最后删掉 `out/frames/`。加 `--keep-frames` 可以留着帧图。编出来的视频还没有声音。
- `node tools/promo/video/music.js` 把 `music/` 里的配乐合进两个视频：视频流原样拷贝，只加一条 AAC 音轨，就地替换，可以反复跑。这首曲子实际是 124 BPM，比画面快一点，前奏也长，所以先整首按采样率放慢约 4.9%（音高跟着低 0.83 个半音，没有时间拉伸的杂音），再裁掉开头，让曲子里律动进来的那一下落在 4 秒、主段落落在 44 秒，然后把响度线性调到 -14 LUFS、真峰值 -1.5 dBTP。换曲子时改脚本开头的 `MUSIC` 和 `HIT`（两处重拍在曲子里的秒数）。

想在浏览器里边改边看，运行 `node tools/promo/video/serve.js`，打开 `http://127.0.0.1:27411/?t=12.5`（停在第 12.5 秒），加 `&debug` 左上角会显示时间和小节，`?play=1` 按真实时间播放。

## 文件

`captions.js` 是节拍网格、分段和全部上屏文字，改文案只改这一个文件。`scene.html`、`scene.css`、`scene.js` 是画面：`window.renderAt(t)` 只依赖时间 t，同一个 t 永远画出同一帧，页面里没有 CSS 动画和过渡。截图在画面里用「截图视图」摆放，镜头、光标和高亮框都写在截图自己的坐标里（桌面截图是 1280×800 的 CSS 像素），镜头推近拉远时框和光标的线宽不变。`capture.js`、`render.js`、`encode.js`、`music.js`、`check-text.js`、`serve.js` 是上面说的几个脚本，`music/` 里是配乐。`out/` 不进仓库。

拍截图时有三处是在浏览器里改仿真数据，界面代码一行没动。版本号改成了 3.0.0，和片尾一致（仿真后端写的是 2.9.0-beta.2）。部署进度页的 `/api/tasks/*` 按帧给出递增的进度，仿真后端给的是固定的 60%。「刚开服」那张把运行时长改短，控制台换成一段干净的开服日志，因为仿真后端的示例日志里有一段插件报错，放在「开好了」这一幕不合适。

## 节拍和段落

全片按 120 BPM 排：一拍 0.5 秒（30 帧），一小节四拍、2 秒（120 帧），一共 38 小节、76 秒、4560 帧。分段都落在小节线上，切镜头、点击、字幕进场都落在拍上。段落之间用草绿色的方块擦除转场，擦除在小节线前后各占大约 0.4 秒，正好在小节线那一帧完全盖住画面。

下面的小节从 1 数。写配乐提示词时可以照这个来。

- 第 1–3 小节（0–6 秒），开场。先出一句「想和朋友开个 MC 服务器？」，第 2 小节方块自下而上落下拼成图标，第 3 小节第一拍（4 秒）图标落定、放出一圈小方块，同时出字标和「我的世界 Windows 一键开服工具」。这是全片的主揭示，音乐在前两小节轻起、渐强，4 秒落下第一个重拍。
- 第 4–10 小节（6–20 秒），新建服务器。选核心、选版本、填名字点开始部署（每小节一步，点击在第 3 拍），然后两小节的部署进度（每半拍换一个进度），最后两小节讲「一个文件就够了」。稳定的中等能量律动。
- 第 11–16 小节（20–32 秒），启动与管理。第 11 小节点启动，第 12 小节看到 Done，第 13 小节服务器列表，第 14–16 小节报错横幅和它能认出的常见原因。律动保持，第 11 小节「开起来了」可以有个小提升。
- 第 17–22 小节（32–44 秒），整合包和联机。拖入 .mrpack、内网穿透复制公网地址、手机扫码管理。能量逐渐上扬，第 21–22 小节为下一段铺垫。
- 第 23–31 小节（44–62 秒），可选的 AI。第 23 小节「AI 是可选的」标题卡是第二个落点，也是全片能量最高的一段；之后是 AI 开服助手的确认卡片、游戏内 AI（画面里雨停天晴在 53.25 秒）、AI 伙伴、音乐共享、Key 和用量上限。
- 第 32 小节（62–64 秒），回顾，「开服、排错、联机」三个词落在第 2、3、4 拍，收尾前最后一次重拍。
- 第 33–38 小节（64–76 秒），片尾。图标再拼一次，字标、「免费开源 · Windows 10/11 · v3.0.0」、网址、「GitHub 搜索 MineDeck」在 66.25 秒前全部到位，之后静止约 10 秒。音乐从 64 秒进入尾声，渐弱到结束。

现在这首配乐对齐以后，段落大致是这样：前 4 秒是淡入的前奏，4 秒律动进来；大约 28.4 秒低音停下，进入一段安静的间奏，比画面在 32 秒的段落切换早三秒多，这是曲子本身的结构；36 秒起蓄力，44 秒前有一下很短的停顿，然后主段落落下；大约 68 秒律动停下，之后渐弱，75 秒前收尽。62.5–63.5 秒那三下，曲子里没有专门的重音。
